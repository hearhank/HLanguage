# 语言设计共识

> 本文档记录与项目所有者达成的设计共识（2026-08-12），是实现的**唯一依据**。所有决策按「Zig → Rust → TypeScript」参考优先级作出（`docs/adr/0001-reference-policy.md`）。术语定义以 `CONTEXT.md` 为准。

## 1. 定位与哲学

- 以数据为中心：定义数据、修改数据、传输数据、保存数据是语言的四大支柱
- **函数 = 唯一处理逻辑**（2026-08-13，Q13 定案）：一切数据处理通过函数表达；接口描述功能（处理能力的契约），复杂类型 = 数据字段 + 函数的组合；无其它处理机制（无运算符重载、无宏）
- **没有隐藏控制**：无异常、无宏、无隐式内存分配；一切控制流、资源与错误路径显式可见（唯一隐式行为：作用域退出自动销毁，词汇可见可预测）
- 同时支持系统编程（编译为原生二进制）与脚本编程（解释执行）
- 严肃长期项目，对标 Zig/Go；1.0 标准见 SPEC README

## 2. 双模式执行

- 同一份 `.hc` 源码两种执行方式，**语义一致**（不存在编译专用/脚本专用子语言）
- **语义一致边界**（2026-08-13 收紧，评审 B4）：语义一致 = 值语义、所有权语义、控制流一致；**错误检测策略是独立维度**——Debug 全检测、Release 裸路径、脚本模式 Debug 语义
- 架构：共享前端 → 共享 IR → 双后端（字节码 VM + LLVM 原生）
- 依据：`docs/adr/0004-dual-mode-architecture.md`

## 3. 类型系统

- 静态强类型；**显式标注为主，局部推断为辅**（Zig 第一、Rust 第二）
- 结构化类型（按形状判断兼容）为脚本模式可选特性（TS 第三）
- **引用类型**（2026-08-13，评审 B3）：定长/变长数组、集合为引用类型——传参走引用，复制需显式（`copy`）；标量保持值语义
- **权限标注模型**（2026-08-13，评审 D2；Rust 标杆修订）：类型标注 = 类型 + 读写权限（`*`/`*mut`）+ 所有权（o）；move 基于所有权判定（有 o 才能 move），与读写权限同属统一权限体系
- 类型即数据的形状：「定义数据」支柱的可靠性与可验证性由静态类型保证

## 4. 内存模型（核心）

- **Allocator**：分配经显式 Allocator；未显式传入时回退全局分配器
- **所有权（注册关系）**：带 `o` 标记的变量，所有权注册在当前作用域，退出时销毁；无 `o` 则注册在别处——通常为**分配器**（如 arena，显式分配、统一回收）或全局存储。**默认规则**（Q16 定案）：复杂类型（分配器创建）除 Arena 外**默认拥有**（o 隐含，作用域接管）；Arena 分配的无所有权。**无 `o` 变量禁止 move**（move 须对整个分配器进行）；仅带 `o` 的变量可 move
- **作用域**：所有权与生命周期的基本单位；每个块是无名字的函数，函数是有名字的作用域
- **move**：显式转移所有权（仅限带 `o` 的变量），不复制数据；转移后由目标作用域管理
- **全局变量**：`global` 声明，根作用域上下文，静态生命周期，默认不可 move、无 `o`
- **传参规则**：标量/纯值 struct 默认复制；数组、集合、复杂类型为引用类型——传参走引用，复制需显式（评审 B3）
- **只读引用**：可选双向注册（编译期选项）；Debug 默认注册、Release 默认裸读
- **读写引用**：强制双向注册；**唯一写者由运行时登记强制**（同一变量同一时间最多一个，可写包含可读）；**wr 引用不可拷贝，只能 move 传递**（评审 A5）；目标销毁→标记悬垂→访问抛错带位置
- **悬垂检测**：已注册引用悬垂访问抛错（携带出错位置）；未注册的悬垂是用户责任（未定义行为）
- **运行时错误**（评审 A2）：悬垂访问/唯一写者冲突 = **不可恢复运行时错误**，与 error union（可恢复）正交
- **无 GC**：双模式同一套模型
- 依据：`docs/adr/0003-memory-model.md`；未决项见 `05-open-questions-and-risks.md`

## 5. 错误处理

- error union + 显式错误集（Zig 第一）；`try` 式传播（Rust 第二）
- **无异常**（TS 第三不采纳：隐式控制流违背「显式优于隐式」）
- 悬垂检测错误属于本模型的运行时错误，同样携带出错位置

## 6. 并发

- 语言内**有 async/await 关键字**（2026-08-13 逆转；**偏离 Zig 第一**——Zig 0.15 移除关键字，H 选择 Rust/TS 式关键字）；`Future(T)` 为异步任务结果句柄，基于线程任务（A2 定案）
- **共享状态 = 四种线程访问模式类型**（2026-08-13 定案）：`OneToOne(T)`/`OneToMany(T)`/`ManyToOne(T)`/`ManyToMany(T)`——内建泛型共享内存容器（脚本生成实例化），写者数量由类型名保证（单写者无锁、多写者互斥）
- **线程所有权**（2026-08-13 定案）：任何作用域可开启线程，归当前作用域；退出时已完成→销毁、运行中→移交根作用域（**无隐式阻塞**）；显式 `t.join() !T` 消耗所有权，获取结果与错误（error union 跨线程传播）
- **根作用域**（2026-08-13，评审 A7）：程序最后退出的场所，负责最终资源回收；global 变量定义于此；后期线程池亦于此
- **线程捕获**（2026-08-13 定案 + Q18 细化）：值类型复制值；引用类型 move 所有权或为 global；**作用域例外**——作用域绑定的执行（await/join 后回到当前作用域）可捕获引用；可能逃逸的线程引用捕获禁用（防悬垂；≠闭包捕获 12.9）
- I/O 与并发抽象入标准库（Io 式接口）；线程为底层原语
- 静态并发安全标记（Send/Sync 式，Rust 第二）
- 事件循环式运行时仅作为脚本模式的库选项（TS 第三）
- 异步执行模型考虑 **Go 式协程 + 通道**（M:N 调度，2026-08-13 评审 B2 方向）——缓解「每个 async 任务一个 OS 线程」的线程爆炸；通道与四模式类型衔接，方向待细化

## 7. 元编程：脚本生成与 comptime 双轨（2026-08-13 评审修订）

- **脚本生成**：`script` 作用域标注脚本代码，编译前由脚本解释器执行并生成代码（对应 Zig 的编译时生成，用脚本表达）；脚本用 H 编写（脚本模式运行），支持实时预览与校验
- **脚本 = H 核心子集**（评审 B1）：在特定分配器、特定 IO 下运行，尽可能与 H 核心一致；若摩擦过大，后续可定义受限子集——脚本生成**必须实现**（核心特性）
- **comptime**：语言内保留（泛型/类型级计算，ADR-0006 修正）
- 分工：comptime 管类型级计算（泛型、类型即值、comptime_int）；脚本生成管样板与数据定义驱动代码生成——**「数据定义 → 样板」场景下脚本功能可选**（评审 A4，comptime 可承担生成）
- 无宏（12.22）

## 12. 语言特性清单（26 项，待逐项定义）

> 以下 26 项为语言特性清单。**状态说明**：`已定义` = 设计共识已确定，无需再议；`骨架已定` = 共识定了方向，细节待补；`待定义` = 由项目所有者逐项定义。每项标注参考语言的对应做法（按 Zig → Rust → TS 优先级）。

### 12.1 基础语法（部分定义）
C 风格（花括号、分号）；标识符 `snake_case`，类型 `PascalCase`。

**变量声明与指针**（项目所有者定义，2026-08-13；Rust 标杆修订同日）：
- `var mut x: o T = t;` — `var` 声明关键字；默认只读，`mut` 修饰可写（Rust 式，占位词可替换）；`:T` 类型标注（可推断时省略）；`o` 前缀 = **所有权注册在当前作用域**（作用域退出时销毁）
- `var x1: *T = &x;` — `*T` 只读指针类型；`&x` 取只读地址
- `var x2: *mut T = &mut x;` — `*mut T` 读写指针类型；`&mut x` 取可写地址（目标变量须可写）
- 无 `o` = 所有权注册在别处（如 arena 分配器统一分配/收回），本作用域不负责销毁；**无 o 变量禁止 move**（评审 A6）
- `global` 声明：根作用域上下文，静态生命周期，默认不可 move、无 `o`
- 作用域退出语句：`defer`（始终执行）/ `errdefer`（仅错误路径）——通用清理机制（Zig 式，见 12.18）

**已定（2026-08-13）**：`&`/`&mut` 匹配规则——`&x` 对只读/可写变量均合法（读权限可降级）；`&mut x` 仅对 `var mut` 变量合法；`&`/`&mut` 可作用于无 `o` 变量。唯一写者由**运行时登记**强制：同一变量同一时间最多一个可写引用，重复 `&mut` 运行时抛错（携带位置）。

**省略规则（2026-08-13）**：`:T` 中的 T 与 `*`/`*mut` 描述均可省略，由系统推断；**`o` 不参与推断**——由声明显式决定（写 = 本作用域拥有；不写 = 所有权在别处）。例：`var mut x: o = t;`（拥有、可写、类型推断）。

**已定（2026-08-13）**：`move` 参数在函数内隐含拥有（见 12.5）；所有权语法（`o`/`move`/`*`/`*mut`/`&`/`&mut`/`global`）全部定案。

### 12.2 运算符（已定义，2026-08-13）
- 算术 `+ - * /`；复合赋值 `+= -= *= /=`
- 除模：`/` 截断除法；`%` 截断取余；`%%` 欧几里得取模（结果非负）
- 逻辑：关键字 `and`/`or`/`!`（不用 `&&`/`||` 符号，避免与位运算视觉混淆）
- 比较 `== != < <= > >=`：严格相等，无双轨（TS 式 `==`/`===` 不采纳）
- 位运算 `& | ^ ~ << >>`；范围 `..`（切片取段）
- 解引用：显式 `p.*`（无自动解引用）
- optional 解包：`x orelse 默认值`；`x.?` 显式断言解包（空则运行时错误带位置）
- 运算符重载：无（与「没有隐藏控制」一致）

### 12.3 数据类型（已定义，2026-08-13）
类型集（Zig 第一）：

| 类别 | 类型 |
|---|---|
| 整数 | `iN`/`uN`（i8–i128、u8–u128）+ `isize`/`usize` |
| 浮点 | `f16`/`f32`/`f64`/`f128` |
| 布尔/空 | `bool`、`void` |
| 复合 | 数组 `[N]T`（**引用类型**，评审 B3）、切片 `&[T]`/`&mut [T]`（Rust 式） |
| 可选 | `?T`（使用前显式解包） |
| 结构体/枚举 | 见 12.12/12.13 |
| 字符串 | 字面量 → `r []u8` 静态视图（12.19 细化） |

- 字面量惰性宽度：comptime_int / comptime_float（Zig 式，2026-08-13 随 comptime 保留恢复完整语义）
- **显式初始化**：变量必须显式初始化，无默认零值（「没有隐藏控制」）
- 泛型 = comptime 式；样板 = 脚本生成（见 §7/12.16）

### 12.4 注释（已定义，2026-08-13）
- `//` 行注释；`///` 文档注释（关联声明，驱动 M8 文档生成）；`/* */` 块注释
- ⚠️ **偏离 Zig 第一**（Zig 刻意无块注释）：项目所有者选择保留块注释（2026-08-13）

### 12.5 函数（部分定义）
函数是有名字的作用域（见 §4）；传参规则：标量/纯值 struct 默认复制，数组/集合/复杂类型为引用类型（传引用，复制需显式），其它对象只能引用/move。

**参数与返回值**（项目所有者定义，2026-08-13）：
- `fn fun(move y: *mut T) void {}` — `move` 表示函数接受带所有权的可读写变量 y，所有权随调用转移
- **move 规则**：仅带 `o`（本作用域拥有）的变量可 move；参数传入与返回值同理。**`move` 参数在函数内隐含拥有**（2026-08-13 定案）：所有权转移进函数即由函数作用域管理，退出自动销毁——函数内 y 等价 `o *mut T`
- **move 与 `*`/`*mut` 正交**：move 只管所有权；`*`/`*mut` 描述指针类型（只读/可读写）——`move y: *T` 允许
- 非 move 参数 `y: *mut T` / `y: *T` 为借用（调用方保留所有权）
- **返回值规则**（细节待后续讨论）：函数内新建的值必须 move 返回（无所有权的除外）；返回引用必须是指向函数参数（只读/读写参数）的引用，不得返回局部变量的引用（悬垂防护）
- 返回值语法（已同意）：`fn() oT`（拥有）/ `fn() *T` / `fn() *mut T`（引用）
- **权限标注模型**（2026-08-13，评审 D2；Rust 标杆修订）：类型标注 = 类型 + 读写权限（`*`/`*mut`）+ 所有权（o）；move 基于所有权判定（有 o 才能 move），与读写权限同属统一权限体系；comptime 函数返回类型（`fn List(T: type) type`）不适用运行时 move 规则

**所有权语法已全部定案（2026-08-13，Rust 标杆修订）**：`o`/`move`/`*`/`*mut`/`&`/`&mut`/`global` 及省略规则、move 隐含拥有。

### 12.6 条件语句（已定义，2026-08-13）
- `if` 是**表达式**：`var x = if (c) a else b;` — 作表达式时 **else 强制**（保证确定值，呼应显式初始化）；作语句时 else 可选
- `if (opt) |v|` 捕获 optional（配合 12.3 的 `?T`）
- switch 穷举匹配见 12.13

### 12.7 循环（已定义，2026-08-13）
- `while (cond) {}`；续步表达式：`while (i < n) : (i += 1) {}`（替代 `for` 的更新子句）
- `for (items) |item| {}` — 数组/切片迭代，捕获默认只读；可写捕获 `for (items) |mut item|`（2026-08-13，评审 B5 + Rust 标杆统一）
- 无 `do-while`、无 `loop` 关键字（用 `while (true)`）
- `break`/`continue` + 带标签 `break :label` / `continue :label`（嵌套退出）

### 12.8 迭代器（已定义，2026-08-13）
- `for` 支持数组/切片直通；任何实现「迭代特性」（12.16）的类型可参与 `for` 迭代（`for` 语法不变，底层走特性）
- 标准库提供迭代器对象：`arr.iter()` — **迭代器是显式数据对象**，可传递、可组合
- 变换**立即求值**（TS 式）：`arr.iter().filter(...).map(...)` 每步产出新数据对象
- 惰性适配器不进入 1.0（求值时机隐藏，与「没有隐藏控制」张力最大）；作为 1.x 性能通道

### 12.9 闭包（已定义，2026-08-13）
Zig 无闭包，按参考规则取 Rust 第二；捕获模式与 H 语法体系对齐：

- 捕获模式**显式标注**（粒度 = 整个闭包）：默认只读捕获全部环境；`mut |x| ...` 提升为可写捕获（Rust 标杆）；`move |x| ...` 转移捕获——捕获模式在声明处可见（无隐藏）
- 调用语法：`f(x)` 直接调用（对数据对象做「调用」操作）
- 闭包是**数据对象**：捕获为字段的结构体 + 调用约定；遵循所有权模型（可 `o`、可 move、捕获随闭包销毁）
- 单变量粒度捕获留 1.x
- 闭包类型标注与「特性」（12.16）联动

### 12.10 所有权（已定义）
见 §4 内存模型（作用域所有权、move、销毁责任）。语法形式：`o` 类型前缀（拥有）、`move` 参数（转移所有权）、`*T`/`*mut T`（引用），见 12.1/12.5。

### 12.11 切片（已定义，2026-08-13；Rust 标杆修订同日）
切片 = `*T`/`*mut T` 的带位置与长度形态，**Rust 式类型** `&[T]`（只读）/ `&mut [T]`（可写），对连续内存的**视图**，**不拥有数据**（无 `o`）：

- `var s: &[T] = &arr[1..3];` — 只读切片；`var s2: &mut [T] = &mut arr[1..3];` — 可写切片
- 操作与 `*T`/`*mut T` 完全一致：双向注册、悬垂检测、唯一写者（同一底层数组同一时间最多一个可写切片，运行时登记）
- `move` 只针对切片所在的定长数组（`o [N]T`），不针对切片本身
- 取切片视图：`&arr[start..end]` → `&[T]`；`&mut arr[start..end]` → `&mut [T]`（`..` 范围含首不含尾）
- 数组 `[N]T` = **引用类型**（评审 B3）：可有 `o`、可被切片；复制需显式
- 传参：与指针规则一致——参数 `&[T]`/`&mut [T]`，无「视图例外」；切片含指针，属「其它对象」而非数据栈对象
- 字符串字面量 → 静态只读切片 `&[u8]`（无 `o`、不可 move；细节归 12.19）

### 12.12 结构体（已定义，2026-08-13；同日修订：纯值化）
「定义数据」支柱的核心。Zig 式：匿名类型、值语义、无继承（组合优于继承）：

- 底层是连续内存（实质是**字节数组**）——**纯值类型**
- 字段只含：标量、struct、定长数组、切片（均内嵌字节，布局连续）；**不含复杂类型字段**（堆数据一律进复杂类型）
- 字段默认只读，`mut` 修饰可写字段（Rust 标杆）；写字段需持有结构体的可写引用（`*mut`）
- 数据栈对象判定：字段全为标量 → 可复制传参；**含数组/切片字段（引用类型）→ 归其它对象**（只能引用/move，2026-08-13 评审 B3 收紧）
- 方法 = 结构体声明的函数成员（Zig 式，无 `impl` 关键字）：`struct Point { x: f32, y: f32, fn dist(a: *Point, b: *Point) f32 }`
- 与 12.20 组合：结构体是「组合优于继承」的基础

### 12.13 枚举类（已定义，2026-08-13）
「定义数据」支柱的类型构造，**合一式**（Rust 式变体 + Zig 式捕获语法）：

- `enum Value { int: i32, float: f64, none }` — 变体可选负载；纯常量枚举 = 变体均无负载的特例
- switch 穷举：漏分支编译期报错；负载捕获沿用 `|x|` 惯例
- 数据栈对象自动判定：负载全为值类型 → 可复制；含引用 → 只能引用/move（与结构体一致）
- 变体负载含复杂类型/数组时，枚举实例归其它对象（2026-08-13，评审 D3 延伸）

见 §8（文件级模块 + `pub` 导出；包管理器内置编译器；官方注册中心）。

### 12.15 错误处理（已定义）
见 §5（error union + 显式错误集 + `try` 传播；无异常）。

### 12.16 泛型和特性（已定义，2026-08-13 重构）
- **泛型 = comptime 式**：`fn List(T: type) type`、`anytype`、类型即值、惰性实例化（Zig 式，2026-08-13 保留）
- **脚本生成**（§7）负责样板与数据定义驱动的代码生成（序列化/校验/存储）
- **分工已确认**（X1，2026-08-13）：comptime 管类型级计算；脚本生成管样板代码生成
- **接口（特性）** = 类型的**特性标**（2026-08-13，评审 A1）：声明类型必须实现的方法契约——`interface A { fn a(t: *mut T) }`；类型显式声明实现（implements 标注，具体形式待定）；可描述复杂类型、标量类型、内建类型、用户 struct
- 接口用于约束与组合（12.20）；闭包「调用契约」、迭代「迭代契约」均为接口实例
- **接口不提供运算符重载**（12.2 已定）
- 「数据定义 → 样板」场景下脚本功能**可选**（评审 A4：comptime 可承担生成；脚本为 H 核心子集，见 §7）

### 12.17 生命周期（已定义，2026-08-13）
- 生命周期单元 = **作用域**（所有权注册处，退出即销毁）
- 悬垂防护 = **双向引用注册**（Debug 抛错带位置、Release 裸读用户负责）
- **无显式生命周期标注**（`'a` 式不进入语言）：接口/复杂类型的生命周期契约用文档约定，缺角由 Debug 检测兜底；若 1.0 暴露真实痛点，再以精简版演进（单一路径哲学）

### 12.18 文件与 IO（已定义，2026-08-13）
- **IO 是类型（类似 Allocator）**：需要 IO 功能的函数必须**显式传递** `io` 参数——无全局/隐式 IO（「没有隐藏控制」）
- `io` 是接口（12.16）：`Io` 接口 + 标准库实现（`Io.Threaded`、`Io.Evented` 等）
- 文件句柄关闭：**defer 式**——`defer f.close()` 保证作用域退出时关闭（清理动作在创建处显式可见，不用隐式析构）；`errdefer` 仅在错误返回路径执行
- `defer`/`errdefer` 是通用作用域退出语句（Zig 式），不限于 IO
- 错误一律 error union（无异常）；同步默认，事件循环式运行时为脚本模式库选项
- 双模式下同一套 IO 标准库行为一致
- 字节为中心：`r []u8` 视图 + 文本编码函数（UTF-8 优先）

### 12.19 集合与字符串（已定义，2026-08-13）
- 集合/字符串 = **复杂类型**（class 家族）：堆上、组合、接口描述功能（12.20/12.16）；**集合为引用类型**（评审 B3）：传参走引用，复制需显式；**String 例外——默认值复制**（2026-08-13 Q16 定案：堆上复杂类型但传参深拷贝语义）
- 泛型集合 **comptime 式实例化**（2026-08-13 修正，X1 连带）：`Vec(T)` 由编译期机制实例化——**双模式一致**（编译模式编译期实例化、脚本模式执行前实例化，机制同一）
- **语言无内建字符串**：字面量 = 静态只读切片（`r []u8`，见 12.11）；可变字符串 = 标准库 `String` 复杂类型（借 `class` 定义，接口描述 UTF-8 等能力）
- 集合接口：迭代契约（12.8）+ 序列化契约（定义数据）等
- 主要集合：`Vec`、`Map`、`Set`、`Deque`（04-stdlib-scope 细化）

### 12.20 面向对象和组合（已定义，2026-08-13）
- **复杂类型** = 组合 + 接口，**无继承**：`class`（通用堆对象）、`tree`（递归/层级结构）等关键字声明（1.0 最小集，家族可扩展）
- `tree` = 递归组合：节点含子节点集合，父子所有权层级化（父 `o` 拥有子）——JSON/配置/文档树形态
- 成员：字段（标量/struct/其它复杂类型，可带 `o`）+ 方法（Zig 式函数成员，同 12.12）+ **显式接口实现**（12.16）
- 构造 = 普通函数返回实例（无特殊构造语法，Zig/Rust 式）；脚本生成为常用构造提供样板（`Foo.new(...)`）
- **无隐式析构**：资源清理走 `defer`（F1 已定）
- 组合优于继承（Zig 第一）

### 12.21 并发编程（已定义，2026-08-13）
- 共享状态：四种线程访问模式类型 `OneToOne(T)`/`OneToMany(T)`/`ManyToOne(T)`/`ManyToMany(T)`——内建泛型共享内存容器（脚本生成实例化），读前写后的命名顺序
- 线程所有权：spawn 归当前作用域；退出时已完成→销毁、运行中→移交根作用域（无隐式阻塞）；显式 `t.join() !T`（消耗所有权，返回结果与 error union 错误）
- 线程捕获：值类型复制；引用类型 move 或 global（无只读引用捕获；≠闭包捕获 12.9）
- 同步原语：由四模式类型族承担（Mutex 式语义并入 `ManyToMany` 等）
- 线程 = 复杂类型数据对象（12.24）；Send/Sync 式静态标记
- 根作用域 = 程序最后退出场所（评审 A7）：负责最终资源回收；global 定义于此；后期线程池亦于此

### 12.22 消失的宏和替代方案（已定义，2026-08-13）
- **宏不进入语言**（与「没有隐藏控制」一致）
- 替代方案 = **脚本生成**（§7/12.16）：`script` 作用域在编译前/执行前生成代码，覆盖宏的典型用途（样板生成、类型构造、代码注入）
- Rust 式宏（第二参考）不采纳；声明宏/过程宏的需求由脚本生成统一承接
- 与 TS（第三参考）一致：无宏

### 12.23 异步编程（已定义，2026-08-13 逆转）
- **async/await 是语言关键字**（逆转此前 Zig 式无关键字决策；偏离 Zig 第一，取 Rust/TS 式）
- `async fn f(...) T` 返回 `Future(T)`；`await f` 等待完成（函数级标记，Rust/TS 惯例）
- **执行语义 = 线程默认**：`async` 函数 = 线程任务（`Io.Threaded`），`await` 等待线程结果（与 `t.join()` 同源）；事件循环（Evented）为可选运行时实现，接口不变
- `Future(T)` = 异步任务结果句柄（复杂类型），基于线程任务；错误以 error union 传播
- 关联 12.21（await 与 join 语义同源）、12.24（线程是数据对象）
- 执行模型考虑 **Go 式协程 + 通道**（M:N 调度，评审 B2 方向）——缓解「每个 async 任务一个 OS 线程」的爆炸风险；方向待细化

### 12.24 多线程模型即数据对象（已定义，2026-08-13）
- **线程 = 数据对象**（H 特有）：`Thread` 是复杂类型（class），可定义、move 传递、join 消耗
- 所有权规则：spawn 归当前作用域；退出时已完成→销毁、运行中→移交根作用域
- `t.join() !T` 消耗所有权获取结果（错误跨线程以 error union 传播）
- **接口契约**：`interface Thread(T)` — `join() !T`、`cancel() !void`、`is_done() bool`
- **detach()**：消耗所有权、显式放弃结果（线程继续运行，由根作用域回收）——与 join、作用域退出移交三种路径覆盖线程生命周期
- 线程捕获规则见 12.21；与四模式类型的组合用法（如 `ManyToMany(T)` 承载线程间共享）

### 12.25 语言库和系统依赖（已定义，2026-08-13）
- 工具链单二进制自带构建组件（`hc build`/`hc cc`，见 M8）；**系统库工具链自带**（内置 libc 等，零依赖跨编译，Zig 式）——不依赖宿主系统环境
- **静态链接默认**（交付独立二进制），动态链接为显式选项
- 项目依赖（包 + 系统库）写入显式清单（`build.zon` 式），构建时校验版本与指纹
- 构建环境可复现、无隐藏系统依赖（「没有隐藏控制」在构建层的兑现）
