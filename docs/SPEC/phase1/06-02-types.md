# H 语言规范：基础类型

> 对应实现模块：07 第一块语言系统 M2 语义。扩展类型（class/枚举/元组/Table/String）见 `06-03-extended-types.md`；接口族见 `06-05-interfaces.md`。

## 类型总表

| 类别 | 语法 |
|---|---|
| 整数 | `iN`/`uN`（i8–i128、u8–u128）+ `isize`/`usize`——**实现 `IInt`/`IUint`**（2026-08-14 定案） |
| 浮点 | `f16`/`f32`/`f64`/`f128`——**实现 `IFloat`**（2026-08-14 定案） |
| 布尔/空 | `bool`、`void` |
| 数组 | `[N]T`（定长，**引用类型**：传引用、复制需显式） |
| 表格 | `Table(T)`（2026-08-14：内建二维结构，代替 `[M][N]T`；见 06-03） |
| 元组 | `(T1, T2, ...)`（2026-08-14：匿名值类型；见 06-03） |
| 切片 | `&[T]` / `&mut [T]`（Rust 式，带位置与长度的指针视图） |
| 可选 | `?T`（使用前显式解包） |
| 错误联合 | `E!T` / `!T`（error union，见 06-07） |
| 函数 | `fn(参数) 返回类型`（见 06-04） |
| 泛型 | comptime 式（见 06-09） |

**数据栈对象判定**：标量、连续类型（字段全为值类型）→ 可复制传参；数组、集合、Table、复杂类型、含数组/切片字段的类型 → **引用类型**（传参走引用，复制需显式 `copy`，评审 B3）。

## 标量

- 内建标量类型实现数字接口族（编译器内建实现，不可重载）：`i8–i128`/`isize` → `IInt`；`u8–u128`/`usize` → `IUint`；`f16–f128` → `IFloat`（接口定义见 06-05）
- **相等 `==`/`!=` = 语言内建通用**（标量按值）；**序比较 `< <= > >=` 绑定 `ICompare`**（经 `INumber : ICompare` 继承）
- 算术/位运算符绑定 INumber 族（`a + b` ≡ `a.add(b)`，见 06-01 运算符）
- 字面量惰性宽度：comptime_int / comptime_float（使用处定型）；字符 `'x'` = comptime_int
- 整数溢出按模式（Debug 检测 / Release wrap）；显式 `@addWithOverflow` 等（见 06-04）
- `bool`：`and`/`or`/`!` 关键字操作；`char` 无独立类型（字符 = 字节/码点）；`void` 仅函数返回

## 数组与切片

- `[N]T` 定长数组：**引用类型**（传参走引用、复制需显式 `copy`）；`[1, 2, 3]` 字面量（Q4 推断式）；可作字段内嵌（连续类型字段集含定长数组，2026-08-14）
- `&[T]` / `&mut [T]` 切片：**带索引位置和长度的指针**（H4 定案）——`*T`/`*mut T` 指针 + 起始索引 + 长度，对连续内存的**视图**，**不拥有数据**（无 `o`）；**数组的引用默认就是切片**（`&arr` 直接产生切片（起始 + 长度），无需显式取段）；`&arr[1..3]` 指定范围
- 操作与指针一致：多切片自由、指针问题用户负责、Debug 悬垂标记可选；move 只针对底层数组
- 字符串字面量 → 静态只读切片 `&[u8]`（无 `o`、不可 move；String 内建新类型见 06-03）
- 比较：数组/切片 `==` 经 `ICompare`（编译器内建：按值逐元素，H3 定案）；越界检查按模式（Q24）

## 可选值

- `?T`：可能没值；使用前显式解包——`x orelse 默认值` / `x.?` 断言（空则运行时错误带位置）/ `if (opt) |v|` 捕获 / `while (opt) |v|` 捕获
- 与 error union（`E!T`「可能出错」）**正交**
- **指针不可空**（Q16 定案）：`*T`/`*mut T` 无空态，空指针用 `?*T`/`?*mut T`；悬垂 ≠ null（悬垂是「曾指向有效对象后被销毁」的运行时状态，Debug 抛错带位置）

## 指针与引用

- `*T` 只读指针 / `*mut T` 可写指针：**不可空**（Q16）；**指针自由（Q-S11）**——多 `*mut`/`*T` 合法、`*mut` 可复制、**指针问题（悬垂/别名）由用户负责**（Zig 式）
- `&x` 只读地址（只读/可写变量均合法）；`&mut x` 可写地址（仅 `var mut` 变量）
- 解引用：`p.*` 显式取值；字段/索引访问自动解引用（`p.x`、`s[i]`，评审 A3）
- **临时引用生命周期（Q25 定案）**：表达式产生的临时 `*T`/`*mut T` 存活到所在完整表达式/语句结束；绑定到变量的引用存活到作用域结束
- Debug 悬垂标记：可选诊断工具（编译时选项；目标销毁时标记指向它的指针，访问提示带位置——非安全保证）
- 指针比较 `==`：按地址（通用相等）
