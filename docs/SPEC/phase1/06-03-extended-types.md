# H 语言规范：扩展类型（class / 枚举 / 元组 / Table / String / tree）

> 对应实现模块：07 第一块语言系统 M2 语义。2026-08-14 定案（struct/class 合并 + Continuous 内部化 + 元组 + Table）。

## 类型定义（class，2026-08-14 定案：struct/class 合并；H1 修订：特性标注）

```hc
[continuous]   // 特性标注：连续内存值类型（H1 定案）
class Point {
    x: f32,
    mut y: f32,                        // 字段默认只读，mut 修饰可写
    fn dist(a: *Point, b: *Point) f32   // 方法 = 函数成员（Zig 式，无 impl）；方法默认公开
}

class Foo { ... }   // 未标注 → 堆上（需分配器、接口、可 move）
```

- **统一关键字 `class`**（`struct` 删除）；**存储形态由特性标注决定**（H1 定案，取代自动判定）
- **特性标注语法（H1 定案）**：类型声明上方中括号 `[name]` / `[name(参数)]`——`[continuous]`（连续内存值类型，编译器验证字段全为值类型，否则编译错误）、`[pad]`（紧凑打包，原 packed）、`[align(T)]`（对齐到类型 T 的对齐值，如 `[align(u64)]` = 8 字节）；**多特性标注叠放（C5 定案）**：`[continuous] [pad]` 连续中括号行叠放，均作用于同一类型
- 连续类型能力：无分配器（栈/内嵌）、可内嵌、赋值即复制、`to_bytes`/`from_bytes` 直映射、字面量构造 `Point{x = 1.0, y = 2.0}`、`[pad]`/`[align(T)]` 布局控制
- 堆上类型能力：需分配器（构造 = `alloc.init(T)`——分配器按类型自动获取大小并创建实例 / `new()` 样板 / 普通函数返回）、`to_json`/`from_json`、字段可带 `o`、可 move
- **构造（L2/C1' 定案，2026-08-14）**：`alloc.init(T)` = 唯一通用构造，**两种形态**——**无参** `alloc.init(Foo)`（分配器按类型自动获取大小并创建实例，字段后续显式赋值——无默认零值、definite assignment 检查）；**带参** `alloc.init(Foo{字段 = 值, ...})`（类型字面量作构造器参数——分配 + 字段初始化）；**`X.new(...)` 样板取消**（不再需要；脚本生成 E1 只做定制样板）；`box()` 装箱值
- **成员可见性（Q3 定案）**：方法默认公开（`pub` 标注）；属性默认私有（`private` 标注，显式可选项）——`pub mut A: owned T`（pub 可见性 + mut 字段可写 +  `owned T` 字段类型形态分离）；**属性无所有权标注**（即使字段类型  `owned T`，所有权由类型实例管理，随实例销毁）
- 字段可含：标量/连续类型/元组/定长数组/切片/复杂类型（String/集合/class，Q2 裁定）
- **布局控制（Q-S5 定案；H1 修订）**：默认布局 = 平台 ABI 对齐（与 C 兼容）；`[pad]`——紧凑布局（仅连续类型；字段限：标量/枚举/连续内嵌/元组/定长数组）；`[align(T)]`——类型级对齐（如 `[align(u64)]` = 8 字节）；`to_bytes` 直映射尊重显式布局（`@offsetOf`/`@alignOf` 可验证）
- 写字段需持有实例的可写引用（`*mut`）；字段默认只读，`mut` 修饰可写
- 方法 = 类型声明的函数成员（Zig 式，无 `impl` 关键字）

## 复杂类型（堆上 class / tree）

```hc
class Foo { ... }   // 含引用/堆字段 → 自动堆上复杂类型（自动判定）
tree Node { ... }   // 递归/层级：节点含子节点集合，父 owned 拥有子
```

- 成员：字段（标量/连续类型/元组/其它复杂类型，可带 `o`）+ 方法（函数成员）+ 显式接口实现——成员与连续类型一致（Q22）
- 构造 = `new()` 样板（Q22：脚本生成）或普通函数返回实例；无特殊构造语法
- **无隐式析构**：资源清理走 `defer`
- 无继承，组合优于继承

## 枚举（合一式）

```hc
enum Value { int: i32, float: f64, none }   // 变体可选负载；纯常量枚举 = 变体均无负载
```

- switch 穷举（漏分支编译期报错）+ 负载捕获 `|x|`；`else` 兜底（Q31）
- **负载可为任意类型**（标量/连续/元组/引用/String/class，2026-08-14 定案）——含引用负载 → 自动堆上（自动判定）
- 数据栈对象自动判定：负载全为值类型 → 可复制；含引用 → 只能引用/move
- **枚举 ↔ 整数（2026-08-14 定案）**：`@intFromEnum(e) usize`（变体序索引，0 起）/ `@enumFromInt(E, i)`（反向，越界 Debug 检测 / Release 未定义值）；仅**纯常量枚举**可转换；带负载枚举不可（须 switch 匹配）；`@intCast` 不处理枚举
- 枚举 `==`：按标签（通用相等）

## 元组（2026-08-14 定案）

- 无名称、**初始化后字段只读**的匿名值类型（天然连续内存）：字面量 `(1, "a", 2.5)`、类型标注 `(i32, &[u8], f64)`、元素访问 `t.0`/`t.1`
- **支持解构**：`var (a, b, _) = t;`（`_` 占位符放弃值）；字段级只读（无 `mut`）
- **多值返回**：`fn divmod(a: i32, b: i32) (i32, i32)`；调用 `var (q, r) = divmod(a, b);`；`E!(T1, T2)` 合法（元组负载）
- **比较**：`==` 逐元素（通用相等延伸）；可作 `Map` 键（元组哈希）
- **序列化**：天然 `to_bytes`/`from_bytes`；可内嵌进 class 字段
- `@addWithOverflow` 等返回 `(T, bool)` 元组

## Table（2026-08-14 定案）

- 内建泛型二维结构 `Table(T)`，**代替二维数组**（`[M][N]T` 语法不再提供，一维数组保留）
- 构造：`Table(T).init(alloc, rows, cols, init)`（M8 定案：统一方法形态，与集合一致；`table(...)` 函数形态废弃）——**显式分配器**、行数、列数、填充初始值，**定长**（可变表路径：`init` + `var mut` 逐格赋值）
- **密封构造 `init_with`（2026-08-22 定案）**：`Table(T).init_with(alloc, rows, cols, cb)`——回调 `|i, j, cell: *mut T|`（cell = 单元格可写引用，`cell.* = v` 写格；元素本身可为指针：`Table(*mut T)` 时 `cell.* = &mut obj`），回调内可写单元格；**返回密封表**——编译期强制只读：直接 `t[i,j] = v`、复合赋值 `t[i,j] += v`、对密封表取 `&mut t` 均**编译错误**（与绑定声明无关）；只读操作（读 `t[i,j]`、行视图 `t[i]`、`&t`、`copy(t)`、迭代、to_bytes）全部可用；**不可解除密封**（无可变路径）
  - 背景：H 绑定级只读（默认只读 Rust 式）**文档已写但未实现**（语义层 `VarInfo` 无 `mut_`、仅 `check_ptr_write` 拦 `*T` 写穿 + 非 `mut` 闭包 `ReadonlyCapture`）——故 Table 用类型级密封补只读保证；全局绑定只读记 1.x 待办，J4 不做
- 访问：**`t[i, j]`** 单元格（行、列索引，M8 定案：仅 Table 类型合法的多参索引）；**`t[i]` 行视图**（2026-08-22 补全：返回切片 `&[T]`/`&mut [T]`，`t[i][j]` ≡ `t[i,j]`，`.len()` = 列数）；越界检查按模式（Q24）
- **写（2026-08-22 补全）**：单元格赋值 `t[i,j] = v`、复合赋值 `t[i,j] += v` 支持；**整行赋值 `t[i] = 行` 不支持**
- **迭代（2026-08-22 补全）**：`for x in t` 产出**扁平单元格**（行主序，元素 = T，IIterable 三态直接套用）；行用 `t[i]` / 嵌套 for
- **方法（2026-08-22 补全）**：`t.len()` = 行数、`t.cols()` = 列数（`rows()` 可选别名）；行视图 `.len()` = 列数；不提供 `.get/.set`（索引即语法）
- **序列化（2026-08-22 补全）**：to_bytes = **u64 LE 行数 + u64 LE 列数 + 行主序元素字节**；from_bytes 靠双维度前缀自描述恢复定长表
- **空表（2026-08-22 补全）**：0×N / N×0 / 0×0 均合法（与 `[0]T` 数组一致）；索引无符号（负索引编译错误）
- **引用类型**（与数组/集合一致：传参走引用、复制需显式 `copy`）；**底层 = 每行一个连续 `T[]` 数组，行主序**（2026-08-22 澄清「连续」：逻辑连续、非整表单缓冲；可 `to_bytes`）
- **泛型参数（2026-08-22 补全）**：T 可为任意类型（含指针）——`Table<T>` 拥有元素（非值类型元素需所有权）/ `Table<*T>` 存只读引用 / `Table<*mut T>` 存读写引用
- **指针元素（2026-08-22 补全）**：`t[i,j]` 返回元素指针；`Table<*T>` 经 `t[i,j].*` 只能读 pointee，`Table<*mut T>` 经 `t[i,j].*` 可写 pointee；**单元格指针替换**：密封表（`init_with`）一律不可替换（类型级强制）；普通表（`init`）当前允许（绑定级只读未实现，2026-08-22 确认），待 1.x 实现绑定级只读后按 `var mut` 门控；**只读指针表（不同指针）用 `init_with`**（回调内逐格赋 `&mut obj`）——比 `init` 单 seed 均匀网格干净；空指针表仍可用 `Table(?*mut T)` + `null` 填充
- **copy / 所有权（2026-08-22 补全）**：内建 `copy(t)` 深复制整表（所有行 + 元素，保留 alloc，`CopyMode.shallow` 可选）；作用域退出释放所有行数组；`move` 合法
- **嵌套（2026-08-22 补全）**：`Table(Table(T))` 合法（泛型递归，无需特判）
- 不提供 `==`（2026-08-14：显式遍历比较）；变长需求用集合组合（`Vec(Table)` 等）

## String（内建新类型，2026-08-14 M3 定案）

- **String = 内建新类型（newtype）**（M3 定案，取代「别名」表述）：底层布局 = `Vec(u8)`（编译器内建实现）；具体功能与 `Vec(u8)` 一致，数组/切片规则全部适用
- **零成本互转**：`as_slice()` 无前缀内容视图 `&[u8]`；字面量 = `&[u8]` 静态只读切片；String 与 `&[u8]` 经 `as_slice` / `String.from` 显式互转
- 构造：`String.from(&[u8], alloc)`（显式转换，分配是显式动作）/ `String.from_slice(&buf, arena)`
- 方法（04-stdlib-scope 细化）：concat / split / join / find ?usize / substring / replace / to_upper / `to_bytes()`（带 u64 前缀序列化）/ `==` 内容比较（经 ICompare，内建）
- 编译器内建实现 `ICompare`（内容序，2026-08-14）；拼接走方法 `s.concat(other)`（Q28，无 `+` 重载）
