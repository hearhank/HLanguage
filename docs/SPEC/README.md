# H 语言 1.0 实现计划（SPEC）

> 状态：已与项目所有者达成设计共识（2026-08-12）。本文档是 H 语言从 0 到 1.0 的实现计划总纲，后续所有修改同步更新到本目录下的 SPEC 文件。

## 项目定位

H 是一门**以数据为中心**、同时支持**系统编程与脚本编程**的编程语言，源码后缀 `.hc`。核心哲学：语言的职责是「**定义数据、修改数据、传输数据、保存数据**」，一切语言特性围绕这四项第一性原则组织。同一份源码既可编译为原生二进制，也可作为脚本解释执行，两种模式语义一致。

- **定位**：严肃长期项目，对标 Zig/Go，欢迎社区参与
- **参考优先级**：Zig → Rust → TypeScript（`docs/adr/0001-reference-policy.md`）
- **初始实现**：Rust（`docs/adr/0002-initial-compiler-in-rust.md`）

## 1.0 的定义

达成 1.0 需全部满足（沿用 Zig 官方 1.0 前置清单）：

1. **语言冻结**：不再有语言层面的变更
2. **语言规范初稿**完成并通过评审
3. **官方包管理器**可用
4. **标准库**（四大支柱）API 稳定
5. **完整经历一个发布周期**且无破坏性变更
