# 协程 + 通道实现计划（M:N 调度 + `chan<T>`）

> 对应 ADR-0024。重构 H 语言并发模型：从「OS 线程 + 四模式容器」到「M:N 协程 + 单一通道」。

## 整体架构

```
┌─────────────────────────────────────────────────┐
│                  H 用户代码                        │
│  spawn(f, args...)  │  ch.send(v)  │  ch.recv()  │
├─────────────────────────────────────────────────┤
│                 运行时调度器 (hc-rt)                │
│  ┌──────┐  ┌──────┐  ┌──────┐                    │
│  │  P   │  │  P   │  │  P   │  ← GOMAXPROCS 个   │
│  │ G队列│  │ G队列│  │ G队列│                     │
│  └──┬───┘  └──┬───┘  └──┬───┘                    │
│     │         │         │                         │
│  ┌──▼───┐  ┌──▼───┐  ┌──▼───┐                    │
│  │  M   │  │  M   │  │  M   │  ← OS 线程          │
│  └──────┘  └──────┘  └──────┘                    │
├─────────────────────────────────────────────────┤
│           LLVM 后端 / IR 后端 / 解释器             │
└─────────────────────────────────────────────────┘
```

| 1e 镜像到 hc-tools | 20min | hc-tools 对应文件 | 编译通过 |

**API**：
```hc
// 无缓冲通道
var ch = chan<i32>.init(alloc);
ch.send(42);
var v = try ch.recv();

// 有缓冲通道（容量 16）
var ch = chan<i32>.init(alloc, 16);
ch.send(42);
var v = try ch.recv();

// 非阻塞操作
var ok = ch.try_send(42);    // bool
var v = ch.try_recv();       // ?T
ch.close();
```

**G 状态机**：
```
  ┌──────┐  spawn   ┌─────────┐  调度器  ┌────────┐
  │ 新建  │ ──────→ │  就绪   │ ──────→ │  运行  │
  └──────┘          └─────────┘         └───┬────┘
       ↑                                    │
       │                              send/recv
       │                              (通道阻塞)
       │                                    │
       │                              ┌─────▼─────┐
       │                              │   等待    │
       │                              │(通道等待队列)│
       │                              └─────┬─────┘
       │                                    │
       │                              通道就绪
       │                              (唤醒)
       │                                    │
       │                              ┌─────▼─────┐
       └──────────────────────────────│   完成    │
                                      └───────────┘
```
