# H 语言规范初稿（Draft）

> 状态：**初稿**（2026-08-13）。汇总 25 项已定义特性的语法与语义，作为编译器实作的依据；M9 将在此基础上产出正式语言规范。未定义项见文末「待定」。
> 术语定义以 `CONTEXT.md` 为准；设计依据见 `01-language-design.md` §12 与 `docs/adr/`。

## 1. 词法

- 文件后缀：`.hc`
- 语法风格：C 风格（花括号、分号）
- 标识符：`snake_case`；类型名：`PascalCase`
- 注释：`//` 行注释；`///` 文档注释（关联声明，驱动文档生成）；`/* */` 块注释
- 数字字面量：无固定宽度（comptime_int / comptime_float），使用处定型，超范围编译期报错
- 字符串字面量：静态只读切片 `&[u8]`（静态存储、无 `o`、不可 move）
- 变量**必须显式初始化**，无默认零值

## 2. 声明

### 变量

```
var [mut] name: [o] [* | *mut] T = init;
const Name = 值;      // 常量/类型别名（Q12 定案：const 不可变，var mut 可变）
```

| 记号 | 语义 |
|---|---|
| `var` | 声明关键字 |
| `mut` | 可写修饰；**默认只读**（Rust 式，占位词可替换） |
| `o` | 所有权注册在当前作用域（退出销毁）；**默认规则**（Q16）：复杂类型（分配器创建）除 Arena 外默认拥有（o 隐含）；Arena 分配无所有权；无 `o` 禁止 move |
| `*` / `*mut` | 只读 / 可写指针类型 |
| `T` | 类型；**T 与 `*`/`*mut` 可省略**（系统推断），`o` 不可省略推断 |

示例：

```hc
var mut x: o *mut T = t;   // 全写：可写、拥有、类型 T
var mut x: o *mut = t;     // 类型推断
var mut x: o = t;          // 类型与 *mut 推断，o 显式
var x1: *T = &x;           // 只读指针、类型推断
var a = arena.alloc(T);    // 无 o：所有权在 arena（禁止 move）
```

- `global`：根作用域上下文，静态生命周期；默认不可 move、无 `o`
- `void`：无类型（函数返回）

### 类型

| 类别 | 语法 |
|---|---|
| 整数 | `iN`/`uN`（i8–i128、u8–u128）+ `isize`/`usize` |
| 浮点 | `f16`/`f32`/`f64`/`f128` |
| 布尔/空 | `bool`、`void` |
| 数组 | `[N]T`（定长，**引用类型**：传引用、复制需显式） |
| 切片 | `&[T]` / `&mut [T]`（Rust 式，带位置与长度的指针视图） |
| 可选 | `?T`（使用前显式解包） |
| 错误联合 | `E!T` / `!T`（error union） |
| 函数 | `fn(参数) 返回类型` |
| 泛型 | comptime 式（见 §9） |

**数据栈对象判定**：标量、纯值 struct（字段全为标量）→ 可复制传参；数组、集合、复杂类型、含数组/切片字段的 struct → **引用类型**（传参走引用，复制需显式 `copy`，评审 B3）。

### struct（值类型）

```hc
struct Point {
    x: f32,
    mut y: f32,                        // 字段默认只读，mut 修饰可写
    fn dist(a: *Point, b: *Point) f32   // 方法 = 函数成员（Zig 式，无 impl）
}
```

- 底层连续内存（字节数组），**纯值**：字段只含标量/struct/定长数组/切片，不含复杂类型字段
- 写字段需持有结构体的可写引用（`*mut`）

### enum（合一式）

```hc
enum Value { int: i32, float: f64, none }   // 变体可选负载；纯常量枚举 = 变体均无负载
```

- switch 穷举（漏分支编译期报错）+ 负载捕获 `|x|`

### 复杂类型（class / tree）

```hc
class Foo { ... }   // 通用堆对象
tree Node { ... }   // 递归/层级：节点含子节点集合，父 o 拥有子
```

- 成员：字段（标量/struct/其它复杂类型，可带 `o`）+ 方法（函数成员）+ 显式接口实现——**成员与 struct 完全一致**（Q22）
- 构造 = `new()` 样板（Q22：脚本生成，12.20）；无特殊构造语法
- **无隐式析构**：资源清理走 `defer`
- 无继承，组合优于继承

### 接口

接口 = 类型的**特性标**（评审 A1）：声明类型必须实现的方法契约。

```hc
interface Shape {
    fn area(self: *Self) f32;   // self = 实现类型的实例；Self = 实现类型（Q14）
}

struct Rect: Shape { ... }      // implements 标注 = 冒号后缀（Q14）
class Foo: Shape, Drawable { ... }
```

- **显式声明实现**（冒号后缀，Q14）；可描述复杂类型、标量、内建类型、用户 struct
- 不提供运算符重载
- 闭包「调用契约」= 内置调用接口类型 `FnN(参数) 返回`（Q13）
- 方法调用双语：`p.dist(q)` ≡ `Rect.area(p)`（Q5，接收者自动取引用）

## 3. 运算符

| 类别 | 记号 |
|---|---|
| 算术 | `+ - * /` |
| 除模 | `/` 截断除法；`%` 截断取余；`%%` 欧几里得取模（非负） |
| 逻辑 | `and` `or` `!`（关键字，非符号） |
| 比较 | `== != < <= > >=`（严格相等，无双轨） |
| 位运算 | `& \| ^ ~ << >>` |
| 范围 | `..`（切片取段） |
| 解引用 | `p.*` 显式取值；**字段/索引访问自动解引用**（`p.x`、`s[i]`，评审 A3） |
| 取地址 | `&x` 只读地址（只读/可写变量均合法）；`&mut x` 可写地址（仅 `var mut` 变量） |
| optional | `x orelse 默认值`；`x.?` 显式断言解包（空则运行时错误带位置） |
| 复合赋值 | `+= -= *= /=` |
| 重载 | **无** |

- **越界检查按模式**（Q24）：Debug 运行时检查（抛错带位置）、Release 裸性能；编译期可证越界（`arr[10]` 对 `[5]i32`）所有模式编译期报错
- **字符串拼接走方法**（Q28）：`s.concat(other)` ≡ `String.concat(a, b)`——无 `++` 运算符、无 `+` 重载（函数 = 唯一处理逻辑）

## 4. 语句与控制流

```
if (cond) a else b            // if 是表达式；作表达式时 else 强制，作语句时可选
if (opt) |v| { ... }          // optional 捕获
switch (v) { int => |i| ..., none => ... }   // 穷举 + 负载捕获；**也是表达式**（Q27）；**else 兜底**（Q31：有 else 免穷举，无 else 强制穷举）
while (cond) { ... }
while (i < n) : (i += 1) { ... }   // 续步表达式
for (items) |item| { ... }           // 数组/切片迭代，捕获默认只读
for (items) |mut item| { ... }       // 可写捕获（评审 B5 + Rust 标杆）
for (0..10) |i| { ... }              // 区间糖（Q29：复用 .. 记号，底层仍是 while）
break :label / continue :label     // 带标签退出嵌套
defer expr / errdefer expr         // 作用域退出执行；errdefer 仅错误路径
```

- 无 `do-while`、无 `loop`（用 `while (true)`）

## 5. 函数与闭包

```hc
fn main(io: Io) !void {}   // 入口：io 显式传入（Q1）；!void 入口错误运行时报告
fn fun(move y: *mut T) void {}        // move：接受带所有权的可读写变量
fn f(x: &[u8]) !i32                   // 返回 error union
async fn af() T                       // 返回 Future(T)
var hp: o *mut Point = box(p, alloc); // 装箱：值 → 堆引用（Q8，显式分配器）
```

- **参数**：数据栈对象默认复制；其它对象只能 `*`/`*mut`/`move`
- **move 规则**：仅带 `o` 的变量可 move；`move` 参数在函数内隐含拥有（函数作用域接管，退出销毁）；`move` 与 `*`/`*mut` 正交（`move y: *T` 允许）；**调用点显式 `move`**（Q23）：`take(move s);` / `return move s;`——所有权转移在调用点可见
- **权限标注模型**（评审 D2）：类型标注 = 类型 + 读写权限（`*`/`*mut`）+ 所有权（o）；move 基于所有权判定，与读写权限同属统一权限体系；comptime 函数返回类型不适用运行时 move 规则
- **返回值**：`fn() oT` 返回拥有（所有权移出）；`fn() *T` / `*mut T` 返回引用；函数内新建的值必须 move 返回（无所有权的除外）；返回引用必须指向函数参数，不得返回局部变量引用
- **闭包**：`|x| expr` 默认只读捕获；`mut |x| ...` 可写捕获（Rust 标杆）；`move |x| ...` 转移捕获（粒度=整个闭包）；调用 `f(x)`；闭包是数据对象（捕获为字段）
- 方法 = 类型声明内的函数成员

## 6. 所有权与内存

- **作用域** = 无名字的函数；函数 = 有名字的作用域；所有权注册在作用域上，退出自动销毁
- **move**：仅带 `o` 可 move；无 `o` 变量（所有权在分配器/arena）**禁止 move**（move 须对整个分配器进行）；转移后目标作用域负责销毁
- **引用**：
  - `*T` 只读指针：可选双向注册（编译期选项）——Debug 默认注册（悬垂抛错带位置）、Release 默认裸读（用户负责）
  - `*mut T` 可写指针：强制双向注册；**唯一写者由运行时登记强制**（同一变量同一时间最多一个，可写包含可读）；**不可拷贝，只能 move 传递**（评审 A5）
- **运行时错误**（评审 A2）：悬垂访问/唯一写者冲突 = **不可恢复运行时错误**（与 error union 可恢复错误正交）
- **o 默认规则**（Q16）：非 Arena 分配器创建的复杂类型默认拥有（作用域接管、退出自动销毁，无需显式 o/deinit）；Arena 例外（统一销毁）；`defer` 管非内存资源（文件等）
- **String 值语义**（Q16）：堆上复杂类型但默认值复制（传参深拷贝）
- **Allocator**：显式传递为主，未传回退**默认分配器**（Q8/Q16：根作用域的 global，全局可引用；每线程独立实例——线程创建自己的根上下文）
- **defer/errdefer**：资源清理（不用隐式析构）
- **无 GC**：双模式同一套模型
- **生命周期**：单元 = 作用域；无显式生命周期标注

## 7. 模块与包

- **命名空间组织**（Q21，C# 式）：`namespace Math { ... }` 块式分组（可跨文件、一文件多组）；`using Math;` 引入（限定访问与直接使用）；文件 = 物理单元
- `pub` 管包边界（同包 using 即达；跨包需 pub + 依赖声明）
- 包管理器内置编译器；**依赖清单 = H 数据字面量**（Q26）：`const build = Build{ name = ..., deps = [...], ... }`（构建时校验版本与指纹）
- 官方注册中心

## 8. 错误处理

- error union（`E!T`）+ 显式错误集（`error{...}`）+ `try` 传播——**可恢复错误**
- **`anyerror`**（Q34）：任意错误类型，仅用于**接口方法契约**（实现方决定具体错误集）；普通函数仍用显式错误集
- **不可恢复运行时错误**（评审 A2）：悬垂访问、唯一写者冲突——程序终止，诊断带位置；与 error union 正交
- **无异常**

## 9. 元编程（双轨）

```hc
script { ... }          // 脚本生成：编译前/执行前执行，生成代码；脚本 = H 核心子集（特定分配器/IO），实时预览与校验
fn List(T: type) type  // comptime 式泛型：编译期函数、类型即值、anytype、惰性实例化
```

- 分工：**comptime 管类型级计算**（泛型）；**脚本生成管样板**（数据定义驱动：序列化/校验/存储）——样板场景下脚本功能**可选**（评审 A4）
- **无宏**

## 10. 并发与异步

```hc
var shared: o ManyToMany(i32) = ...;   // 四模式共享容器
var t: o Thread(i32) = spawn(af, ...); // spawn = 函数 + 显式参数（Q18）
var r = try t.join();                  // 消耗所有权（await 同源）
t.cancel() / t.is_done() / t.detach()
var f: Future(T) = af(...); var v = await f;  // await 任何函数可用（Q19）
```

- **四模式类型**：`OneToOne(T)`（单读单写）/ `OneToMany(T)`（单读多写）/ `ManyToOne(T)`（多读单写）/ `ManyToMany(T)`（多读多写）——内建泛型共享内存容器，写者数量由类型名保证（单写者无锁、多写者互斥）
- **线程所有权**：spawn 归当前作用域；退出时已完成→销毁、运行中→移交根作用域（无隐式阻塞）；**根作用域 = 程序最后退出场所**，负责最终资源回收（评审 A7）
- **线程捕获**：值类型复制值；引用类型 move 或 global；**作用域例外**（Q18）——作用域绑定的执行（await/join 后回到当前作用域）可捕获引用；逃逸线程引用捕获禁用（编译期检查）
- **async/await**：语言关键字（逆转，见 ADR-0008）；`Future(T)` = 线程任务结果句柄；await 与 join 同源且**任何函数可用**（Q19，无 async 传染）；执行模型考虑 **Go 式协程 + 通道**（M:N，评审 B2 方向）
- 静态并发安全标记（Send/Sync 式，编译器内置）
- 事件循环（Evented）为可选运行时：`var ev_io = Io.evented(alloc);` 显式创建/切换（Q35）——同一套 await 代码两种运行时语义一致（双模式承诺）

## 11. 标准库

四大支柱（详见 `04-stdlib-scope.md`）：定义（类型+序列化）/ 修改（集合+变换）/ 传输（网络+FFI）/ 保存（文件+存储）。基础层：`mem`（Allocator）、`io`（I/O+并发，含 async/await 支持）、`time`、`debug`。

- **序列化分层**（2026-08-13 定案）：struct ↔ bytes 内建（`to_bytes`/`from_bytes`，零拷贝视图）；class ↔ JSON 内建（`to_json`/`from_json`）+ 脚本生成可定制；集合 → 二进制内建（长度前缀 u64 LE + 元素字节，Q38）。**POD 边界**（2026-08-13 确认）：仅纯值（POD）struct 可 `to_bytes` 直映射；含切片/指针字段的 struct 走递归序列化（脚本定制，Q37 精神）
- **文件 IO 双语**（Q20）：`f.read_all(alloc)` ≡ `io.fs.read_all(&f, alloc)`；`defer f.close()`；字节为中心 + UTF-8 函数
- **集合构造**（Q15）：`Vec(i32).init(alloc)`——comptime 类型应用 + 构造函数；`String.from(&[u8], alloc)` 显式转换
- **端到端验收基准**（Q25）：TCP 服务——接收 → 反序列化 → 校验/变换 → 序列化回写 → 落盘（见 `examples/05-tools/81-end-to-end.hc`）
