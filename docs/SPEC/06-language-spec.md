## 1. 词法

- 文件后缀：`.hc`
- 语法风格：C 风格（花括号、分号）
- 标识符：`snake_case`；类型名：`PascalCase`
- 注释：`//` 行注释；`///` 文档注释（关联声明，驱动文档生成）；`/* */` 块注释
- 数字字面量：无固定宽度（comptime_int / comptime_float），使用处定型，超范围编译期报错
- 字符字面量（2026-08-13 Q5 定案）：`'x'` 单引号包裹单个字符，**类型 = comptime_int**（惰性宽度，使用处定型，如 `split(',')` 定型为 u8）；支持转义（与字符串同集）
- 字符串字面量：静态只读切片 `&[u8]`（静态存储、无 `o`、不可 move）
- 转义（2026-08-13 Q6 定案，字符串与字符共用）：`\n` `\r` `\t` `\\` `\"` `\'` `\xNN`（十六进制字节）`\u{...}`（Unicode 码点 → UTF-8）；非法转义编译期报错；无原始字符串形态
- 变量**必须显式初始化**，无默认零值
- **关键字/token 清单（2026-08-13 Q7 冻结）**：
  - 声明：`var` `const` `fn` `global` `test`
  - 控制流：`if` `else` `while` `for` `break` `continue` `return` `switch` `defer` `errdefer`
  - 类型构造：`struct` `enum` `class` `tree` `interface`
  - 模块：`namespace` `using` `pub`
  - 内存/所有权：`o` `move`
  - 操作：`and` `or` `try` `catch` `orelse`
  - 元编程：`script` `comptime` `anytype` `type`
  - 并发：`async` `await` `spawn`
  - 字面量：`void` `null` `true` `false`
  - `mut`（可写修饰，Rust 标杆；**定名，占位符解除**）
  - 内建函数（非关键字，Q12 定案）：`box`（装箱）、`copy`（复制）
- 标点/运算符 token：`{}` `()` `[]` `;` `,` `.` `:` `=>` `=` `==` `!=` `<` `<=` `>` `>=` `+` `-` `*` `/` `%` `%%` `+=` `-=` `*=` `/=` `&` `|` `^` `~` `<<` `>>` `!` `?` `..` `.*` `|x|`（捕获）`||`（错误集联合）`_`（忽略绑定）

## 2. 声明

### 变量

```
var [mut] name: [o] [* | *mut] T = init;
const Name = 值;      // 常量/类型别名（Q12 定案：const 不可变，var mut 可变）
```

| 记号 | 语义 |
|---|---|
| `var` | 声明关键字 |
| `mut` | 可写修饰；**默认只读**（Rust 式，2026-08-13 Q7 定名） |
| `o` | 所有权注册在当前作用域（退出销毁）；**仅适用于分配器分配的对象**（复杂类型/装箱指针，2026-08-13 Q15 裁定）——标量/纯值 struct 上写 `o` 编译错误；非 Arena 分配默认拥有（`o` 冗余标注，Q1）；Arena 分配无所有权；**无所有权禁止 move** |
| `*` / `*mut` | 只读 / 可写指针类型 |
| `T` | 类型；**T 与 `*`/`*mut` 可省略**（系统推断），`o` 不可省略推断 |

示例：

```hc
var mut x: o *mut T = t;   // 全写：可写、拥有、类型 T
var mut x: o *mut = t;     // 类型推断
var mut x: o = t;          // 类型与 *mut 推断，o 显式
var x1: *T = &x;           // 只读指针、类型推断
var a = arena.alloc(T);    // 无 o：所有权在 arena（禁止 move）
```

- `global`：根作用域上下文，静态生命周期；默认不可 move、无 `o`
- `void`：无类型（函数返回）

### 类型

| 类别 | 语法 |
|---|---|
| 整数 | `iN`/`uN`（i8–i128、u8–u128）+ `isize`/`usize` |
| 浮点 | `f16`/`f32`/`f64`/`f128` |
| 布尔/空 | `bool`、`void` |
| 数组 | `[N]T`（定长，**引用类型**：传引用、复制需显式） |
| 切片 | `&[T]` / `&mut [T]`（Rust 式，带位置与长度的指针视图） |
| 可选 | `?T`（使用前显式解包） |
| 错误联合 | `E!T` / `!T`（error union） |
| 函数 | `fn(参数) 返回类型` |
| 泛型 | comptime 式（见 §9） |

**数据栈对象判定**：标量、纯值 struct（字段全为标量）→ 可复制传参；数组、集合、复杂类型、含数组/切片字段的 struct → **引用类型**（传参走引用，复制需显式 `copy`，评审 B3）。

### struct（值类型）

```hc
struct Point {
    x: f32,
    mut y: f32,                        // 字段默认只读，mut 修饰可写
    fn dist(a: *Point, b: *Point) f32   // 方法 = 函数成员（Zig 式，无 impl）
}
```

- 底层连续内存（字节数组），值类型；字段可含：标量/struct/定长数组/切片/复杂类型（String/集合/class，2026-08-13 Q2 裁定）；**纯 POD**（字段全为标量/纯值 struct）→ 连续字节、可 `to_bytes` 直映射；含堆字段 → struct 本体内嵌字段值、序列化走递归（非 POD）
- 写字段需持有结构体的可写引用（`*mut`）
- 数据栈对象判定：字段全为标量/纯值 struct → 可复制传参；含数组/切片/集合/复杂类型字段 → 归其它对象（只能引用/move）

### enum（合一式）

```hc
enum Value { int: i32, float: f64, none }   // 变体可选负载；纯常量枚举 = 变体均无负载
```

- switch 穷举（漏分支编译期报错）+ 负载捕获 `|x|`

### 复杂类型（class / tree）

```hc
class Foo { ... }   // 通用堆对象
tree Node { ... }   // 递归/层级：节点含子节点集合，父 o 拥有子
```

- 成员：字段（标量/struct/其它复杂类型，可带 `o`）+ 方法（函数成员）+ 显式接口实现——**成员与 struct 完全一致**（Q22）
- 构造 = `new()` 样板（Q22：脚本生成，12.20）；无特殊构造语法
- **无隐式析构**：资源清理走 `defer`
- 无继承，组合优于继承

### 接口

接口 = 类型的**特性标**（评审 A1）：声明类型必须实现的方法契约。

```hc
interface Shape {
    fn area(self: *Self) f32;   // self = 实现类型的实例；Self = 实现类型（Q14）
}

struct Rect: Shape { ... }      // implements 标注 = 冒号后缀（Q14）
class Foo: Shape, Drawable { ... }
```

- **显式声明实现**（冒号后缀，Q14）；可描述复杂类型、标量、内建类型、用户 struct
- 不提供运算符重载
- 闭包「调用契约」= 内置调用接口类型 `FnN(参数) 返回`（Q13）
- 方法调用双语：`p.dist(q)` ≡ `Rect.area(p)`（Q5，接收者自动取引用）
- **接口指针（Q17 定案，2026-08-13）**：`*Shape` = **胖指针**（data 指针 + 虚表指针，两字宽）；`box(rect, alloc)`（`o *mut Rect`）赋给接口指针时**编译期自动收窄**（接口实现检查通过即合法，无需 as）；data 部分参与双向引用登记（悬垂/唯一写者与 `*T`/`*mut T` 一致），虚表指针不参与（编译期静态）
- **接口参数（Q22/Q22b 定案，2026-08-13）**：接口类型传参 = **带约束的虚拟类型 T**，约束放签名末尾的 **where 子句**：`fn add(a: *T) void where T: INumber`；形态映射 `&T`→`*T`（只读）/ `&mut T`→`*mut T`（可写）/ `move T`→`o T`（拥有）；调用点显式：`add(&a)` / `add(&mut a)` / `add(move a)`；**静态分发**（单态化、无虚表）为主路径；动态分发（`*Shape` 胖指针装箱，Q17）保留给异构集合

### 测试块（2026-08-13 Q8 定案）

```hc
test "add 基本" {
    try expect(add(1, 2) == 3);
}
```

- 顶层测试块：编译器收集为独立测试单元，`hc test` 命令运行（M8 工具链）
- 块内可用任意 H 代码；**测试失败 = error**（`try expect(...)` 传播即失败，报告带位置）
- `expect(cond)` 归标准库 `debug` 模块，测试块内**隐式可用**（无需 using）
- 测试块非函数（无参数/无返回值/不可调用）；可出现在文件任何顶层位置

## 3. 运算符

| 类别 | 记号 |
|---|---|
| 算术 | `+ - * /` |
| 除模 | `/` 截断除法；`%` 截断取余；`%%` 欧几里得取模（非负） |
| 逻辑 | `and` `or` `!`（关键字，非符号） |
| 比较 | `== != < <= > >=`（严格相等，无双轨） |
| 位运算 | `& \| ^ ~ << >>` |
| 范围 | `..`（切片取段） |
| 解引用 | `p.*` 显式取值；**字段/索引访问自动解引用**（`p.x`、`s[i]`，评审 A3） |
| 取地址 | `&x` 只读地址（只读/可写变量均合法）；`&mut x` 可写地址（仅 `var mut` 变量） |
| optional | `x orelse 默认值`；`x.?` 显式断言解包（空则运行时错误带位置） |
| 复合赋值 | `+= -= *= /=` |
| 重载 | **无** |

- 越界检查按模式（Q24）：Debug 运行时检查（抛错带位置）、Release 裸性能；编译期可证越界（`arr[10]` 对 `[5]i32`）所有模式编译期报错
- **字符串拼接走方法**（Q28）：`s.concat(other)` ≡ `String.concat(a, b)`——无 `++` 运算符、无 `+` 重载（函数 = 唯一处理逻辑）

**优先级与结合性（2026-08-13 Q4 定案，Zig 式，从高到低）**：

| 优先级 | 运算符 | 结合性 |
|---|---|---|
| 1（最高） | 后缀：`p.*` 解引用、`f(x)` 调用、`a[i]` 索引、`p.x` 字段、`x.?` 断言 | — |
| 2 | 前缀/一元：`-` `!` `~` `&x` `&mut x` `try` | — |
| 3 | `*` `/` `%` `%%` | 左 |
| 4 | `+` `-` | 左 |
| 5 | `<<` `>>` | 左 |
| 6 | `&`（位与） | 左 |
| 7 | `^` | 左 |
| 8 | `\|`（位或） | 左 |
| 9 | `==` `!=` `<` `<=` `>` `>=` | 非结合（`a < b < c` 编译报错） |
| 10 | `and`（短路） | 左 |
| 11 | `or`（短路） | 左 |
| 12 | `orelse` / `catch` | 左 |
| 13 | `..`（仅索引取段与 for 区间内） | — |
| 14（最低） | `=` `+=` `-=` `*=` `/=` | 右 |

- `&` 一元（取地址）与二元（位与）由「一元高于二元」标准规则区分
- `..` 优先级低于算术：`8 .. 8 + len` = `8 .. (8 + len)`
- `try a catch b` = `try (a catch b)`（Zig 惯例）
- **`&` 三义解析（Q24 定案，2026-08-13）**：lexer 只产出一个 `&` token；**类型位置**（`:` 后/参数类型/泛型参数）→ 切片类型 `&[T]`/`&mut [T]`；**表达式位置** → 一元取地址（`&x`/`&mut x`，表达式起始处）或二元位与（`a & b`）；`&mut` = `&` + `mut` 关键字（最长匹配）；parser 上下文标志消解（LL(1) 可行）

## 4. 语句与控制流

```
if (cond) a else b            // if 是表达式；作表达式时 else 强制，作语句时可选
if (opt) |v| { ... }          // optional 捕获
if (e!) |v| else |err| { ... } // error union 双向捕获（Q9 定案：必须成对，错误显式处理）
switch (v) { int => |i| ..., none => ... }   // 穷举 + 负载捕获；**也是表达式**（Q27）；**else 兜底**（Q31：有 else 免穷举，无 else 强制穷举）
while (cond) { ... }
while (i < n) : (i += 1) { ... }   // 续步表达式
while (opt) |v| { ... }           // optional 捕获（Q10 定案：空则退出循环）
while (e!) |v| { ... } else |err| { ... }  // error union 捕获（错误走 else 后退出）
for (items) |item| { ... }           // 数组/切片迭代，捕获默认只读
for (items) |mut item| { ... }       // 可写捕获（评审 B5 + Rust 标杆）
for (0..10) |i| { ... }              // 区间糖（Q29：复用 .. 记号，底层仍是 while）
break :label / continue :label     // 带标签退出嵌套
defer expr / errdefer expr         // 作用域退出执行；errdefer 仅错误路径；多 defer 按 LIFO（Q21：后声明先执行）
```

- 无 `do-while`、无 `loop`（用 `while (true)`）

## 5. 函数与闭包

```hc
fn main(io: Io) !void {}   // 入口：io 显式传入（Q1）；!void 入口错误运行时报告
fn fun(y: o *mut T) void {}          // o T：参数拥有（Q22b 类型标注制；退出销毁）
fn add(a: *T) void where T: INumber {}  // 接口约束：where 子句在签名末尾（Q22b）
fn f(x: &[u8]) !i32                   // 返回 error union
async fn af() T                       // 返回 Future(T)
var hp: o *mut Point = box(p, alloc); // 装箱：值 → 堆引用（Q8，显式分配器）
```

- **参数**：数据栈对象默认复制；其它对象只能 `*T`（只读引用）/ `*mut T`（可写引用）/ `o T`（拥有，函数作用域接管，退出销毁）
- **接口约束参数（Q22b 定案，2026-08-13）**：虚拟类型 T + `where T: I1, I2` 约束子句（签名末尾）；调用点按形态显式：`add(&a)` / `add(&mut a)` / `add(move a)`
- **io 参数（Q22c 定案，2026-08-13）**：库函数统一虚拟类型制 `io: *T where T: Io`（调用点 `&io`）；**入口特例**：`fn main(io: Io)` 由编译器注入默认 IO 实现句柄（无调用者，唯一例外）
- **move 规则**：仅本作用域拥有（非 Arena）的变量可 move；拥有参数用 `o T` 标注（函数内隐含拥有，退出销毁）；`o` 与 `*`/`*mut` 正交（`o *mut T` 允许）；**调用点显式 `move`**（Q23）：`take(move s);` / `return move s;`——所有权转移在调用点可见
- **权限标注模型**（评审 D2）：类型标注 = 类型 + 读写权限（`*`/`*mut`）+ 所有权（o）；move 基于所有权判定，与读写权限同属统一权限体系；comptime 函数返回类型不适用运行时 move 规则
- **返回值**：`fn() oT` 返回拥有（所有权移出）；`fn() *T` / `*mut T` 返回引用；函数内新建的值必须 move 返回（无所有权的除外）；返回引用必须指向函数参数，不得返回局部变量引用
- **闭包**：`|x| expr` 默认只读捕获；`mut |x| ...` 可写捕获（Rust 标杆）；`move |x| ...` 转移捕获（粒度=整个闭包）；调用 `f(x)`；闭包是数据对象（捕获为字段）
- **闭包捕获登记（Q26 定案，2026-08-13）**：捕获的变量与闭包建立**双向注册**（与 `&` 引用同一模型）——被捕获变量销毁时，捕获它的闭包被标记悬垂（Debug：后续调用该闭包抛错带位置；Release：裸）；闭包存容器合法（捕获随闭包入容器，登记链覆盖）
- **作用域退出销毁顺序 = 声明逆序（LIFO）**（Q26 定案）：后声明的变量先销毁——容器（通常后声明）先于被捕获目标销毁，常规形态无悬垂；顺序不利时由登记机制兜底（访问才报错）
- 方法 = 类型声明内的函数成员

### 内建函数（2026-08-13 Q12 定案）

- **`box(value, alloc) -> o *mut T`**：装箱——分配堆内存、值写入堆、返回带所有权的可写指针；改变值的存储位置与所有权性质（语言机制，普通函数无法实现）
- **`copy(&value) -> T`**：按类型复制——标量 = 复制、引用类型 = 深拷贝、class = 递归复制（含内存树）
- 两者是**编译器内建**（不可用户定义/重载）；**非关键字**（可作标识符，如 `var box = 1;`）

## 6. 所有权与内存

- **作用域** = 无名字的函数；函数 = 有名字的作用域；所有权注册在作用域上，退出自动销毁
- **所有权归属（Q1 裁定：按分配来源编译时判定）**：非 Arena 分配器创建的复杂类型 → 所有权**默认注册当前作用域**（显式 `o` 冗余标注）；Arena 分配 → 所有权归 Arena（变量无所有权，统一回收）
- **引用类型赋值 = 别名共享**（Q3c 裁定）：`var s2 = s1;`（数组/集合/String 等引用类型）→ s2 与 s1 共享同一数据，s1 保持唯一拥有（作用域退出销毁一次）、s2 无所有权；深拷贝需显式 `copy(&s1)`；s2 构成对 s1 的「向内引用」→ move s1 编译期禁止；s2 不得比 s1 长寿（逃逸检查，防悬垂）。所有权转移是重大动作，必须显式 `move` 关键字（赋值不隐含转移，「没有隐藏控制」）
- **move**：仅对**本作用域拥有**的变量合法；Arena 来源（无所有权）**禁止 move**（move 须对整个 Arena 进行）；转移后目标作用域负责销毁
- **可移动性（编译时判定，Q1 裁定）**：可 move ⟺ ① 非 Arena（默认拥有）；② 内存树**无外部引用**——无向外引用（字段及递归子项均无引用值 `*T`/`*mut T`/`&[T]`/`&mut [T]`）+ 无向内引用（move 程序点无指向树内节点的存活引用，编译期别名检查）。任一不满足 → 编译期禁用 move。String/Vec 等自有子对象随树转移；Thread/Future/四模式线程类型豁免
- **引用**：
  - `*T` 只读指针：可选双向注册（编译期选项）——Debug 默认注册（悬垂抛错带位置）、Release 默认裸读（用户负责）
  - `*mut T` 可写指针：强制双向注册；**唯一写者由运行时登记强制**（同一变量同一时间最多一个，可写包含可读）；**不可拷贝，只能 move 传递**（评审 A5）
  - **指针不可空**（Q16 定案，2026-08-13）：`*T`/`*mut T` 永远指向有效对象或已被标记悬垂；空态用 `?*T`/`?*mut T`（可选指针）；无 NULL 字面量；悬垂 ≠ null（悬垂是「曾指向有效对象后被销毁」的运行时错误状态）
  - **临时引用生命周期（Q25 定案，2026-08-13）**：表达式产生的临时 `*T`/`*mut T` 存活到所在完整表达式/语句结束——方法链整链期间唯一写者资格保持、链末一次注销；绑定到变量的引用存活到作用域结束；链内传递的临时 `*mut` = 同一写者资格的延续（reborrow 精神，衔接开放问题 #2）
- **运行时错误**（评审 A2）：悬垂访问/唯一写者冲突 = **不可恢复运行时错误**（与 error union 可恢复错误正交）
- **o 默认规则**（Q16）：非 Arena 分配器创建的复杂类型默认拥有（作用域接管、退出自动销毁，无需显式 o/deinit）；Arena 例外（统一销毁）；`defer` 管非内存资源（文件等）
- **String = `u8[]` 别名**（2026-08-13 Q3 裁定）：引用类型，默认传引用、赋值走复杂类型默认语义——原 Q16「String 值复制例外」取消
- **Allocator**：显式传递为主，未传回退**默认分配器**（Q8/Q16：根作用域的 global，全局可引用；每线程独立实例——线程创建自己的根上下文）
- **defer/errdefer**：资源清理（不用隐式析构）
- **无 GC**：双模式同一套模型
- **生命周期**：单元 = 作用域；无显式生命周期标注

## 7. 模块与包

- **命名空间组织**（Q21，C# 式）：`namespace Math { ... }` 块式分组（可跨文件、一文件多组）；`using Math;` 引入（限定访问与直接使用）；文件 = 物理单元
- `pub` 管包边界（同包 using 即达；跨包需 pub + 依赖声明）
- 包管理器内置编译器；**依赖清单 = H 数据字面量**（Q26）：`const build = Build{ name = ..., deps = [...], ... }`（构建时校验版本与指纹）
- 官方注册中心

## 8. 错误处理

- error union（`E!T`）+ 显式错误集（`error{...}`）+ `try` 传播——**可恢复错误**
- **错误值引用（Q13 定案，2026-08-13）**：`error.Name` 在任何上下文可引用（**错误名全局唯一**）；可 return/比较/switch 分支匹配（`error.NotFound => ...`）；返回显式错误集的函数中 `return error.X` 未在集合内 → 编译报错；`anyerror` 上下文任意错误名可用
- **忽略错误（Q11 定案，2026-08-13）**：仅 `expr catch |_| {}` 形态——「忽略」必须显式写出捕获与空处理；**无 `catch {}` 简写**（忽略是显式动作，不是隐式吞错）
- **`anyerror`**（Q34）：任意错误类型，仅用于**接口方法契约**（实现方决定具体错误集）；普通函数仍用显式错误集
- **不可恢复运行时错误**（评审 A2）：悬垂访问、唯一写者冲突——程序终止，诊断带位置；与 error union 正交
- **无异常**

## 9. 元编程（双轨）

```hc
script { ... }          // 脚本生成：编译前/执行前执行，生成代码；脚本 = H 核心子集（特定分配器/IO），实时预览与校验
fn List(T: type) type  // comptime 式泛型：编译期函数、类型即值、anytype、惰性实例化
```

- 分工：**comptime 管类型级计算**（泛型）；**脚本生成管样板**（数据定义驱动：序列化/校验/存储）——样板场景下脚本功能**可选**（评审 A4）
- **脚本输入机制（Q23 定案，2026-08-13）**：script 块 = 编译前执行的 H 表达式块（H 核心子集），**产物 = 生成的代码字符串**就地替换本块（Q17）；脚本上下文隐式提供 `types` 元数据对象——`types.fields("Person")`（字段名+类型列表）、`types.type("Person")`（类型结构）、`types.all()`（当前文件全部类型）；元数据由编译器生成注入（M2 类型系统 → M3 脚本桥）；脚本用 H 字符串操作遍历类型定义拼接生成代码，无第二语言
- **无宏**

## 10. 并发与异步

```hc
var shared: o ManyToMany(i32) = ...;   // 四模式共享容器
var t: o Thread(i32) = spawn(af, ...); // spawn = 函数 + 显式参数（Q18）
var r = try t.join();                  // 消耗所有权（await 同源）
t.cancel() / t.is_done() / t.detach()
var f: Future(R) = af(...); var v = await f;  // await 任何函数可用（Q19）；R = 完整返回类型（Q20）
```

- **四模式类型**：`OneToOne(T)`（单读单写）/ `OneToMany(T)`（单读多写）/ `ManyToOne(T)`（多读单写）/ `ManyToMany(T)`（多读多写）——内建泛型共享内存容器，写者数量由类型名保证（单写者无锁、多写者互斥）
- **四模式类型方法集（Q14 定案，2026-08-13）**：`init(alloc)`（构造）/ `write(v)`（写，写者数量由类型名保证）/ `read() T`（**阻塞读**：有值即返回，close 后空则运行时错误）/ `try_read() ?T`（**非阻塞读**：无值或 close 后空返回 `null`）/ `close()`（**结束标志**：此后 `write` 报错、`try_read` 返回 `null`）；全部方法取 `*Self`（Q32 内建共享特例：不占唯一写者槽、内部同步）
- **线程所有权**：spawn 归当前作用域；退出时已完成→销毁、运行中→移交根作用域（无隐式阻塞）；**根作用域 = 程序最后退出场所**，负责最终资源回收（评审 A7）
- **线程捕获**：值类型复制值；引用类型 move 或 global；**作用域例外**（Q18）——作用域绑定的执行（await/join 后回到当前作用域）可捕获引用；逃逸线程引用捕获禁用（编译期检查）
- **线程捕获静态检查（Q19 定案，2026-08-13）**：
  - **绑定/逃逸判定（数据流）**：句柄（Thread/Future）在声明作用域内被 join/await → 绑定（引用捕获合法）；被 detach 或作用域退出未 join → 逃逸（引用捕获编译错误）
  - **冻结窗口（借用期）**：绑定场景下，被捕获引用的目标从 spawn 到 await/join 之间主线程不可写（不可 `var mut` 写入、不可取 `&mut`）——编译期检查，await/join 后恢复；并发写共享数据 → 显式用四模式类型
- **async/await**：语言关键字（逆转，见 ADR-0008）；`Future(T)` = 线程任务结果句柄；await 与 join 同源且**任何函数可用**（Q19，无 async 传染）；执行模型考虑 **Go 式协程 + 通道**（M:N，评审 B2 方向）
- **Future 类型参数（Q20 定案，2026-08-13）**：`async fn f(...) R` 返回 `Future(R)`——R 是完整返回类型（含 `!`）；`await` 返回 R，`try await` 解包 error union
- 静态并发安全标记（Send/Sync 式，编译器内置）
- 事件循环（Evented）为可选运行时：`var ev_io = Io.evented(alloc);` 显式创建/切换（Q35）——同一套 await 代码两种运行时语义一致（双模式承诺）

## 11. 标准库

四大支柱（详见 `04-stdlib-scope.md`）：定义（类型+序列化）/ 修改（集合+变换）/ 传输（网络+FFI）/ 保存（文件+存储）。基础层：`mem`（Allocator）、`io`（I/O+并发，含 async/await 支持）、`time`、`debug`。

- **序列化分层**（2026-08-13 定案）：struct ↔ bytes 内建（`to_bytes`/`from_bytes`，零拷贝视图）；class ↔ JSON 内建（`to_json`/`from_json`）+ 脚本生成可定制；集合 → 二进制内建（长度前缀 u64 LE + 元素字节，Q38）。**POD 边界**（2026-08-13 确认）：仅纯值（POD）struct 可 `to_bytes` 直映射；含切片/指针字段的 struct 走递归序列化（脚本定制，Q37 精神）
- **文件 IO 双语**（Q20）：`f.read_all(alloc)` ≡ `io.fs.read_all(&f, alloc)`；`defer f.close()`；字节为中心 + UTF-8 函数
- **集合构造**（Q15）：`Vec(i32).init(alloc)`——comptime 类型应用 + 构造函数；`String.from(&[u8], alloc)` 显式转换
- **端到端验收基准**（Q25）：TCP 服务——接收 → 反序列化 → 校验/变换 → 序列化回写 → 落盘（见 `examples/05-tools/81-end-to-end.hc`）
