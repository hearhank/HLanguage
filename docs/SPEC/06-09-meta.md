# H 语言规范：元编程（script / comptime 双轨）

> 对应实现模块：07 **第三块 E1**（元编程完整）。**第一部分最小功能集明确不实现**——仅泛型 where 基础（06-04）。注意区分：**脚本模式（`hc run` 解释执行）= 第一块 M3.2（必须实现）**；**脚本生成（`script` 块）= 本文件（E1，**已实现**，组 B 2026-08-18）**。序列化定制通道（Q37/Q38）随组 C（E1.3，2026-08-18）落地。**comptime 类型函数**（`fn List(T: type) type`）**已实现**：D1（2026-08-18）解析/语义/具体化（`hc::comptime` 三后端共享）、interp+IR 惰性登记、类型函数体降级跳过（示例 34 三模式全绿）；D3/D4 最小切片（2026-08-18）comptime_int 值参数 + 数组类型函数（`fn ArrayLen(T: type, n: comptime_int) type { return [n]T; }`，`Type::ComptimeInt` + `Expr::ArrayType`，示例 35 三模式全绿）；comptime 块（`comptime { }`，组 D D2 最小切片，2026-08-18：装载期受限 Interp 求值、结果丢弃、失败 = 编译错误，测试 5 项端到端全绿）；comptime_float / anytype 完整语义仍待组 D4。

```hc
script { ... }          // 脚本生成：编译前执行（H5：无运行时环境，纯模板生成）；类型信息可见 = 所在作用域
comptime { ... }        // 编译时执行（H5：语义分析阶段，完整类型系统，可执行更多操作）
fn List(T: type) type   // comptime 式泛型：编译期函数、类型即值、anytype、惰性实例化
```

- 分工：**comptime 管类型级计算**（泛型）；**脚本生成管样板**（数据定义驱动：序列化/校验/存储）——样板场景下脚本功能**可选**（评审 A4）
- **执行位置与可见数据（H5 定案，2026-08-14）**：`script` 块 = **编译前**执行（解释器），无运行时环境（io/alloc/argv 不可用），一般只执行模板生成；**类型信息可见范围随块位置收窄**——script 块在 class 内 → 该 class 类型数据可用；在命名空间下 → 整个命名空间类型信息可用（`types` 元数据对象 `types.fields/type/all` 可见范围随块位置）；**生成物（class/function/属性列表等）不得与当前环境冲突**（同名 = 编译错误）；`comptime` 块 = **编译时**执行（语义分析阶段），能获取的数据多得多（完整类型系统，`types` 元数据可见全部类型），可执行更多操作
- **脚本输入机制（Q23 定案）**：script 块产物 = 生成的代码字符串就地替换本块（Q17）；脚本用 H 字符串操作遍历类型定义拼接生成代码，无第二语言
- **comptime 块与错误机制（2026-08-14 定案）**：comptime 函数 = 参数含 `type`/`anytype` 即触发编译期执行的普通函数；**作用域/函数/script 块/comptime 块均为可返回错误的执行单元（error union）**——script/comptime 块执行失败 = **编译错误**（解释器/编译器抛出，带块内位置 + 所属块位置），与运行时错误同一机制
- **降级闸门（Q-S10 定案）**：脚本生成保持 1.0 必达；若成本超预期 → 降级为「脚本生成 = 编译期执行 H 子集函数（comptime 内联）」，`script{}` 语法保留、实现走编译期求值
- **序列化定制（Q37/Q38）**：脚本生成序列化/校验/存储样板（数据定义 → 样板）——**已实现**（组 C E1.3，2026-08-18）：`types.fields` 驱动校验（String 非空 / i32 ≥ 0 / ?String null 守卫）与 to_json（String 带引号 / i32 裸值 / ?String→`null`）；schema 版本/迁移钩子设计见 05 #4
- **无宏**（12.22：宏不进入语言，与「没有隐藏控制」一致）
