# H 语言规范：词法、声明、运算符、语句与控制流、测试

> 对应实现模块：07 第一块语言系统 M1 前端。

## 1. 词法

- 关键字/token 清单（2026-08-13 Q7 冻结；2026-08-14 修订）：
  - 声明：`var` `const` `fn` `global` `test`
  - 控制流：`if` `else` `while` `for` `break` `continue` `return` `switch` `defer` `errdefer`
  - 类型构造：`class` `enum` `tree` `interface` `where`（R-5 补充：接口约束子句；`struct` 已合并入 class，2026-08-14）
  - 模块：`namespace` `using` `pub`
  - 内存/所有权：`o` `move`
  - 操作：`and` `or` `try` `catch` `orelse`
  - 元编程：`script` `comptime` `anytype` `type`
  - 并发：`async` `await` `spawn`
  - 字面量：`void` `null` `true` `false`
  - `mut`（可写修饰，Rust 标杆；定名）
  - 内建函数（非关键字，Q12 定案）：`box`（装箱）、`copy`（复制）
- 标点/运算符 token：`{}` `()` `[]` `;` `,` `.` `:` `=>` `=` `==` `!=` `<` `<=` `>` `>=` `+` `-` `*` `/` `%` `%%` `+=` `-=` `*=` `/=` `&` `|` `^` `~` `<<` `>>` `!` `?` `..` `.*` `|x|`（捕获）`||`（错误集联合）`_`（忽略绑定）
- `@` 前缀（Q-S1 定案）：内建函数前缀（`@sizeOf`/`@intCast`/`@ptrCast` 等，见 06-04）——不与用户标识符冲突
- 数字字面量：无固定宽度（comptime_int / comptime_float），使用处定型，超范围编译期报错；0x/0b/0o 进制（Q46）；`_` 数字分隔符
- 字符字面量（Q5 定案）：`'x'` 单引号包裹单个字符，**类型 = comptime_int**（惰性宽度，如 `split(',')` 定型为 u8）；无独立 char 类型——非 ASCII 字符用 u32 码点显式（如 `0x1F600`，2026-08-14 确认）
- 字符串字面量：静态只读切片 `&[u8]`（静态存储、无 `o`、不可 move）；**多行/原始字符串 `"""..."""`**（无转义，2026-08-14 定案）
- **推断枚举值字面量 `.name`（L1 定案，2026-08-14）**：参数/字段类型已知时 `.Name` 推断为对应枚举变体（如 `copy(&x, .shallow)` ≡ `copy(&x, CopyMode.shallow)`）
- 转义（Q6 定案，字符串与字符共用）：`\n` `\r` `\t` `\\` `\"` `\'` `\xNN`（十六进制字节）`\u{...}`（Unicode 码点 → UTF-8）；非法转义编译期报错
- 注释：`//` 行注释；`///` 文档注释（关联声明，驱动 M8 文档生成）；`/* */` 块注释（偏离 Zig 第一：项目所有者选择保留，2026-08-13）

## 2. 声明

### 变量

```hc
var x: i32 = 5;          // 声明；T 可推断时省略
var mut x: o *mut T = t; // 全写：可写、拥有、类型 T
var mut x: o *mut = t;   // 类型推断
var mut x: o = t;        // 类型与 *mut 推断，o 显式
var x1: *T = &x;         // 只读指针、类型推断
var a = arena.alloc(T);  // 无 o：所有权在 arena（禁止 move）
const Name = 值;          // 常量/类型别名（Q12 定案：const 不可变，var mut 可变）
```

| 记号 | 语义 |
|---|---|
| `var` | 声明关键字 |
| `mut` | 可写修饰；**默认只读**（Rust 式，Q7 定名） |
| `o` | 所有权注册在当前作用域（退出销毁）；**仅适用于分配器分配的对象**（复杂类型/装箱指针，Q15 裁定）——标量/Continuous 类型上写 `o` 编译错误；非 Arena 分配默认拥有（`o` 冗余标注，Q1）；Arena 分配无所有权；**无所有权禁止 move** |
| `*` / `*mut` | 只读 / 可写指针类型 |
| `T` | 类型；**T 与 `*`/`*mut` 可省略**（系统推断），`o` 不可省略推断 |

**类型推断原则（Q-S9 定案）**：推断优先，显式兜底：
- 可推断：变量绑定（`var x = init`）、字面量惰性宽度、泛型参数（anytype / where T）、指针形态（`var x = &mut t` → `*mut T`）、函数返回类型（单返回路径/一致类型）
- 必须显式：函数参数类型（含 `*`/`*mut`/`o` 形态）、class 字段类型、接口实现标注；`o` 不参与推断

- `global`：根作用域上下文，静态生命周期（程序退出时销毁）；**有所有权（归根作用域）**，不可 move；`o` 标注不用于 global；**初始化 = 程序启动时执行**（main 前；**M7 定案：跨文件按初始化表达式依赖图拓扑排序，无依赖按文件声明序，循环依赖 = 编译错误**）
- `void`：无类型（函数返回）

### 测试函数（Q8 定案；Q-R11 修订：测试 = 标记为测试的函数）

```hc
[test] fn add_basic() !void {
    try expect(add(1, 2) == 3);
}
```

- **`[test("名称")] fn 名称() !void`**：标记为测试的函数——`hc test` 收集运行；可被普通代码调用/复用；参数可省（`[test]` 省略显示名 / `[test("名称")]` 指定显示名），显示名 = 名称 ?? 函数名
- **测试失败 = error**（`try expect(...)` 传播即失败，报告带位置）
- **断言 API（Q-T1 定案，归 std.debug、测试函数内隐式可用）**：`expect(cond)` / `expect_eq(a, b)`（失败输出期望 vs 实际）/ `expect_neq(a, b)` / `expect_error(error.e, expr)` / `expect_eq_slices(a, b)`（失败输出长度 + 首个差异位置）；`expect_eq` 支持 `==` 可比较类型（含 String 内容比较）；全部返回 `anyerror!void`
- **输出与统计（Q-T2 定案）**：`[PASS]/[FAIL]/[SKIP] 文件名::测试名`；FAIL 附错误类型 + 断言位置；汇总 `N passed, M failed, K skipped (总耗时)`；失败数 > 0 → 退出码非零；失败不中止
- **隔离/执行/跳过（Q-T3 定案）**：每个 test = 独立块作用域（退出自动销毁）；默认串行（并发测试留 1.x）；`return error.SkipTest;` → 统计为 SKIP
- **环境注入（Q-T4 定案）**：test 内隐式 `test_io`（独立 `Io.threaded()` 实例）与 `alloc`；IO 测试默认真实执行
- **双模式（Q-T5 定案；M6 测试矩阵，2026-08-14）**：`hc test` 默认脚本 Debug；`--mode=compile` 编译 **Debug**（双模式一致性验证——含错误路径用例）；`--release` 编译 Release（零开销验证——仅跑**正常路径子集**，不含越界/溢出/悬垂错误路径用例）
- **示例测试形态（Q-T6 定案，四层）**：S1 纯逻辑断言 / S2 main smoke / S3 局部逻辑 / S4 演示标注（输出不捕获）

## 3. 运算符

| 类别 | 记号 |
|---|---|
| 算术 | `+ - * /` |
| 除模 | `/` 截断除法；`%` 截断取余；`%%` 欧几里得取模（非负） |
| 逻辑 | `and` `or` `!`（关键字，非符号） |
| 比较 | `== != < <= > >=`（严格相等；`==` = 值比较，内部调用 ICompare 方法，H3 定案） |
| 位运算 | `& \| ^ ~ << >>` |
| 范围 | `..`（切片取段） |
| 解引用 | `p.*` 显式取值；字段/索引访问自动解引用（`p.x`、`s[i]`，评审 A3） |
| 取地址 | `&x` 只读地址（只读/可写变量均合法）；`&mut x` 可写地址（仅 `var mut` 变量） |
| optional | `x orelse 默认值`；`x.?` 显式断言解包（空则运行时错误带位置） |
| 复合赋值 | `+= -= *= /=` |
| 重载 | **无**（运算符只绑定内建接口族） |

- 越界检查按模式（Q24）：Debug 运行时检查（抛错带位置）、Release 裸；编译期可证越界所有模式编译期报错
- **整数溢出按模式（Q-S6 定案）**：Debug/脚本检测并 `@panic`（带位置）；Release 裸 wrap；显式原语 `@addWithOverflow` / `@subWithOverflow` / `@mulWithOverflow` → **元组 `(T, bool)`**（value, overflow）
- **运算符绑定（2026-08-14 定案；H3 修订）**：算术 `+ - * /`（及一元 `-`）绑定 `INumber` 族——`a + b` ≡ `a.add(b)`，`%`/`%%` 编译器派生；**相等 `==`/`!=` = 值比较，内部调用 ICompare**（标量/枚举/元组/String/集合按值；class 身份比较删除——需实现 ICompare 才有 `==`；指针比较 = 指向对象地址，数组/切片含位置 + 长度）；**序比较 `< <= > >=` 绑定 `ICompare`**；**无用户运算符重载**
- **字符串拼接走方法**（Q28）：`s.concat(other)`——无 `++` 运算符、无 `+` 重载

优先级表（Q4 定案）：后缀（解引用/调用/索引/字段/断言）> 前缀/一元（`-` `!` `~` `&x` `&mut x` `try`）> `*` `/` `%` `%%` > `+` `-` > `<<` `>>` > `&` > `^` > `|` > 比较（非结合，`a < b < c` 编译报错）。

## 4. 语句与控制流

```hc
if (cond) a else b            // if 是表达式；作表达式时 else 强制，作语句时可选
if (opt) |v| { ... }          // optional 捕获
if (e!) |v| else |err| { ... } // error union 双向捕获（Q9 定案：必须成对，错误显式处理）
switch (v) { int => |i| ..., none => ... }   // 穷举 + 负载捕获；也是表达式（Q27）；else 兜底（Q31：有 else 免穷举）
switch (v) { int => |i| i if i > 0 => ..., ... }  // switch 守卫（2026-08-22 定案：模式后 if 守卫）
while (cond) { ... }
while (i < n) : (i += 1) { ... }   // 续步表达式
while (opt) |v| { ... }           // optional 捕获（Q10 定案：空则退出循环）
while (e!) |v| { ... } else |err| { ... }  // error union 捕获（错误走 else 后退出）
for (items) |item| { ... }           // 数组/切片迭代，捕获默认只读（迭代契约见 06-05）；值类型迭代自动取引用（L4：for (fib) ≡ for (&mut fib)）
for (items) |mut item| { ... }       // 可写捕获（评审 B5 + Rust 标杆）
for (items) |move item| { ... }      // 拥有迭代（IIterable<o T>，2026-08-14）
for (0..10) |i| { ... }              // 区间糖（Q29：复用 .. 记号，底层仍是 while）
break :label / continue :label     // 带标签退出嵌套
defer expr / errdefer expr         // 作用域退出执行；errdefer 仅错误路径；多 defer 按 LIFO（Q21：后声明先执行）
```

- 无 `do-while`、无 `loop`（用 `while (true)`）
- **switch 守卫（2026-08-22 定案，ADR-0017）**：`switch (v) { 模式 if 守卫 => 表达式 }`——守卫为任意布尔表达式，可引用负载捕获变量（`int => |i| i if i > 0 => ...`）；**守卫失败 → 继续尝试下一个分支**（不报错、不落入）；**穷举性**：有守卫的分支仍算覆盖该值形态，但守卫可能失败 → 需存在无守卫分支或 `else` 兜底保证穷举（否则编译错误）；仍是表达式（每个分支产出值，守卫失败走后续分支求值）；与 `else` 兜底（Q31）正交叠加
- **`for` 值类型自动取引用（L4 定案，2026-08-14）**：`for (fib)`（fib 为值）≡ `for (&mut fib)`（可写迭代）/ `for (&fib)`（只读迭代）——与方法调用自动取引用同精神；只读绑定（无 `mut`）时可写迭代编译错误
- **多参索引（M8 定案，2026-08-14）**：`expr[i, j]` 逗号索引——仅 `Table` 类型合法（行、列）；其它类型单参索引 `s[i]`
