# 01 · 数据模型

数据的两种内存形状是类型系统的根基。判断标准：**内存是否连续**。

## 块 (Block)

- 连续内存块（struct 式）。内容在内存中紧邻。
- **复制语义**：赋值、传参 = memcpy。默认不可变，可变需显式声明。
- 默认在栈上；放堆上永远是显式选择（经 allocator）。
- **块只含块**：块是纯数据（无指针、无生命周期），因此字节化是平凡的（memcpy）。
- 枚举（标签联合）是块的一种，支持穷尽性模式匹配。

## 树 (Tree)

- 非连续数据（class 式）。内容分散在不同内存位置，通过引用相连。
- 在堆上分配（经 allocator）。
- **字段分两类**：
  - 值字段（块）——复制语义，廉价；
  - 引用字段（树）——指针 + 双向引用，带生命周期。
- 树支持序列化，序列化后压平为块（byte 数组）；可反序列化恢复为树。
- 可写指针必须双向引用且不跨执行体；只读指针的双向引用是可选项。

## 动态块（内建）

- 字符串、动态数组是内建动态块：连续数据区 + 长度（+容量）。
- 复制即复制数据区；字节化平凡。
- 数据区在堆上，经显式 allocator 分配；扩容是显式操作（可见的分配）。

## 集合数据的归属

- 哈希表/字典：buckets 非连续，内部有引用 → **树**。
- 判定标准统一：**数据在内存中是否连续**。

## 元组（块的一种，匿名块）

- 连续内存、值语义、元素必须块；默认栈上。
- 位置元组 `(T1, T2)`：访问 `.0`/`.1`；命名元组 `(x: T1, y: T2)`：访问 `.x`/`.y`。**严格分离**：禁止混用；命名元组是带字段名的独立块类型（字段名参与类型与字节化标签）。
- 字面量 `(v1, v2)` / `(x: v1, y: v2)`；空元组 `()`；单元素 `(v,)`（尾逗号区分表达式分组 `(v)`）。
- 解构 `(a, b) = f()`：声明新建或覆盖已有变量（逐元素可写性检查 R4）；支持 `(a, b) = (b, a)` 交换与嵌套解构。
- 字节化：`__shape:"block"` + `__items:[...]`（位置）/`__fields:{...}`（命名，无 `__type`）——与 struct（有 `__type`）、动态块（JSON 数组）区分。

## 切片（借用视图）

- 不拥有的 `[ptr, len]` 视图，只指向**堆上动态块数据区**（动态块/Str/动态块字段）；栈值（struct/元组本身）不可切片。
- 类型 `[]T`（与拥有式 `[T]` 对称）；子切片 `s[a..b]`、`s[..]`；默认只读，`mut` 可写（写透原数据区）。
- 互转：`[T]` → `[]T` 传参自动借用（也允许显式 `arr[..]`）；`[]T` → `[T]` 显式 `clone()`（拷贝有成本、显式标注）。
- **防悬垂**：双向引用通知推广到堆上块数据——动态块/Str 销毁时通知切片置空（ADR 0008）；动态块因此获得生命周期钩子。
- **借入不借出（R12）**：切片不得返回、不得入字段/全局、不得作 spawn 参数——编译期拒绝。

## 结构约束

- 块 ⊃ 块（递归嵌套值）+ 元组（匿名块）；块 ⊅ 树（块不能持有引用）。
- 树 ⊃ 块（值字段）+ 树（引用字段）。
- 切片 = 指向块数据的引用：随切片引入，"块无引用"的纯净性对**堆上动态块数据区**让位（通知机制覆盖，见 03 生命周期）；栈上纯块仍无引用。
- 递归数据（链表/树结构）通过树表达（引用字段天然支持自引用）。类型级递归允许；实例级成环（含自引用）在序列化时检测报错（见 02 字节化）。

## 语法

- 形状用关键字区分声明：**`struct`**（块）、**`class`**（树）、**`enum`**（枚举）；元组用括号字面量（匿名块）；切片用 `[]T`（借用视图）。
- 可写变量：`mut x: T = ...`；默认无前缀 = 只读。

## OPEN

- 动态块的 allocator 传参写法（`[T]` 分配函数的签名形态）。
- 元组/切片已定设计（ADR 0007/0008），实现待排期（parser/checker/cgen 两后端同步落地）。
