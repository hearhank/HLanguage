# 05 · 行为层

行为（函数、组合、接口）是作用于数据的工具层。数据是第一等，行为组织成清晰的契约。

## 函数

- 函数 = 处理数据的方法：`A fun(B)`。
- 参数三种方式（关键字标注）：
  - `x: T`——值复制（块）/ **只读指针（树默认）**；
  - `x: ref T`——可写指针（要求调用方变量可写）；
  - `x: move T`——转移所有权。
- 返回修饰：
  - `-> move T`——返回类型包含所有权（销毁责任随调用方作用域）；
  - `-> ref T`——返回可写引用；
  - `-> T`——只读的值。
- **规则**：树（class）参数不标注时默认只读指针；块参数不标注时默认值复制——两种默认，明确区分。
- **捕获规则**：三类捕获——值捕获（块/动态块，复制）、move 捕获（树，所有权入环境）、ref 捕获（树引用，活引用）。值/move 捕获的函数可字节化；ref 捕获的函数不可字节化（编译期检查）。标注拼写 OPEN（`[x]` / `[move y]` / `[ref z]` 形态）。

## class（组合）

- class = 树数据（class 式）的定义：数据字段（值字段 + 引用字段）+ 方法集。
- **接口声明处绑定**：`class C : I1, I2`，类内定义方法即实现。
- 无继承。提供类似 class 的能力，但方法绑定在类型上、调用静态解析。

### 导入（组合嵌入，替代继承）

- A 导入 B：A 自动获得 B 的方法，并自动标注 B 所满足的接口；可选择性隐藏。
- **同名冲突规则**：
  - A 自己定义的方法公开，导入的同名方法自动隐藏；
  - 多个导入对象之间的同名方法**强制用户处理**——必须隐藏（`hide B::foo`），或对指定对象的指定方法设别名（`alias foo = B::foo`）。
- **隐藏语法**：`hide B::foo`（隐藏方法）、`hide I2`（隐藏继承的接口标注）——只影响对外呈现，内部能力不变。
- **深度传递**：A 导入 B、B 导入 C → A 自动获得 C 的方法。
- **循环拒绝**：导入关系必须无环（命名空间/组合是树，不是图）。
- 显式消歧语法（`B::foo(a)` 访问被遮蔽实现）——OPEN 拼写。

## 接口

- 接口 = 契约：一组函数签名，无数据、无实现状态。
- **纯静态**：只存在于编译期，作为约束，调用编译期单态化；运行期无"接口值"。
- 显式实现：class 声明处列出接口；方法签名匹配由编译器检查。

## 枚举与模式匹配

- 枚举是块的一种（标签联合），支持穷尽性 match——语言核心（错误集是枚举特化）。

## 错误处理

- **error union**（Zig 式）+ 可选值（预期缺席），无异常。
- 错误是显式数据流：错误值 = 枚举（块），可字节化、可传输。
- 错误展开显式（`try`/`catch`），无隐藏跳转。

## 命名空间

- 命名空间树 = 文件系统：文件即命名空间，子目录即子命名空间。
- 两级可见性：`pub` / 私有。
- 显式导入后裸名可用（`use a.b.foo`）；全路径永远可写。

## 类型推断

- **局部推断**（Rust 式）：函数签名显式（类型、错误集、内存语义靠签名传达），函数体内允许推断。

## 语法（已定拼写）

- 函数：`fun`；错误返回 `-> error T`；错误值 `error.X`。
- 参数：`x: T`（块值复制 / 树只读指针）、`x: ref T`、`x: move T`；返回 `-> move T` / `-> ref T` / `-> T`。
- 接口绑定：`class C : I1, I2`。
- class 内导入：`import B`（字段区，细节见 OPEN）。
- 全局：`global x: Mode<T>`。

## OPEN

- class 导入的显式消歧拼写（`B::foo(a)` 形态——`hide`/`alias` 已用 `B::foo` 引用法，消歧调用沿用同一语法）。
- 捕获标注的拼写（`[x]` / `[move y]` / `[ref z]` 形态）。
