# 07 · 与 Rust / Zig 功能对比

定位：H 以**数据生命周期为第一原则**，站在 Rust（所有权）与 Zig（显式与无隐藏控制流）的肩膀上，目标是"静态编译 + 脚本化 + 一切都是数据"。本模块把 H 的类型、内建能力与 Rust、Zig 逐项对照，既用于定位（H 是什么），也用于自查（H 的每一项设计是否落到了实处）。

三者的哲学一句话：

- **Rust**：编译器全知——借用检查、trait、宏在编译期把安全与抽象铸死，运行时零成本。
- **Zig**：运行时全显式——allocator、指针、error、`defer` 都在明面上，无隐藏控制流，编译期用 `comptime` 补抽象。
- **H**：生命周期可见但自动——单一所有权 + 显式 `move`，销毁安全交给**运行时双向引用通知**（内建但可见的成本），不做 Rust 式编译期借用检查（约束过强），不用 GC（隐藏控制流）。

## 总览

| 维度 | H | Rust | Zig |
|---|---|---|---|
| 内存形状 | 块（连续）/ 树（引用图），类型即形状 | 值（栈）/ 引用（堆）由使用方式决定 | 值（栈）/ 切片与指针，堆经 allocator |
| 所有权 | 单一所有权 + 显式 `move`，运行时通知 | 单一所有权 + 隐式移动 + 编译期借用检查 | 无所有权模型，手动管理 |
| 销毁 | 作用域退出自动销毁（树），指针被通知置空 | 作用域退出 `Drop`，借用关系编译期保证不悬垂 | `defer` 显式释放，悬垂靠自觉 |
| 错误 | `error T` union + 未处理即终止 | `Result<T, E>` + `?` | `error union` + `try` / `catch` |
| 并发 | 执行体统一（线程/协程）+ M:N + Channel | 线程 + async/await + mpsc | 线程 + 有限 async，Channel 自建 |
| 对象系统 | class 组合（import/hide/alias，无继承）+ 静态接口 | trait（动态分派或单态化） | struct 方法（无接口/无继承） |
| 序列化 | 内建 `to_bytes`/`from_bytes`（可逆自描述，全类型） | serde（库，需 derive） | std.json + 手动序列化 |
| 元编程 | 无宏（函数/组合承担抽象） | 宏（声明式 + 过程式） | `comptime`（编译期执行） |
| 工具链 | 双后端：解释器（脚本）+ C 原生编译 | rustc/cargo | zig build |
| 内存安全策略 | 运行时通知（防悬垂）+ 编译期读写分离 | 编译期借用检查 | 无内建保护，显式即安全 |
| 隐藏控制流 | 无（同 Zig 哲学） | 有（`?`、panic、async 隐式状态机） | 无 |

## 数据类型对照

| H | Rust | Zig | 说明 |
|---|---|---|---|
| `u64` / `f64` / `bool` | `u64` / `f64` / `bool` | `u64` / `f64` / `bool` | 标量一一对应 |
| `Str`（内建动态块） | `&str` / `String` | `[]const u8` / `[]u8` | H 与 Zig 都是"数据区+长度"；Rust 分借用/拥有两种 |
| `[T]`（动态块） | `Vec<T>` | `std.ArrayList(T)` / `[]T` 切片 | 连续数据区+长度；Zig 的切片是借用视图，H 是值 |
| `struct`（块） | `struct` | `struct` | 值语义、连续内存，三者一致；H 用关键字区分形状 |
| `enum` | `enum`（可带数据 payload） | `enum`（无 payload） | H/Zig 无 payload；Rust 的 payload 变体近似"枚举+结构" |
| `class`（树） | `struct` + `Box`/`Rc` | `struct` + 手动堆分配 | **H 独特**：树 = 引用语义 + 双向引用 + 生命周期，是类型系统的一等形状 |
| `ref T`（可写指针） | `&mut T` | `*T` / `*mut T` | H/Zig 显式；Rust 编译器保证别名规则 |
| `move T` | `move`（隐式）+ 所有权转移 | 手动所有权 | H 的移动是**显式关键字**，Zig 无所有权概念 |
| `error T` | `Result<T, E>` | `T \| error`（error union） | H 借鉴 Zig 形态 |
| `Channel<T>` | `std::sync::mpsc` / tokio | 自建（Mutex+Cond） | H/Zig 形态相近；H 是内建 |
| `Exclusive<T>` / `SharedRead<T>` | `Mutex<T>` / `RwLock<T>` | `std.Thread.Mutex` 等 | H 把访问模式做进类型（类型即模式） |
| 泛型 `T<...>` | 泛型（trait 约束） | `comptime` 参数 | H 语法已定（GenericType），实现受限（原型仅 Channel） |
| 函数（一等） | `fn` + 闭包 | `fn` + 闭包（有限） | H 函数可字节化（代码引用+捕获环境），Rust/Zig 无此能力 |

## 生命周期与内存对照

| 机制 | H | Rust | Zig |
|---|---|---|---|
| 所有权 | 单一所有权，`move` 显式转移 | 单一所有权，移动隐式（可显式 `move` 闭包捕获） | 无 |
| 借用 | `ref T`：写透别名，运行时双向引用通知 | `&T`/`&mut T`：编译期借用检查 | 裸指针，无检查 |
| 悬垂防护 | 树对象内嵌被引用链表，销毁时通知所有指针置空 | 借用检查器拒绝悬垂代码 | 无（靠 allocator 纪律 + 防御） |
| 销毁 | 作用域退出自动销毁（树），块零成本 | `Drop` trait | `defer` 显式 |
| 循环引用 | 已决策"先禁用"（实例级成环禁止） | `Rc<RefCell>` 可成环（泄漏） | 手动，成环即泄漏 |
| 分配器 | 显式 allocator（设计，动态块数据区经 allocator） | 全局分配器（默认隐藏） | **allocator 显式传参**（语言级） |
| 拷贝语义 | 块=memcpy，树=引用（不复制） | `Clone`/`Copy` trait 控制 | 赋值即拷贝（值），无自定义 |
| 不可变默认 | 是（`mut` 显式） | 是（`mut` 显式） | 是（`var` 显式） |

## 行为组织对照

| 机制 | H | Rust | Zig |
|---|---|---|---|
| 函数签名 | `x: T` / `ref T` / `move T`；返回 `move/ref/T` | 引用标注 `&`/`&mut`，移动隐式 | 指针显式 `*`，无所有权语义 |
| 组合（替代继承） | class `import` + `hide` + `alias`，方法表提升 | trait 默认方法 + 组合（struct 字段） | 无继承，组合即字段 |
| 接口 | 静态绑定（编译期单态化，无运行期接口值） | `trait`（静态或动态分派） | 无接口；用 `comptime` + 编译期约定 |
| 同名冲突 | 编译期强制处理（hide/alias，R11） | 方法重载受限，trait 冲突编译期报错 | 无方法集，无此问题 |
| 模式匹配 | `match` 穷尽（R10），无绑定/守卫 | `match` 富模式（绑定、守卫、嵌套） | `switch` 穷尽（有限模式） |
| 方法派发 | 静态派发 `Type_method(self,...)` | 静态（单态化）或 `dyn` 动态 | 静态（普通函数 + self 参数） |

## 错误处理对照

| 机制 | H | Rust | Zig |
|---|---|---|---|
| 表示 | `-> error T`，值 = 枚举 | `Result<T, E>` | `error union` |
| 产生 | `return error.X` | `Err(e)` | `return error.X` |
| 展开/处理 | 未处理即终止（打印 + 退出码 1）；`try/catch` 设计（OPEN） | `?` 运算符（编译期展开） | `try` / `catch`（显式） |
| 错误集 | 枚举（块，可字节化/传输） | 类型 `E: Debug` | 全局错误集 + `anyerror` |
| 隐藏跳转 | 无（未处理即终止是显式可观测行为） | `?` 是隐藏返回路径 | `try` 显式 |

## 并发对照

| 机制 | H | Rust | Zig |
|---|---|---|---|
| 执行体 | 统一线程/协程（数据+逻辑），`spawn`/`yield` | 线程 / async 任务（两套） | 线程；async 有限（0.14 起淡化） |
| 调度 | **M:N**：语言级协作式映射多系统线程（C 后端已实现） | 1:1 线程；async 经运行时（tokio） | 1:1 线程 |
| 通信 | `Channel(n)` 内建（容量+等待者队列） | mpsc / crossbeam / tokio 通道 | 自建（锁+条件变量） |
| 共享数据 | 访问模式包装类型（`Exclusive<T>` 等），类型即模式 | `Mutex`/`RwLock`/`Arc` | `Mutex`/`Atomic` |
| 跨执行体规则 | **引用不跨执行体**（数据只有 move 或模式化共享两条路） | `Send`/`Sync` 编译期标记 | 无语言级规则 |
| 生命周期归属 | 执行体挂载于创建它的作用域，作用域退出时提升注册到根对象 | 线程生命周期独立（`JoinHandle`） | 线程独立 |

## 序列化 / 字节化对照

| 机制 | H | Rust | Zig |
|---|---|---|---|
| 内建 | **是**：所有类型自动获得 `to_bytes`/`from_bytes`（可逆自描述 JSON + 版本字段 + 类型注册表） | 否：serde derive | 否：std.json + 手动 |
| 格式 | 可逆、自描述、跨版本（`__ver`）、类型标签校验 | 由库决定（serde_json/bincode…） | 无标准 |
| 块 | memcpy 语义（连续内存直映） | 派生序列化 | 手动 |
| 树 | 序列化压平 + 反序列化恢复（含 ref 字段重连） | 递归序列化（引用需手写） | 手动 |
| 函数 | 代码引用 + 捕获环境（设计） | 无 | 无 |

## 元编程与工具链对照

| 机制 | H | Rust | Zig |
|---|---|---|---|
| 元编程 | 无宏；抽象靠函数 + class 组合（设计取舍） | 宏（声明式 `macro_rules!` + 过程式） | `comptime`（编译期执行任意代码） |
| 编译期求值 | 无（枚举穷尽/方法表/类型注册表是编译期结构） | `const fn` | `comptime` 全量 |
| 构建 | `h build`（探测 zig cc/gcc/cc/clang） | cargo（包管理 + 构建） | `zig build` |
| 双后端 | **解释器 + 编译器同源码**（脚本即正式代码） | 无解释器（rustc 单后端） | 无解释器 |
| 跨平台编译 | zig cc 原生跨编译（已验证 x86_64/aarch64 Linux） | 交叉编译需 target 配置 | 天然交叉编译 |
| 互操作 | C ABI：字节数组为 FFI 边界协议（设计） | FFI（unsafe）+ cbindgen | `@cImport`（内建，无 unsafe） |

## 设计借鉴与取舍

- **从 Rust 借鉴**：单一所有权、作用域销毁、局部类型推断、穷尽 match、不可变默认。
  - **差异**：移动**显式**（Rust 隐式）；不做编译期借用检查，改用**运行时双向引用通知**（防悬垂成本可见，换来约束松、学习曲线平）。
- **从 Zig 借鉴**：error union 形态、无隐藏控制流、显式 allocator、指针显式标注、`comptime` 思想（H 用编译期方法表/类型注册表替代）。
  - **差异**：Zig 无所有权（H 补上）；Zig 无对象组织（H 补上 class 组合 + 接口）。
- **H 独有**：两种内存形状（块/树）是类型系统根基；字节化全类型内建（含树压平/恢复）；双后端（脚本与编译同一份代码）；执行体统一 + 引用不跨执行体；类型即访问模式。

## 对照表小结（能力矩阵）

| 能力 | H | Rust | Zig |
|---|---|---|---|
| 编译期内存安全 | 部分（读写分离/类型约束） | **强**（借用检查） | 无 |
| 运行时防悬垂 | **有**（双向引用通知） | 无（编译期已保证） | 无 |
| 脚本化 | **有**（双后端） | 无 | 无 |
| 一切皆字节 | **有**（内建） | 无（库） | 无 |
| 显式性（无隐藏控制流） | **有** | 无 | **有** |
| 学习曲线 | 平（显式 move + 运行时通知） | 陡（借用检查） | 中（手动内存） |
| 零开销抽象 | 中（树有运行时通知成本） | **高** | **高** |
