# 03 · 生命周期

数据生命周期 = 作用域生命周期。程序是作用域的树形结构。

## 作用域与销毁

- 数据在作用域内**生成、修改、传输、存储、销毁**。
- 退出作用域时，拥有所有权的变量**必须销毁**（显式规则，非隐藏行为）。
- **全局** = 作用域树的根：数据可读写、**不可 move**、需声明访问模式（见 04）。
- 逃逸规则：跨作用域存活的数据通过 `move` 返回（所有权转移给调用方作用域）。

## 所有权

- **单一所有权**：同一时刻只有一个作用域拥有数据的所有权。
- **move 是显式的**（关键字）。move 之后：原变量失效、所有指向它的指针失效。
- 因此借用期间数据不会被销毁——数据会正确销毁。

## 读写权限与变量声明

- 数据创建后具有：所有权、读、写三个特性。
- 拥有写权限才可以写，否则只读。
- 变量声明 Zig 式：可变性显式（`mut` 可写 / 默认只读）。
- **只有可写变量才能声明可写指针**；只读变量只能 move 所有权或创建只读指针。

## 指针（高级指针）

- 保留指针，但采用高级指针（Zig 式）：带类型、带长度（切片）、可空、const 限定。
- 指针**只代理读写、不代理所有权**——所有权只有 move 一条路。
- 写必须显式指定（const 限定，Zig 式）。
- **可写指针**：必须双向引用，且**不跨执行体**。
- **只读指针**：双向引用是**可选项**。
  - 无双向引用的只读指针：**静态作用域规则**保证不悬垂——只能在所有者作用域（或其子作用域）内创建和存活，编译器检查，零运行时成本。
  - 需要逃出该作用域的只读指针：必须启用双向引用。
- 跨执行体的数据访问统一走模式化共享数据（见 04），不提供裸指针跨执行体。

## 双向引用通知

- 指针与数据互相知晓；数据销毁时通知所有指针使其失效；指针销毁时解除链接。
- **内建但可见**：显式运行时成本（注册/通知/解除），确定性、可预见。
- **只对堆上的树数据生效**；块数据（复制语义）不需要。
- 通知机制永远发生在单一执行体内（可写指针不跨执行体；只读指针跨执行体走模式化数据），无跨线程同步成本。

## 内存分配

- **显式 allocator**（Zig 式）：分配点显式传 allocator（默认全局 + 可换）。拼写：`allocator.alloc(T, n)` 方法调用；allocator 参数 `allocator: *Allocator`（可写指针）。
- 块默认栈上；堆上分配永远是显式选择。
- 树的节点、动态块的数据区经 allocator 分配。
- 作用域退出销毁是唯一隐式回收点（且是显式规则）。

## 函数契约（摘要，详见 05）

- 参数：值复制（块）/ 只读指针（树默认）/ `ref`（可写指针）/ `move`（转移所有权）。
- 返回：`move`（带所有权）/ `ref`（可写引用）/ 默认只读值。

## OPEN

- 无双向引用的只读指针逃逸边界的精确静态规则（子作用域深度的形式化）。
- 双向引用通知的数据结构（链表/表）与成本上限。

## 语法（已定拼写）

- 可写变量：`mut x: T = ...`（无前缀 = 只读）。
- 可写指针：`ref T`。
- 转移所有权：`move`（参数 `move T`、返回 `-> move T`、表达式 `move x`）。
- 全局：`global x: Mode<T> = ...`（可读写、不可 move、必须声明访问模式）。
- 分配：显式 allocator（Zig 式）：`allocator.alloc(T, n)` / `allocator.free(ptr)`；allocator 是内建 class 实例，作为参数显式传递（`allocator: *Allocator`，可写指针）。字面量（`[T]{...}`）是编译期数据，零分配（只读数据段）。
