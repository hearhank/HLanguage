# 04 · 并发

## 执行体（线程/协程统一）

- 执行体 = **数据 + 处理逻辑** 的统一组合（语言层面不区分线程/协程）。
- 是程序作用域树的一个分支，有自己的作用域结构。
- **调度：M:N**——语言级协作式执行体，映射到多个系统线程。
- 退出时，其拥有的数据自动销毁（若有所有权）。

## 跨执行体规则

- **引用（指针）不跨执行体**。跨执行体传递数据只有两条路：
  1. **move**——所有权转移（专属数据，无需访问模式；单一所有权保证无竞争）；
  2. **模式化共享数据**——声明了访问模式的数据（含全局）。
- 这使双向引用通知永远在单一执行体内（无跨线程同步，成本确定）。

## 访问模式（类型即模式）

- 跨执行体**共享的数据必须声明访问模式**；全局默认共享，必须声明。
- 模式是**类型的一部分**，用内建包装类型表达；编译器按类型分派实现：

| 模式 | 包装类型 | 实现 |
|---|---|---|
| 单写单读 | `Channel<T>` | 无锁通道（SPSC） |
| 单写多读 | `SharedRead<T>` | 读写锁 / 共享不可变 + 版本 |
| 多写单读 | （内建） | 专属实现 |
| 多写多读 | `Exclusive<T>` | 互斥 / 原子 / 事务 |

- 模式适用于单个数据与集合数据（数组等）。
- 内建而非库：实现需要编译器/运行时的底层支持，且覆盖四种访问模式。

## 全局数据

- 根作用域：可读写、**不可 move**、必须声明访问模式。
- "统一结构"落地：程序提供全部实现框架——共享内存（模式化共享数据）+ 消息传递（`Channel<T>`），由使用方选择。

## OPEN

- 四种模式包装类型的具体 API 与语义（阻塞/非阻塞、容量等）。
- 语法已定部分：`spawn worker()`（创建执行体）；yield 与通信语义见 Q24。
