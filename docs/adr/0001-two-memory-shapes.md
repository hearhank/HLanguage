# 0001 · 两种内存形状作为类型系统根基

数据从内存角度看只有两种形状：**块**（连续内存、复制语义、memcpy 字节化）与**树**（非连续、带引用与生命周期、序列化压平）。类型系统以"内存是否连续"作为第一判据，块只含块、树含值字段（块）与引用字段（树）。

选择以内存形状而非"结构/类"作为根基，是因为它直接决定了复制语义、字节化方式与生命周期成本：块是纯数据（廉价、可自由复制），树是有生命的数据（显式管理）。形状用关键字在声明处显式标注，避免改字段悄悄改变类型形状。

备选：统一 struct 按字段推导形状（被否——形状突变不稳定）、运行时统一值模型（被否——失去静态布局）。
