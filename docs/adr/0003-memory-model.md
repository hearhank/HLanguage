# 内存模型：Allocator + 作用域所有权 + 运行时双向引用跟踪

H 的内存模型由项目所有者定义（2026-08-12），三参考语言均无先例：

- 分配经显式 Allocator 进行，未显式传入时回退到全局分配器
- 每个变量要么拥有所有权、要么不拥有；所有者负责销毁，作用域（无名字的函数/块）退出时自动销毁其拥有的变量；所有权通过 `move` 在作用域间显式转移
- 数据栈对象（自包含连续内存值类型）传参默认复制；其它对象只能通过只读引用、读写引用或 `move` 传递
- 读写引用与目标为强制双向注册关系：目标销毁时引用被标记悬垂，访问悬垂引用抛出带出错位置的错误；同一变量同时最多存在一个读写引用（唯一写者）
- 只读引用与目标为可选双向注册，是否注册是编译期选项：Debug 默认注册（快速定位悬垂），Release 默认裸读（悬垂属用户责任）

这是对 Zig「零开销、用户全责」哲学的主动偏离：H 选择运行时安全网（悬垂检测）换取更友好的脚本体验与更快的 Debug 期问题定位，代价是引用创建/销毁的簿记开销与运行时依赖。**唯一写者的强制机制（编译期检查或运行时登记）尚未定案**，见 SPEC 开放问题。

2026-08-13 细化：所有权是「注册」关系——带 `o` 标记的变量其所有权注册在当前作用域；无 `o` 时注册在别处（如 arena 分配器统一分配与收回）。仅带 `o` 的变量可 move（参数与返回值同理）。`global` 变量位于根作用域上下文，静态生命周期，默认不可 move、无 `o`。

2026-08-13 补充：唯一写者由**运行时登记**强制——同一变量同一时间最多一个可写引用（可写包含可读），重复登记 `write &` 在运行时抛错（携带位置）。不采用编译期借用检查，与「运行时双向引用 + 悬垂检测」模型保持单一路径。

2026-08-13 评审补充：① `*mut` 引用**不可拷贝**，只能 move 传递（Rust 式 &mut 语义）——唯一写者双保险（登记 + 不可拷贝）。② 无 `o` 变量 = 所有权注册在**分配器**（如 arena）上，**禁止 move**（move 须对整个分配器进行）。③ 悬垂/唯一写者冲突 = **不可恢复运行时错误**，与 error union（可恢复）正交。

2026-08-13 Q1–Q3 定案（可移动性谓词）：class/tree 复杂类型实例可 move ⟺ 所有字段及递归子项均不含引用值——仅显式引用字段（`*T`/`*mut T`/`&[T]`/`&mut [T]`）计为引用值，String/Vec 等自有子对象不算（随实例一起转移所有权）——且子项所有权均可随行（无所有权注册在其它作用域的子项，如 arena 分配的对象）。move 转移**整个内存树的所有权**；任一子项所有权在别处 → 编译期禁用 move。Thread/Future/四模式线程类型豁免（语言保证 move 语义安全）；规则约束用户定义类型（Q2）。

2026-08-13 Q1 裁定（可移动性扩展为编译时判定）：所有权归属按**分配来源**编译时判定——非 Arena 分配默认注册当前作用域（显式 `o` 冗余）；Arena 分配无所有权（归 Arena，禁止 move）。move 合法性 = 来源条件（非 Arena）+ 树形内存条件（内存树无外部引用：无向外引用——字段及递归子项无引用值；无向内引用——move 程序点无指向树内节点的存活引用，**编译期别名检查**）。「无向内引用」是 move 点的窄范围编译期别名分析，与运行时唯一写者登记正交（登记管并发写者，别名检查管 move 合法性）。

2026-08-13 Q3 裁定（String 例外取消）：String 定义为 `u8[]`（变长字节数组）的别名，纳入引用类型（评审 B3）——默认传引用、赋值走复杂类型默认语义，复制需显式 `copy`。此裁定**取代 Q16 的「String 值复制例外」**（隐式深拷贝），恢复「无隐式内存分配」原则的无例外地位。

2026-08-13 Q3c 裁定（引用类型赋值语义）：数组/集合/String 等引用类型的绑定级赋值 `var s2 = s1;` = **别名共享**——s2 与 s1 共享同一数据；s1 保持唯一拥有（作用域退出销毁一次），s2 无所有权；深拷贝需显式 `copy`。别名构成对原变量的「向内引用」→ move 原变量编译期禁止（Q1 自洽）；别名不得比拥有者长寿（逃逸检查）。所有权转移必须显式（`move` 关键字），赋值不隐含转移（「没有隐藏控制」）。

2026-08-13 Q25 定案（临时引用生命周期）：表达式产生的临时引用存活到所在完整表达式/语句结束——方法链（builder 形态）整链期间唯一写者资格保持、链末一次注销；绑定到变量的引用存活到作用域结束。链内传递的临时 `*mut` = 同一写者资格的延续（reborrow 精神），衔接开放问题 #2（reborrow 语义）：方法链是自动 reborrow 的典型形态。

2026-08-13 Q26 定案（闭包捕获生命周期 + 销毁顺序）：① 闭包捕获的变量与闭包建立**双向注册**（与 `&` 引用同一模型）——目标销毁 → 闭包标记悬垂（Debug 调用抛错带位置、Release 裸）；闭包存容器合法（捕获随闭包入容器，登记链覆盖，67/72 模式）。② **作用域退出销毁顺序 = 声明逆序（LIFO）**——后声明先销毁，容器先于被捕获目标，常规形态无悬垂；不利时序由登记机制兜底（访问才报错）。

2026-08-13 Q-R7/Q-R8 定案（引用登记定位修订）：① **唯一写者登记**——Debug 默认开启（唯一写者检测 + 悬垂标记，便于即时定位出错位置），**Release 默认关闭**（裸路径、性能优先，接受性能损失换取 Debug 可定位性），由编译时选项控制。② **悬垂语义 = Zig 式**——悬垂由用户负责；双向引用登记是**可选的诊断机制**，非强制安全机制。此前「强制双向注册」「悬垂/唯一写者冲突 = 不可恢复运行时错误」表述由此修订（登记开启时仍为不可恢复运行时错误，带位置）。

2026-08-13 Q-S11 定案（所有权语义重大修订：Zig 式销毁责任模型——**取代 Q1 可移动性谓词、Q-R7/Q-R8 唯一写者登记、Q-S7 reborrow**）：① **所有权 = 销毁责任的唯一归属**——同一时间只有一个对象（作用域/分配器）对「变量退出时销毁其内存」负责，**非访问权限控制**；非 Arena 分配默认作用域负责销毁，Arena 由 Arena 统一负责。② **指针自由**——变量可有多个读写指针（`*mut`）与多个只读指针（`*T`），**指针问题（悬垂/别名）由用户负责**；**唯一写者概念取消**；`*mut` **可复制**（A5「不可拷贝只能 move」取消）。③ **可移动性简化**——move 唯一约束 = 拥有所有权（非 Arena）；旧「内存树无外部引用（无向外/无向内）」谓词取消，指针别名不阻塞 move。④ **Debug 悬垂标记保留为可选诊断工具**（编译时选项：目标销毁时标记指向它的指针，访问提示带位置；非安全保证）。⑤ **reborrow 概念取消**（无写者资格——传参即指针传递）；Q25 临时引用生命周期保留（临时值语句末失效），Q-S7 作废。

2026-08-14 Q1'/Q5'/Q2' 定案（赋值语义 + 所有权情况全录——**取代 Q3c 引用类型赋值 = 别名共享**）：① **引用类型赋值 = 编译错误**——`var s2 = s1;`（数组/集合/String）不合法；共享数据走显式指针（`&s1`，指针问题用户负责），复制走显式 `copy(&s1)`（新建内存、有所有权）；`copy` 默认深复制，浅复制需显式标注（如 `copy(&s1, .shallow)`），浅复制引入的内存问题由用户负责。② **move 后原绑定仍可访问**——move 不复制数据、不移动内存、变量本身不变；原作用域退出不再销毁；继续访问造成的悬垂/冲突由用户负责（指针自由哲学延伸）。③ **global 有所有权（归根作用域）**——凡分配器分配皆有所有权；global 所有权归根作用域（程序/库），程序退出时销毁；不可 move（移出即失去全局性）；旧「global 无 o」表述修订。④ **所有权情况全录**（无所有权：值类型/指针与切片自身/Arena 对象；有所有权：当前作用域 / Arena / 根作用域(global) / 父对象(owned 字段) / copy 新对象；转移：move 函数参数与返回值 / 字段带 owned 赋值 / 线程捕获；禁止 move：Arena / global / 无所有权对象；销毁时机：作用域退出递归 / 根作用域退出 / Arena 统一回收 / defer 显式）——完整清单落点 CONTEXT.md 所有权章节。
