# 0002 · 单一所有权 + 显式 move + 双向引用通知

所有权采用**单一所有权**（一个作用域拥有一份数据），但 move 是**显式关键字**（不同于 Rust 的隐式移动）；move 后原变量与所有指针失效。指针只代理读写、不代理所有权。销毁安全由**运行时双向引用通知**保证：数据与指针互相知晓，所有者销毁时通知所有指针失效。

双向引用通知是"内建但可见"的显式运行时成本，且只对堆上树数据生效（块数据复制语义不需要）。这是"无隐藏控制流"与"无悬垂指针"之间的折中：不做 Rust 式编译期借用检查（复杂、约束强），也不用 GC（隐藏控制流），而是把生命周期保护做成可见的运行时机制。

备选：Rust 式借用检查（被否——学习曲线与约束过强）、GC（被否——隐藏控制流）、裸手管理（被否——悬垂风险）。
