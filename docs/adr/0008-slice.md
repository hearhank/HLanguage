# 0008 · 切片：借用视图 + 双向引用通知推广

切片 `[]T` 是**借用视图**（不拥有的 `[ptr, len]`），只指向堆上动态块数据区（动态块/Str/动态块字段），栈值不可切片。**双向引用通知从树推广到堆上块数据**（ADR 0002 的扩展）：动态块/Str 销毁时通知指向它的切片置空——打破"块无引用"的纯净性，但兑现"无悬垂指针"承诺；动态块因此获得生命周期钩子（顺带解决数据区释放）。语法 Zig 式：`s[a..b]` range、`mut` 可写（写透原数据区）；`[T]`→`[]T` 传参自动借用，反向显式 `clone()`。

生命周期采用**借入不借出**粗规则（R12）：切片不得返回、不得入字段/全局、不得作 spawn 参数——编译期拒绝，不做 Rust 式生命周期标注；同作用域内数据先销毁由运行时通知置空兜底。拒绝选项：Rust 式借用检查（既有决策——约束过强）、接受悬垂（违背无悬垂承诺）。
