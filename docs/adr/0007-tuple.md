# 0007 · 元组：块值、严格分离、解构混合

元组是**块**（连续内存、值语义、元素必须块），语法取 Rust 式（`(T1, T2)` 类型、`(v1, v2)` 字面量、`.0/.1` 访问、`()` 空元组、`(v,)` 单元素尾逗号），并允许命名（`(x: T1, y: T2)`、`.x/.y` 访问）。位置与命名**严格分离**：禁止混用，命名元组是带字段名的独立块类型（字段名参与类型与字节化标签）。解构 `(a, b) = f()` 同时支持声明新建与覆盖已有变量（逐元素可写性检查，R4）。字节化：`__shape:"block"` + `__items`（位置）/`__fields`（命名，无 `__type`）。

选严格分离而非"命名是糖"：命名元组带字段名使类型可自描述（字节化/跨语言），混用时"第几个"的语义微妙。选解构混合：`(a, b) = (b, a)` 交换与多返回值是元组核心价值，声明与赋值统一逐元素处理。
