# ADR-0037: 词法与声明层修订（局部推断 / 逻辑运算符 Rust 化 / 嵌套注释 / 字符码点化 / 数字字面量报错 / tree 移除 / 解构范围 / f32 宽度）

2026-08-31 裁决（项目所有者 Hank，对照 Rust/Zig 的词法层评审后 8 项决定）。本 ADR 修订 D1/D2/G2/H1（`01-lexical-declarations.md` §1.14）、E1（`02` §2.20）、F1（`03` §3.12）的部分条款。

## 决策

| # | 条目 | 裁决 | 修订对象 |
|---|---|---|---|
| D8 | 变量类型推断 | **`var` 局部推断为正**——类型注解可省略，从初始化器推断；**仅无法推断时**（无初始化器/无法定型）报诊断要求显式标注。取代 H1 裁决中「注解必须显式」的排期（推断自举后实现 → 立即实现）。函数参数/返回类型仍必须显式（与 Rust 一致）；`global` 有初始化器可推断，无初始化器（零值）必须显式标注 | `01` §1.9.1、`03` §3.9 |
| D9 | 逻辑运算符 | **Rust 语法为正**：`&&`/`\|\|` 是逻辑与/或的本体 token（不再词法重写为 `and`/`or`）；**`and`/`or` 从关键字表移除**（变普通标识符）。`&&` 不再被吞并——但它不是双引用（H 无 `&&T` 形态，取址的取址不支持）。`\|\|` 的错误集联合特例（`const E = A \|\| B;`）保留 | `01` §1.2.1/§1.2.2、D2/E1 的「兼容别名」定位作废 |
| D10 | 块注释 | **支持嵌套**（`/*` / `*/` 计数配对）；未闭合仍报 `unterminated block comment` | `01` §1.3 |
| D11 | 字符字面量 | **词法 Rust 化 + 定型维持 comptime_int**：字面量 = Unicode 标量码点——支持 `\u{...}` 转义与直接书写非 ASCII 字符（`'中'` 合法）；token 携带 u32 码点；语义定型维持 comptime_int（码点值），ASCII 场景行为不变（存量零迁移）。取代 D1 的「单 ASCII 字节」限定。显式 `char` 类型为后续提案 | `01` §1.5、`03` |
| D12 | 数字字面量前缀错误 | **词法层直接报错**（参考 Rust/Zig）：`0x`/`0b`/`0o` 前缀后无有效数字位 → 词法诊断 `invalid hex/binary/octal literal`，不再产出 `Int(0)` + Ident 的延迟错误 | `01` §1.4.1 |
| D13 | `tree` 关键字 | **移除**（关键字表、token、声明分支全删；`tree` 变普通标识符）。取代 G2 的「保留关键字暂不实现」——连预留都不保留，未来需要单独立项 | `01` §1.2.1、`04` §4.5 |
| D14 | 解构范围 | **前期目标 = 元组解构 + 函数多返回值解构**（含 `_` 忽略位）✅ 已达成；全场景（赋值左侧、参数位、match 等）保留 ⏳。D6 的「解构不支持 `mut`」不变 | `01` §1.9.3、D7 |
| D15 | 浮点宽度 | **f32 真实宽度重新实现，`f16` 移除**（词法后缀 `f16` 不再合法；`f32`/`f64` 保留且语义区分）。修订 F1（f16/f32 双真实宽度 → 仅 f32）。**实现单列专项**（`SType::Float` 宽度化 + IR/VM 算术 + LLVM + 字面量定型），本轮只落文档 | `03` §3.2.2、backlog #5 改写 |

## 影响

- **Lexer**（`hc/src/lexer/mod.rs` + `stage1/lexer.hc` 双侧同步，k1 对拍要求）：`&&`→`AndAnd` token；关键字表删 `and`/`or`/`tree`；块注释嵌套计数；`lex_number` 前缀报错；`lex_char` 码点化。
- **存量迁移**：全仓库 `.hc`（stage1/examples）`and`→`&&`、`or`→`\|\|` 词边界替换；corpus 01-keywords（45→42）/03-numbers/05-chars 预期同步。
- **Semantic**：`var` 无注解无初始化器 → 诊断；推断路径已有（`declared.or(init_ty)`）转正。
- **Parser**：`parse_and` 接受 `AndAnd`；`parse_decl` 删 KwTree 分支。
- **文档**：`01` 全面修订、`03` §3.2.2/§3.9 修订、`00-index.md` backlog 调整。
