# 多线程模型：四模式类型 / 线程所有权 / 捕获规则

2026-08-13 项目所有者定义多线程模型（三参考语言均无此组合，H 自主设计）：

- **四模式共享类型**：单读单写/单读多写/多读单写/多读多写 = 内建泛型**共享内存容器** `OneToOne(T)`/`OneToMany(T)`/`ManyToOne(T)`/`ManyToMany(T)`；写者数量由类型名保证（单写者无锁路径、多写者互斥）；脚本生成实例化
- **线程所有权**：spawn 归当前作用域；作用域退出：已完成→销毁、运行中→所有权移交根作用域（**无隐式阻塞**）；显式 `join() !T` 消耗所有权，错误以 error union 跨线程传播
- **捕获规则**：值类型复制值；引用类型必须 move 所有权或为 global（**无只读引用捕获**——线程可能比作用域长寿，防悬垂）；线程捕获 ≠ 闭包捕获（12.9）

选择理由：「以数据为中心」——共享状态是「数据 + 访问控制」的容器，而非散落的锁原语；线程所有权与捕获规则从根上杜绝悬垂（无隐式阻塞符合「没有隐藏控制」）；错误处理跨线程一致（error union）。

代价：四模式类型需精心实现同步原语（单写者无锁、多写者互斥）；线程移交根作用域后的回收需运行时支持；Send/Sync 式静态标记需与运行时簿记配合（SPEC 开放问题 #5）。
