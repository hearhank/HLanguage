# 显式所有权模型：`owned` + `defer`/`move` 替代自动作用域销毁

2026-08-25 定案。本 ADR 取代 ADR-0005 中关于所有权自动销毁的条款（其余语法约定仍有效）。

## 背景

原所有权模型（ADR-0005 / ADR-0003）采用「默认注册当前作用域，退出自动销毁」——凡由分配器分配的对象，作用域退出时自动递归销毁。`defer` 仅用于文件句柄等少数外部资源。

实践中发现此模型与 H 语言「无隐藏控制」的核心哲学冲突：自动销毁是隐式控制流，用户无法在销毁点插入自定义逻辑，且与非 Arena 堆对象的生命周期管理耦合过紧。

## 决策

所有权模型改为**完全显式**——以 Zig 为标杆，去除所有隐式销毁：

### 规则

1. **作用域不自动释放任何资源**。堆创建的对象、文件句柄、数据连接等外部资源，统一用 `defer` 在退出作用域时显式释放。
2. **无 `defer` 则必须 `move`**。`owned` 变量必须要么有对应的 `defer` 语句，要么通过 `move` 将所有权转移出当前作用域。否则编译错误。
3. **变量三种权限**：可读（默认）、可写（`mut` 标注）、拥有（`owned` 标注）。三权正交，可独立组合。
4. **栈 / Arena 分配无所有权**。栈上创建的标量/Continuous 类型，以及 Arena 分配器分配的对象，均无所有权，不需要 `defer`，由栈或 Arena 统一管理。
5. **`owned` 变量只能 move 一次**（affine type）。move 后原变量不再拥有所有权，再次访问原变量是用户错误（编译期暂不检查，悬垂指针后续做静态检测）。
6. **`move` 转移内存管理责任**。`move` 将资源的销毁责任从当前作用域转移到目标作用域（函数参数/返回值/通道）。转移后当前作用域不再负责释放。因提前释放导致的悬垂指针问题由用户负责（后期加强静态检查）。

### 类型标注

| 标注 | 权限 | 说明 |
|------|------|------|
| `T` | 只读 | 值类型或不可变引用 |
| `mut T` | 可写 | 允许修改，无所有权 |
| `owned T` | 拥有 | 拥有所有权，必须 `defer` 或 `move` |
| `owned mut T` | 拥有 + 可写 | 拥有所有权且可修改 |

函数参数类型：

| 参数类型 | 语义 |
|----------|------|
| `T` | 值类型（复制/借用） |
| `*T` | 只读指针 |
| `*mut T` | 可写指针 |
| `owned *T` | 拥有所有权 + 只读指针 |
| `owned *mut T` | 拥有所有权 + 可写指针 |
| `owned T` | 兼容 `owned *T`（自动收窄） |
| `owned mut T` | 兼容 `owned *mut T`（自动收窄） |

### defer 语义

- `defer` 在作用域退出时执行（正常路径和错误路径均执行）
- 多个 `defer` 按**后进先出（LIFO）** 执行
- `errdefer` 仅在错误路径执行，语义不变

### 与现有模型的关系

- `o` 关键字不再使用（由 `owned` 取代）
- `r`/`wr` 引用语法已由 `*T`/`*mut T` 取代（ADR-0005 2026-08-13 修订已确认）
- `move` 关键字保留，仅出现在调用点
- `owned` 关键字已在词法/语法层面存在，本 ADR 使其语义生效

## 影响范围

1. **语义分析**（`semantic/`）：新增 `owned` 变量的语义检查——必须匹配 `defer` 或 `move`
2. **IR 降级**（`ir/`）：新增 `IrInst::Defer` 指令
3. **解释器**（`hc-rt/interp/`）：`defer` 栈执行
4. **LLVM 后端**（`codegen/llvm/`）：`defer` 代码生成
5. **标准库**：文件句柄、网络连接等资源类型添加 `owned` 标记，示例代码添加 `defer`

## 迁移策略

分阶段实施：

1. **Phase 1（warning）**：语义分析中 `owned` 变量无 `defer`/`move` 时产生 warning，不影响编译
2. **Phase 2（error）**：warning 升级为 error，强制所有 `owned` 变量必须匹配 `defer` 或 `move`
3. **Phase 3（示例迁移）**：更新全部示例代码，添加必要的 `defer` 语句
