# 0004 · 执行体模型：引用不跨执行体 + 类型即模式

线程与协程统一为**执行体**（= 数据 + 处理逻辑），M:N 调度（语言级协作式映射到系统线程）。**指针不跨执行体**：跨执行体传数据只有 move 或模式化共享数据两条路。并发安全由**类型即模式**保证——四种访问模式（单写单读/单写多读/多写单读/多写多读）是内建包装类型（`Channel<T>`、`SharedRead<T>`、`Exclusive<T>` 等），跨执行体共享的数据（含全局）必须声明模式。

这套模型让双向引用通知永远在单一执行体内（无跨线程同步成本），把并发安全的全部责任收敛到模式化数据上，与"单一所有权 + move"形成三层闭环：同执行体内 = 通知机制（不悬垂）+ 编译期读写分离（不冲突）；跨执行体 = move 或模式化共享（不竞争）。

备选：裸指针跨线程（被否——悬垂与竞争）、运行时统一调度器（被否——隐藏控制流）。
