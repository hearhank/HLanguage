# 所有权与引用语法：o / move / r / wr / write & / global

H 的所有权与引用采用显式标记语法（项目所有者定义，2026-08-13），与 ADR-0003 内存模型一一对应：

- `var [write] name: [o]T = init;` — 声明关键字 `var`；默认只读，`write` 修饰可写；`o` = 所有权注册当前作用域（退出时销毁），无 `o` = 注册在别处（如 arena 分配器、全局存储）
- `r T` 只读引用 / `wr T` 读写引用；`&x` 只读地址，`write &x` 可写地址（目标须 `var write`，读权限可降级：`&` 对只读/可写变量均合法）
- `move` 仅对带 `o` 的变量合法，转移所有权到函数参数或返回值；`move` 参数在函数内**隐含拥有**（函数作用域接管，退出自动销毁）；`move` 与 `r`/`wr` 正交（`move y: r T` 允许）
- 类型省略：T 与 `r`/`wr` 描述可省略、由系统推断；`o` 不参与推断，由声明显式决定
- 返回值：函数内新建的值必须 move 返回（无所有权的除外）；返回引用必须指向函数参数（悬垂防护），细节待讨论
- `global` 变量：根作用域上下文，静态生命周期，默认不可 move、无 `o`
- **唯一写者**：同一变量同一时间最多一个 `wr` 引用（可写包含可读），由运行时登记强制（双向引用注册冲突即抛错带位置）；`wr` 引用**不可拷贝**，只能 move 传递（评审 A5，2026-08-13）

选择运行时强制而非编译期借用检查：与「运行时双向引用 + 悬垂检测抛错」的内存模型保持单一路径（无隐藏控制），代价是 `wr` 引用创建/销毁的运行时簿记（见 SPEC 风险登记）。

所有权语法（`o`/`move`/`r`/`wr`/`write &`/`global` 及省略规则）已全部定案；返回值引用规则的具体细节待后续讨论。

**2026-08-13 评审修订（Rust 标杆，已定稿）**：引用语法改为以 Rust 为标杆——取引用 `&x`（类型 `*T`）、可写引用 `&mut x`（类型 `*mut T`）；绑定级可写 `var mut x`（R1 定案）；切片 `&[T]`/`&mut [T]`（R2 定案，取段 `&arr[1..3]`/`&mut arr[0..2]`）。`mut` 为当前占位符，后续可替换为其它词（如 `write`）。`r T`/`wr T`、`write &x`、`write` 修饰分别由 `*T`/`*mut T`、`&mut x`、`mut` 取代。

**2026-08-13 Q1 裁定（所有权判定修订）**：所有权不再由 `o` 标注决定，改按**分配来源**编译时判定——非 Arena 分配默认注册当前作用域（`o` 为可选冗余标注）；Arena 分配无所有权（归 Arena，禁止 move）。可移动性 = 来源条件 + 内存树无外部引用（见 ADR-0003 条注）。此前「无 `o` 变量禁止 move」「`o` 由声明显式决定」表述由此裁定取代。

**2026-08-13 Q7 定名（`mut` 占位符解除）**：可写修饰定名为 `mut`（Rust 标杆），不再允许替换为其它词；关键字/token 清单冻结（见 06 §1）。

**2026-08-13 Q15 裁定（`o` 适用范围收紧）**：`o` 标注仅适用于**分配器分配的对象**（复杂类型/装箱指针）；标量/纯值 struct 上写 `o` = **编译错误**。可移动性判定不变：非 Arena（默认拥有）+ 内存树无外部引用（见 ADR-0003）。

**2026-08-13 Q22/Q22b 定案（参数签名制 + 接口约束）**：参数签名统一为**类型标注制**——`o T`（拥有）/ `*T`（只读引用）/ `*mut T`（可写引用），`move` 关键字仅保留在调用点（`take(move s);`，Q23）。接口约束 = 签名末尾 **where 子句**：`fn add(a: *T) void where T: INumber`，调用点 `add(&a)` / `add(&mut a)` / `add(move a)`。此前「`move y: *mut T` 参数签名声明 move」的表述由本裁定取代。
