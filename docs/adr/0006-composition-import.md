# 0006 · class 导入机制替代继承

组合（class）提供类似 class 的能力但**无继承**：扩展通过**导入**（嵌入）——A 导入 B 即自动获得 B 的方法并自动继承 B 的接口标注，可选择性隐藏。同名冲突规则：自己定义的方法优先（导入的同名自动隐藏）；多个导入对象之间的同名方法强制显式处理（隐藏或别名）。导入深度传递、循环编译期拒绝。

选择嵌入式组合而非继承，是为了保住"一切都是数据"：继承引入对象身份与可变 `this`，破坏值语义、字节化与生命周期模型。导入的自动能力提升 + 显式消歧是 Go 嵌入与 Rust trait 的折中——少写代码，同时契约依然可见。

备选：经典类继承（被否——对象身份破坏数据模型）、仅手动组合（被否——方法提升的仪式感过重）。
