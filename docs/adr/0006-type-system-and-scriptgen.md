# 类型系统与元编程：struct / 复杂类型 / 接口 / 脚本生成

2026-08-13 项目所有者重构类型系统与元编程机制（三参考语言均无此组合，为 H 自主设计）：

- **struct**：值类型，底层连续内存（字节数组）；字段只含标量、struct、定长数组、切片；**不含复杂类型字段**（堆数据一律进复杂类型）
- **复杂类型**：堆上类型，用关键字声明（1.0 最小集 `class`、`tree`，家族可扩展）；连续或不连续内存；**组合形式**，字段可含标量、struct、其它复杂类型，字段可带 `o`
- **接口**：方法契约集合，**显式声明实现**（Rust 式）；可描述复杂类型、标量、内建类型、用户 struct；不提供运算符重载
- **脚本生成替代 comptime**：`script` 作用域标注脚本代码，编译前由脚本解释器执行并生成代码（对应 Zig 的编译时生成，用脚本表达）；脚本用 H 编写，解释器支持实时预览与校验

选择理由：脚本生成与双模式执行同源（H 的脚本模式即生成器运行时）；「以数据为中心」= 数据定义驱动四大支柱样板生成；接口显式实现符合「没有隐藏控制」。

代价：失去 Zig 式编译期求值的紧耦合（comptime_int 等退化为纯类型规则）；脚本运行器需在编译前可用（M3 依赖脚本模式 VM 的先行子集，里程碑排期调整）。

**2026-08-13 修正**：语言内**保留 Zig 式 comptime 功能**（泛型等类型级计算：编译期函数、类型即值）；脚本生成负责样板与数据定义驱动的代码生成。分工已确认（X1）：comptime 管类型级计算（泛型、类型即值、惰性实例化、comptime_int）；脚本生成管样板与数据定义驱动代码生成。

**2026-08-13 评审补充（A4/B1/D1）**：① 脚本生成**必须实现**（核心特性），但「数据定义 → 样板」场景下脚本功能**可选**（comptime 承担生成）。② 脚本语言 = **H 核心子集**（在特定分配器、特定 IO 下运行，尽可能与 H 核心一致）——若摩擦过大，后续可定义受限子集。③ 表述统一：「脚本生成与 comptime 双轨」。

**2026-08-13 Q2 裁定（struct 字段集放宽）**：struct 字段可含复杂类型（String/集合/class），与 class 成员集一致（Q22）。纯 POD struct（字段全为标量/纯值 struct）为连续字节、可 `to_bytes` 直映射；含堆字段的 struct 本体仍内嵌字段值（指针+长度），序列化走递归（非 POD）。struct 与 class 差异收敛为：值语义（可内嵌、无分配器）vs 堆上引用类型（需分配器）。此前「struct 不含复杂类型字段」表述由本裁定取代。

**2026-08-13 Q17 定案（接口指针表示）**：`*Shape` 接口指针 = 胖指针（data 指针 + 虚表指针，两字宽）；`box` 装箱产生，具体指针 → 接口指针**编译期自动收窄**（接口实现检查）；胖指针 data 部分参与双向引用登记（悬垂检测/唯一写者与普通指针一致），虚表不参与（编译期静态）。接口引用无运行时安全例外——与内存模型单一路径。

**2026-08-13 Q22/Q22b/Q22c 定案（接口参数 = 虚拟类型 + where 约束）**：接口类型传参用**带约束的虚拟类型**，约束放签名末尾 where 子句：`fn add(a: *T) void where T: INumber`。形态映射 `&T`→`*T`（只读）/ `&mut T`→`*mut T`（可写）/ `move T`→ `owned T`（拥有）；调用点 `add(&a)` / `add(&mut a)` / `add(move a)`。静态分发（单态化无虚表）为主路径；动态分发（`*Shape` 胖指针装箱）保留给异构集合。io 参数：库函数统一 `io: *T where T: Io`；入口 `fn main(io: Io)` 为编译器注入特例。

2026-08-13 Q23 定案（脚本输入机制）：script 块 = 编译前执行的 H 表达式块（H 核心子集），产物 = 生成代码字符串，就地替换本块；输入 = 上下文隐式 `types` 元数据对象（`types.fields("Person")` / `types.type("Person")` / `types.all()`），由编译器从类型系统生成注入；脚本用 H 字符串操作遍历类型定义拼接生成代码，无第二语言。

**2026-08-14 定案（struct/class 合并 + Continuous + 元组 + Table——重大修订，取代本 ADR 第 3/6/7 行与 Q2 裁定的 struct/class 分立）**：① **统一关键字 `class`**（`struct` 删除）——默认 class 语义（堆上、需分配器、接口描述功能、字段可带 `o`、可 move、构造 = `new()`/普通函数返回、`to_json`）。② **内建布局特性 `Continuous`**（`class Point: Continuous`）——编译器验证字段全为值类型（标量/枚举/Continuous/元组），获得值语义全集：无分配器/可内嵌/赋值即复制/`to_bytes` 直映射/`packed`/`align(N)`/字面量构造 `X{...}`。③ **元组**——无名称、字段只读的匿名值类型（天然连续内存）：`(1, "a")`、`t.0` 访问、**支持解构**（`var (a, _) = t;`，`_` 放弃值）。④ **Table<T>**——内建二维结构代替 `[M][N]T`：`table(rows, cols, init)`、`t[i, j]`、定长、引用类型、行主序可 `to_bytes`。⑤ `tree` 保留。落点：CONTEXT §4、01 §12.12/12.19/12.20、06 §2、04 序列化分层。

**2026-08-14 定案（标量类型体系：INumber 族——内建标量接口化）**：① **`INumber`** = 所有数字的基本契约：`add`/`sub`/`mul`/`div`/`neg`/`eq`/`lt`（签名 `fn add(self: *Self, other: Self) Self`）。② 子接口：**`IInt`**（`i8`–`i128`/`isize`，+`mod`/`abs`）、**`IUint`**（`u8`–`u128`/`usize`，+`mod`）、**`IFloat`**（`f16`–`f128`，+`abs`/`pow`）——均实现 `INumber`；内建标量编译器内建实现（不可重载）。③ **运算符绑定 INumber 族**：`+ - * /`（及一元 `-`、`==`、`<`）作用于所有实现 INumber 的标量，`a + b` ≡ `a.add(b)`；`!=`/`<=`/`>`/`>=`/`%`/`%%` 编译器派生；无用户运算符重载。④ 类型名保留小写（`i32` 实现 `IInt`），接口名大写。⑤ 泛型约束 `where T: INumber` 可约束标量（示例 86-scalar-interfaces.hc）。落点：CONTEXT §4 标量类型体系、01 §12.2/§12.16、06 §2 类型表与标量接口族小节。

**2026-08-14 定案（比较接口化 + 连续内存内部化 + 补充定案——修订前两条）**：① **比较接口 `ICompare`**（`eq`/`lt`，派生 `ne`/`le`/`gt`/`ge`）——`INumber : ICompare`（比较能力经继承获得）；**相等 `==`/`!=` = 语言内建通用**（标量按值/String 按内容/指针按地址/枚举按标签/class 按身份）；**序比较 `< <= > >=` 绑定 `ICompare`**（String 编译器内建实现；未实现则编译错误）。② **连续内存 = 语言内部机制（用户不可标注）**——存储形态编译器自动判定：字段全值类型（标量/枚举/**定长数组（新增允许）**/元组/连续类型）→ 连续内存值类型；含引用/堆字段 → 堆上；强制堆上分配全值对象用 `box()`；示例中 `: Continuous` 标注全部移除。③ **多值返回**：`fn f() (T1, T2)` 返回元组、`var (a, b) = f();` 解构、`E!(T1, T2)` 合法。④ **`table(alloc, rows, cols, init)` 显式分配器**。⑤ **标量装箱**：`box<i32>` → `*INumber`/`*mut INumber`（接口 = 类型标注，Q17 统一）。⑥ **接口实现标注正式定案**：冒号后缀 `class Foo: I1, I2`（去「待定」）。⑦ **`packed class` 字段集扩展**：标量/枚举/连续内嵌/元组/定长数组。⑧ **元组比较/序列化**：`==` 逐元素、`to_bytes`、可作 Map 键；**序列化 = 默认接口**（to_bytes/from_bytes、to_json/from_json 为内建接口契约，编译器实现不可重载）。落点：CONTEXT §4（标量类型体系/类型定义/连续内存/元组/Table/接口）、01 §12.2/§12.12/§12.16、06 §2 类型表/类型定义/接口/标量接口族、示例 13/19/24/30/50/57/58/64/81/86。

**2026-08-14 定案（H1–H5 可行性 review 裁决——修订②③④与上条）**：① **H1 特性标注**——存储形态改由**特性标注**决定（取代自动判定）：类型声明上方中括号 `[name]`/`[name(参数)]`——`[continuous]`（连续内存，编译器验证字段全值类型）、`[pad]`（紧凑打包，原 packed）、`[align(T)]`（对齐到类型 T 的对齐值，如 `[align(u64)]` = 8 字节）；未标注 → 堆上（构造 = `alloc.init(T)` 分配器按类型自动大小创建实例）。② **H3 相等比较**——`==`/`!=` = **值比较，内部调用 ICompare 方法**；**class 身份比较删除**（class 需实现 ICompare 才有 `==`）；**指针比较 = 指向对象地址**（数组指针/切片含位置 + 长度）。③ **H4 切片**——**数组的引用默认就是切片**（`&arr` 直接产生切片）；切片 = 带索引位置和长度的指针。④ **H5 元编程**——script = **编译前**执行（无运行时环境，模板生成），类型信息可见 = 所在作用域（class 内 → 该类；namespace 下 → 整个命名空间），**生成物不得与当前环境冲突**；comptime = **编译时**执行（完整类型系统）。⑤ **Q3 成员可见性**——方法默认公开（`pub`）、属性默认私有（`private`）；`pub mut A: owned T`（可见性/可写/类型形态分离）；**属性无所有权标注**（所有权由类型实例管理）；`alloc.init(T)` 构造。⑥ 类型名保持 `i32`（无 int）。落点：CONTEXT §4/§6、01 §12.2/§12.11/§12.12/§7、06-01/02/03/05/06/09、示例 13/19/24/30/50/57/58/64/81/86/88。

**2026-08-14 定案（M1–M8 可行性 review 中严重度裁决）**：① **M1 重载解析顺序**——① 精确参数数量匹配（忽略默认值）→ ② **具体非泛型候选优先于泛型候选** → ③ 泛型按 where 编译时验证 → ④ 同等匹配歧义报错（恢复 87 示例行为，统一文档）。② **M2 期望类型传播**——类型检查器 expected-type 通道：已知目标类型时优先选返回类型匹配的重载（TS 式）。③ **M3 String = 内建新类型**（布局同 `Vec<u8>`，编译器内建实现；`as_slice` 零成本互转；取代「别名」表述）。④ **M4 拥有迭代**——`IIterable<o T>` = 迭代器持有容器所有权（x move 进迭代器、next 逐元素转移、迭代后容器不可再用）。⑤ **M5 胖指针三字宽** = data + 虚表 + alloc 引用（装箱携带分配器，销毁用携带 alloc 释放）。⑥ **M6 测试矩阵**——`hc test` 脚本 Debug；`--mode=compile` 编译 Debug（含错误路径用例）；`--release` 编译 Release（仅正常路径子集）。⑦ **M7 global 跨文件初始化**——按初始化表达式依赖图拓扑排序（无依赖按文件声明序；循环依赖编译错误）。⑧ **M8 Table 语法**——`Table<T>.init(alloc, rows, cols, init)` 方法构造（统一集合形态）、`t[i, j]` 多参索引（仅 Table 合法）。落点：01 §4/§12.8/§12.16/§12.19、06-01/02/03/04/05、CONTEXT §4/§5、ADR-0006。

**2026-08-14 定案（L1–L6 可行性 review 低严重度裁决）**：① **L1 `.name` 推断枚举值字面量**（参数/字段类型已知时 `.Name` 推断为对应枚举变体）；`copy` 的浅复制模式 = 内建枚举 `enum CopyMode { deep, shallow }`（`copy(&x, .shallow)` ≡ `copy(&x, CopyMode.shallow)`）。② **L2 构造**——`alloc.init(T)` = 唯一通用构造（分配器按类型自动大小 + 创建实例，字段显式初始化）；`Foo.new(...)` 保留为脚本生成便捷样板（alloc 首参 + 字段序，E1 实现）。③ **L3 `ExitType` = 语言内建枚举**（编译器提供，落 M4；`Exit`/`Error` 固定，扩展走 code 参数）。④ **L4 `for` 值类型自动取引用**——`for (fib)` ≡ `for (&mut fib)`（可写）/ `for (&fib)`（只读）；只读绑定时可写迭代编译错误。⑤ **L5 错误码 = 「包 ID + 包内码」编码**（高位包 ID、低位包内序——静态链接与动态库均无冲突，M6 细化）。⑥ **L6 `@intFromEnum` 返回 `usize`（平台宽度）**——序列化/固定宽度场景显式 `@intCast`。落点：06-01/03/04/07、总纲、ADR-0006。至此可行性 review 全部 19 项（H1–H5 + M1–M8 + L1–L6）裁决完毕。
