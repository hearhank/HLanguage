# script 块语义定案：编译前求值 + 文本区间替换 + 受限子集

> 2026-08-18 定案（第三块前置裁决 A3）。关联：[ADR-0006 类型系统与脚本生成](0006-type-system-and-scriptgen.md)、[ADR-0012 comptime 类型即值](0012-comptime-type-values.md)、[06-09-meta.md](../SPEC/06-09-meta.md)、[01-language-design.md](../SPEC/01-language-design.md)（评审 B1 脚本生成必须实现）、[05-open-questions-and-risks.md](../SPEC/05-open-questions-and-risks.md)（评审 C3 供应链风险）、执行细表 [10-part3-execution.md](../SPEC/10-part3-execution.md)。

## 背景

- **06-09 H5 定案（2026-08-14）**：script 块 = **编译前**执行（解释器），无运行时环境（io/alloc/argv 不可用），一般只做模板生成；类型信息可见范围随块位置收窄（class 内 → 该类；命名空间下 → 整个命名空间）；生成物与当前环境同名 = 编译错误；产物 = 生成的代码字符串**就地替换本块**（Q17）；脚本失败 = 编译错误（同一错误机制）
- **评审 C3（供应链风险）**：依赖包中的 `script` 块在构建时执行任意代码 → 需 build.zon 指纹校验 + 依赖来源审计 + 脚本 = H 核心子集（受限分配器/IO）
- **Q-S10 降级闸门**：若成本超预期 → 降级为「脚本生成 = 编译期执行 H 子集函数（comptime 内联）」，`script{}` 语法保留
- **缺口**：「就地替换」的**精确机制**未定——替换什么文本区间、替换后是否重解析、types 元数据对象的具体形态与求值环境

## 决策

1. **执行流程（装载时重解析）**：`hc` 装载一个文件时——① 词法/解析得 AST（含 `script { }` 块节点，节点携带**源码文本区间**）；② 对每个 script 块（按出现序）：求值块体（解释器子集）得**产物字符串**；③ 产物字符串**替换该块节点的源码文本区间**；④ 修改后的源码**重解析**进完整编译。脚本块自身不产出运行时代码（替换后即消失）
2. **求值环境 = 受限 H 子集**：脚本体可用的语言构造 = 标量/字符串/集合/错误 union/函数调用（模板拼接所必需）；**io/alloc/argv/线程/网络不可用**（无运行时环境）；`types` 元数据对象按块位置注入（见 4）。求值器 = 复用解释器子集，不另起语言
3. **产物形态 = 合法声明序列**：产物字符串须为一个或多个**顶层/所在作用域合法声明**（class/fn/enum/interface/const 等）；语法非法或与当前环境同名 → 编译错误（带块内 + 所属块位置）
4. **`types` 元数据对象**：块内隐式 `types`，字段：`fields`（当前可见类型字段表 `{name, type}`）、`type`（当前类型名/构造）、`all`（可见类型清单）——**可见范围随块位置**（06-09）：class 内 → 该类；命名空间下 → 该命名空间；顶层 → 全文件；随实施细化字段形态
5. **供应链安全**：依赖包中的 script 块**默认禁用**——仅当 build.zon 声明信任（`deps.X.script = true` 形态待 I4 注册中心指纹落地时一并定）才执行；本块范围内执行的是**主包脚本**与**显式信任的本地依赖**。脚本 = H 核心子集（受限分配器/IO）作为双层防护（评审 C3 对策）
6. **失败语义**：脚本求值错误（含 `return error.X`）/ 产物替换后重解析失败 = 编译错误，位置 = 块内 + 所属块（06-09 错误机制统一）。**降级闸门 Q-S10 保留**：本机制成本失控时走「编译期执行 H 子集函数」

## 影响

- **装载流程（组 B1/B3）**：解析器产 script 块节点（带文本区间）→ 装载期求值 + 替换 + 重解析（`hc` 前端流水线新增「脚本展开」阶段）
- **求值器（组 B2/B3）**：受限子集求值器 + `types` 元数据注入 + 产物字符串校验
- **安全（组 B4）**：build.zon 信任声明 + 受限子集强制 + 依赖脚本默认禁用
- **三后端（组 B5）**：脚本展开在装载期完成，IR/字节码/native 对展开后的 AST 无感知（后端零改动）
- **文档**：06-09（执行流程/替换机制/安全补定）、06-08（build.zon 信任声明）、01（供应链警示）
- **未变**：script/comptime 双轨分工（comptime 管类型级计算）；「无宏」（12.22——脚本生成是数据驱动样板，非任意代码内嵌宏）；降级闸门

## 取舍

- 选择「文本区间替换 + 重解析」而非「AST 直接拼接」：替换后走正常编译路径，产物可读、错误定位自然、后端无感知；代价是重解析开销（仅含脚本的文件，可接受）与产物必须是完整声明（不能是表达式片段）
- 选择「脚本 = H 核心子集」而非「任意 H（如 06-09 初始表述的完整语言）」：供应链风险可控（评审 C3）、求值器小而稳；样板生成所需能力（字符串遍历/拼接）子集已够——若后续发现需要更多，随 1.x 扩展
- 未做「脚本即宏（任意 AST 操作）」：H 的「没有隐藏控制」哲学——脚本生成是数据驱动的声明样板，能力边界清晰
