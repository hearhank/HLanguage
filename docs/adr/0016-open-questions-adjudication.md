# 开放问题裁决：悬垂粒度 / Arena 惯例 / 注册中心治理 / Send·Sync 静态标记

> 2026-08-22 定案（C2 开放问题裁决，grill-with-docs 访谈，4 子项全推荐）。关联：SPEC [05-open-questions-and-risks.md](../SPEC/05-open-questions-and-risks.md)（状态表 #1/#3/#5/#6 关闭项）、[01-unimplemented-features.md](../phase3/01-unimplemented-features.md)（C2 / C3 / B3 条目）、[02-syntax-rules.md](../phase3/02-syntax-rules.md)（§5 语句规则）、查询手册 [H Language.md](../H%20Language.md) §5 / §7。

## 背景

- `05` 开放问题 #1/#3/#5/#6 为第三阶段 E6.1（组 J1）「开放问题裁决」待办项，均未定案
- 协作式并发（ADR-0011 逆转）后，真 OS 并行归 1.x——Send/Sync 静态标记的「时机」需重新评估

## 决策

### #1 Debug 悬垂标记切换粒度 → **编译单元级**

1. 悬垂标记按**编译单元（文件）**切换，粒度=简单可预测；函数级留 1.x 性能优化场景
2. CLI 形态：`hc run` / `hc test` / `hc build` 增 `--dangle=on|off|auto`；`auto` = Debug 开 / Release 关（默认值，与既有双模一致）；tag1 既有 `debug_dangling` 开关对齐为此
3. Release 默认关（零开销）；`--dangle=on` 可强制 Debug 行为于 Release，`--dangle=off` 可关 Debug 悬垂诊断

### #3 无 GC 长运行脚本 Arena 惯例 → **机制就绪 + 惯例文档化 + `with_arena` 包装**

1. `mem.Arena` 机制已就绪（`Arena.init(alloc)` / `arena.alloc(...)` / 作用域退出统一回收 / `deinit` 批量归还）——本项不新增机制
2. **脚本惯例**：长运行脚本（服务 / 事件循环）每轮（请求 / 迭代）新建 Arena、处理完整体回收——「每请求一个 arena」；`io.time` / `io.rng` 等长运行同组场景默认建 Arena 再操作
3. 标准库补便利包装 `mem.with_arena(fn)`：进入时建 Arena、退出时统一回收（含 deinit），减少样板

### #5 注册中心治理 → **MVP 只做「唯一包名 + 指纹发布」，治理 1.0**

1. 第三阶段 MVP 治理范围：**唯一包名（注册冲突拒绝）+ 发布带 build.zon 指纹签名**
2. 冲突仲裁、安全审计流程、取消失控等治理规则全部标注 1.0（B4 正式注册中心）——B3 的 `hc pkg publish` / `fetch` + 指纹校验不阻塞
3. 供应链校验（依赖来源审计）随 B3 指纹落地，与治理分离

### #6 跨线程引用传递 Send/Sync 静态标记 → **语法先行、语义留 1.x（编译期接口 + 协作式诊断）**

1. **语法形态**：`Send` / `Sync` = 编译期接口（H 式显式标注，接口三用途）；编译器验证可推导性（组合性：元素/字段 Send 则容器 Send）
2. **时机**：协作式单线程模型下无真数据竞争，Send/Sync 标记**仅做编译期诊断**（可检测跨线程引用传递模式，提示带位置），真并行检查 1.x 启用
3. 与 Q18/Q19 关系：协作式下线程捕获安全已由绑定/逃逸 + 冻结窗口保证（编译期强制）；Send/Sync 为 1.x 真并行的**类型层铺垫**，不替代 Q18/Q19
4. 详细编译期诊断语义（哪些模式报错、如何推导）在 C3 与「惰性迭代、switch 守卫」一并细化（C3 备注：Send/Sync 与 C2 #6 联动）

## 理由

- #1 编译单元级：与既有 Debug/Release 双模天然对齐、可预测、实现最简；函数/引用点级为性能分析工具场景，收益不抵复杂度
- #3 不新增机制：Arena 已实现且经 G1 验证（真实 bump + 块链表），缺的只是「何时用」的约定与样板包装；`with_arena` 一行包装即得、无隐藏控制
- #5 治理推 1.0：MVP 阶段无第三方生态，治理规则空转；唯一名 + 指纹是发布/校验的最小可信基座，先落地不阻塞 B3
- #6 语法先行：Send/Sync 为类型层契约（编译期纯静态、零运行时开销），先定义形态可锁定 1.x 方向；协作式下诊断不破坏确定性承诺；详细语义归 C3 统一设计，避免与惰性迭代/switch 守卫重复访谈
