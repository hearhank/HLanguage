## 三、裁定记录（Q1–Q28 摘要）

### 所有权与内存（Q1–Q3 系列）

- **Q1（P0-1）所有权按来源编译时判定**：非 Arena 分配器创建的复杂类型 → 所有权**默认注册当前作用域**（显式 `o` 为冗余标注）；Arena 分配 → 所有权归 Arena（禁 move，move 须对整个 Arena）。**可移动性（编译时判定）** = ① 来源条件（非 Arena）；② 树形内存条件：内存树**无外部引用**——无向外引用（字段及递归子项均无 `*T`/`*mut T`/`&[T]`/`&mut [T]` 引用值）+ 无向内引用（move 程序点无指向树内节点的存活引用，**编译期别名检查**）。「无向内引用」是 move 点的窄范围编译期别名分析，与运行时唯一写者登记正交。String/Vec 等自有子对象随树转移；Thread/Future/四模式类型豁免。
- **Q2（P0-2）struct 字段集放宽**：struct 字段可含复杂类型（String/集合/class），与 class 成员集一致（Q22）。纯 POD（字段全为标量/纯值 struct）→ 连续字节、可 `to_bytes` 直映射；含堆字段 → struct 本体内嵌字段值、序列化走递归。struct 与 class 差异收敛为：值语义（可内嵌、无分配器）vs 堆上引用类型（需分配器）。
- **Q3（P0-3）String = `u8[]` 别名**：String 具体功能与 `Vec(u8)` 一致，数组/切片规则全部适用（切片 = 数组视图）；**取代 Q16「String 值复制例外」**——恢复「无隐式内存分配」原则的无例外地位。
- **Q3c 引用类型赋值 = 别名共享**：`var s2 = s1;`（数组/集合/String）→ 共享同一数据；`s1` 保持唯一拥有（退出销毁一次）、`s2` 无所有权；深拷贝需显式 `copy`；别名 = 向内引用 → move 原变量编译期禁止；别名不得比拥有者长寿（逃逸检查）；所有权转移必须显式 `move`（赋值不隐含转移）。

### 语法规格（Q4–Q14）

- **Q4 运算符优先级**：Zig 式 14 级——后缀(1) > 一元(2) > 乘除模(3) > 加减(4) > 移位(5) > 位与(6) > 位异或(7) > 位或(8) > 比较(9，非结合) > `and`(10) > `or`(11) > `orelse`/`catch`(12) > `..`(13) > 赋值(14，右结合)；`try a catch b` = `try (a catch b)`。
- **Q5 字符字面量**：`'x'` 类型 = `comptime_int`（惰性宽度，使用处定型）；支持转义；无独立 `char` 类型。
- **Q6 转义集**：`\n` `\r` `\t` `\\` `\"` `\'` `\xNN` `\u{...}`；非法转义编译期报错；无原始字符串。
- **Q7 token 冻结 + mut 定名**：29 个关键字 + 标点清单冻结（见 06 §1）；`mut` 定名（占位符解除）；`box`/`copy` 为内建函数（非关键字）。
- **Q8 test 块**：`test "名称" {}` 顶层测试块；`hc test` 运行；失败 = error；`expect` 归 std.debug 测试块内隐式可用。
- **Q9 if 双向捕获**：`if (e!) |v| else |err|` 必须成对（错误显式处理）；作表达式时两分支值类型一致。
- **Q10 while 捕获**：`while (opt) |v|`（空则退出）、`while (e!) |v| else |err|`（错误走 else 后退出）；可与续步表达式组合。
- **Q11 忽略错误**：仅 `catch |_| {}` 形态，无 `catch {}` 简写。
- **Q12 box/copy 内建**：`box(value, alloc) -> owned *mut T`（装箱）；`copy(&value) -> T`（按类型复制）；编译器内建、不可重载/用户定义、非关键字。
- **Q13 错误值**：`error.Name` 全局唯一；显式错误集函数 return 未声明错误 → 编译报错；`anyerror` 上下文任意可用。
- **Q14 四模式方法集**：`init(alloc)` / `write(v)` / `read() T`（阻塞）/ `try_read() ?T`（非阻塞）/ `close()`（结束标志）；方法取 `*Self`（Q32 内建共享特例）。

### 类型与引用（Q15–Q17）

- **Q15 `o` 适用范围**：仅**分配器分配的对象**（复杂类型/装箱指针）；标量/纯值 struct 写 `o` = 编译错误。
- **Q16 指针不可空**：`*T`/`*mut T` 无空态；空指针用 `?*T`/`?*mut T`；悬垂 ≠ null；无 NULL 字面量。
- **Q17 接口指针**：`*Shape` = 胖指针（data + 虚表，两字宽）；`box` 装箱后赋给接口指针**编译期自动收窄**（接口实现检查，无需 as）；data 部分参与双向引用登记（悬垂/唯一写者同 `*T`），虚表不参与。

### 并发与生命周期（Q18–Q21）

- **Q18 悬垂唯一路径**：引用逃逸到比目标更长寿的容器/全局（返回值引用被编译期禁止）；容器元素「取指针」不抛错、「解引用」才触发检测；28 示例重写。
- **Q19 线程捕获静态检查**：① 绑定/逃逸判定（数据流）——句柄在声明作用域内 join/await = 绑定（引用捕获合法），detach/未 join 退出 = 逃逸（引用捕获编译错误）；② **冻结窗口**——被捕获目标在 spawn→await 间主线程不可写（await 后恢复）；并发写共享数据走四模式类型。
- **Q20 Future 类型参数**：`async fn f(...) R` 返回 `Future(R)`，R = 完整返回类型（含 `!`）；`await` 返回 R（`try await` 解包）。
- **Q21 defer LIFO**：多 defer 后声明先执行（与资源创建顺序成镜像）。

### 接口与参数制（Q22 系列）

- **Q22 接口参数 = 虚拟类型 + where 约束**：`fn add(a: *T) void where T: INumber`；形态映射 `&T`→`*T` / `&mut T`→`*mut T` / `move T`→ `owned T`；调用点 `add(&a)` / `add(&mut a)` / `add(move a)`；静态单态化为主路径；`*Shape` 胖指针（Q17）用于异构集合。
- **Q22b 参数签名类型标注制**：参数签名统一  `owned T`（拥有）/ `*T`（只读）/ `*mut T`（可写）；`move` 关键字仅保留在调用点（`take(move s);`）；此前「`move y: *mut T` 参数签名」表述取代。
- **Q22c io 参数**：库函数统一 `io: *T where T: Io`（调用点 `&io`）；入口 `fn main(io: Io)` 为编译器注入特例（唯一例外）。

### 元编程与解析（Q23–Q24）

- **Q23 script 输入机制**：script 块 = 编译前执行的 H 表达式块（H 核心子集），产物 = **生成代码字符串**就地替换；上下文隐式 `types` 元数据对象（`types.fields(name)` / `types.type(name)` / `types.all()`，编译器生成注入）。
- **Q24 `&` 三义**：lexer 只产出一个 `&` token；类型位置 = 切片类型 `&[T]`/`&mut [T]`；表达式位置 = 一元取地址（`&x`/`&mut x`）或二元位与（`a & b`）；`&mut` = `&` + `mut`；parser 上下文消解（LL(1) 可行）。

### 生命周期与销毁（Q25–Q26）

- **Q25 临时引用生命周期**：表达式产生的临时 `*T`/`*mut T` 存活到语句结束——方法链整链写者资格保持、链末一次注销；绑定引用存活到作用域结束；链内传递 = 同一写者资格延续（reborrow 形态，衔接开放问题 #2）。
- **Q26 闭包捕获登记 + 销毁 LIFO**：捕获变量与闭包建立双向注册（目标销毁 → 闭包标记悬垂，Debug 调用抛错带位置）；闭包存容器合法（登记链覆盖）；**作用域退出销毁顺序 = 声明逆序（LIFO）**。

### 一致性（Q27）与排期（Q28）

### 系统级 review 回应裁定（Q-R7~R12，2026-08-13）

- **Q-R7（唯一写者登记定位）**：登记 Debug 默认开启（唯一写者检测 + 悬垂标记，便于即时定位出错位置）、**Release 默认关闭**（裸路径、性能优先，接受性能损失换取 Debug 可定位性），由编译时选项控制。
- **Q-R8（悬垂语义 = Zig 式）**：悬垂由用户负责；双向引用登记是**可选的诊断机制**（非强制安全机制）。登记开启时悬垂/唯一写者冲突仍为不可恢复运行时错误（带位置）。
- **Q-R9（接口三用途）**：① 标记 class 功能（implements 标注）；② 标记参数类型（`where T: Shape` 约束）；③ 类型参数编译可验证。
- **Q-R10（String 特例评估修正）**：接受——H String（堆 + == 内容比较 + 显式复制 + as_slice/to_bytes）与 Rust String 同级（家族一致；差异点：H 赋值 = 别名共享 Q3c、Rust 赋值 = move——已定案接受）。
- **Q-R11（测试 = 标记为测试的函数）**：`test "名称" { }` 块 → **`test fn 名称() !void { }`**（可被普通代码调用/复用，原「测试块非函数」限制解除）；86 个示例全部迁移（113 处测试函数）。
- **Q-R12（四模式类型通道方法）**：新增 `send(v)` / `recv() T`——线程间数据传输的通道语义（与 write/read 同源），四模式类型即线程间传输通道。

### 系统级缺失定案（Q-S1 起，2026-08-13）

- **Q-S1 定案（@ 内建函数集）**：Zig 式 `@` 前缀编译期内建，1.0 最小集——`@sizeOf(T)` / `@alignOf(T)` / `@offsetOf(T, "字段")` / `@typeOf(expr)`（类型查询）、`@intCast(T, x)`（整数转换，超范围 Debug 检测/Release 裸）、`@ptrCast(T, p)`（指针转换，**唯一显式放弃类型安全的逃生舱**，替代 Rust unsafe / C 强转）、`@alignCast(T, p)`（对齐断言）、`@compileError("msg")`（显式编译失败）。`@` 前缀不与用户标识符冲突（Q7 冻结清单外的新 token 类）；其余 Zig 内建按需 1.x 扩展。
- **Q-S2 定案（panic 语义）**：不可恢复运行时错误（登记开启时的悬垂/唯一写者冲突）→ 内置 **`@panic("消息", 位置)`**——打印 + abort 终止；**不执行 defer 清理**、**无 unwind/recover**（回卷是隐式控制流，与「没有隐藏控制」一致）；测试内 panic → 该测试记 FAIL（不终止整个 hc test）；Release 同样 abort（消息精简）；panic 钩子留 1.x。
- **Q-S3 定案（原子操作）**：`@atomicLoad(T, p, order)` / `@atomicStore(T, p, v, order)` / `@atomicRmw(T, p, op, v, order)`（op = `.add`/`.sub`/`.exchange`/`.cmpxchg` 等，限整数/指针/枚举等可原子类型）；**内存序 C11 五序子集** `relaxed`/`acquire`/`release`/`acq_rel`/`seq_cst`，**默认 `seq_cst`**（弱序需显式）；四模式类型内部实现基于这些原语（单写者路径可免原子）；双模式 VM 提供等价原子语义。
- **Q-S4 定案（FFI / 跨语言调用）**：`extern fn c_func(...) 返回类型;`（C ABI 外部声明，`hc cc` 编译 C 链接）；`@cImport("header.h")`（编译期解析 C 头生成 H 声明，内建 C 解析器）；**C 指针 = `*T` 但不参与双向登记**（外部内存用户负责，进入引用体系需显式 `box` 包装）；**C 错误码 → error union 手动映射**（无隐式转换）；C struct ↔ H struct POD 直映射 + `@offsetOf`/`@alignOf` 布局验证。12.26 从「待定」转为「已定义」。
- **Q-S5 定案（对齐/打包控制）**：默认布局 = 平台 ABI 对齐（与 C 兼容）；**`packed struct`**——紧凑布局（字段无填充，网络/文件协议头；字段限可打包类型：无指针/切片的标量与枚举）；**`align(N)`**——类型级（`struct Foo align(4)`）与字段级（`field: i32 align(2)`）对齐注解；`to_bytes` 直映射尊重显式布局（`@offsetOf`/`@alignOf` 可验证）。
- **Q-S6 定案（整数溢出语义）**：Debug/脚本模式——算术溢出检测并 `@panic`（带位置）；Release——裸 wrap（两补码回绕，零开销）；**显式原语** `@addWithOverflow` / `@subWithOverflow` / `@mulWithOverflow` → `{ value, overflow: bool }`（不受模式影响，确定性算术用它们）；`@intCast` 超范围 Debug 检测/Release 裸。与 Q24「越界检查按模式」同一哲学。
- **Q-S7 定案（reborrow 函数调用边界，关闭开放问题 #2）**：`*mut T` 传 `*mut T` 借用参数（或 `&mut x` 直接传）→ **自动 reborrow**——调用期间写者资格转移给被调函数、返回自动恢复；Debug 为临时借用登记创建/注销（与 Q25 同一模型）；Release 纯编译期借用作用域跟踪零成本；借用参数调用点不触发 move 检查（16-slices 等示例保持合法）。
- **Q-S8 定案（`!T` 匿名错误集语义，关闭观察 O-2）**：`!T` = **推断错误集**——编译器从函数体收集所有 `return error.X` + `try` 传播的实际返回集，与显式 `E!T` 语义一致（显式标注 = 文档/契约、推断 = 便利）；调用方 switch 可穷举；`try` 传播取实际返回集；递归/泛型无法收集时退化为 `anyerror`（编译器提示显式标注）；`anyerror` 仍仅接口契约（Q34）。
- **Q-S9 定案（推断优先原则，回应「语法密度」）**：类型系统修订为**推断优先、显式兜底**——有信息来源的位置默认推断：变量绑定（`var x = init`）、字面量惰性宽度、泛型参数（anytype / where T）、指针形态（`var x = &mut t`）、**函数返回类型**（单路径/一致类型，TS 式；递归/多类型需显式）；无法推断才显式：函数参数类型（含 `*`/`*mut`/`o` 形态，调用点不可见）、struct/class 字段类型、接口实现标注；`o` 不参与推断（Q1 按来源判定）。不引入额外语法糖（拒绝 A 的接口名作参数形态），以推断默认缓解语法密度。
- **Q-S10 定案（1.0 范围）**：脚本生成保持 1.0 必达，但设**降级闸门**——若 M5 后 VM/LLVM 一致性无法通过或脚本生成器成本超预期 → 降级为「脚本生成 = 编译期执行 H 子集函数（comptime 内联）」，`script{}` 语法保留（B1 预案）；**双后端不可降级**（规则 5 核心承诺）；**自举转可选里程碑**（M9，不阻塞 1.0——README 1.0 定义本就未含自举，Rust 参考实现长期保留）。
- **Q-S11 定案（所有权语义重大修订：Zig 式销毁责任模型——取代 Q1 谓词、Q-R7/Q-R8、Q-S7）**：① 所有权 = **销毁责任的唯一归属**（非访问权限控制）；非 Arena 默认作用域负责销毁、Arena 由 Arena 统一负责。② **指针自由**——多 `*mut`/`*T` 合法，**指针问题（悬垂/别名）由用户负责**；唯一写者取消；`*mut` 可复制。③ 可移动性简化——move 唯一约束 = 拥有所有权（非 Arena）；「内存树无外部引用」谓词取消。④ Debug 悬垂标记 = 可选诊断工具（非安全保证）。⑤ reborrow 概念取消（传参即指针传递）；Q-S7 作废，Q25 临时生命周期保留。同时：H vs Rust 功能比对表已沉淀 `RESEARCH/h-vs-rust-comparison.md`（标注 H 为规划中的语言）。
- **2026-08-14 Q1'/Q5'/Q2' 定案（赋值语义 + 所有权情况全录——取代 Q3c 别名共享；完整清单落点 CONTEXT 所有权章节）**：① **引用类型赋值 = 编译错误**——`var s2 = s1;`（数组/集合/String）不合法：共享数据走显式指针（`&s1`，指针问题用户负责），复制走显式 `copy(&s1)`（新建内存、有所有权）；`copy` 默认深复制，浅复制需显式标注（`copy(&x, .shallow)`），浅复制引入的内存问题由用户负责。② **move 后原绑定仍可访问**——move 不复制数据、不移动内存、变量本身不变；原作用域退出不再销毁；继续访问造成的悬垂/冲突由用户负责（指针自由哲学延伸）。③ **global 有所有权（归根作用域）**——凡分配器分配皆有所有权；global 所有权归根作用域（程序/库，程序退出时销毁）；不可 move（移出即失去全局性）；旧「global 无 o」表述修订。④ **所有权情况全录**：A 无所有权（值类型/指针与切片自身/Arena 对象）；B 有所有权（当前作用域 / Arena / 根作用域(global) / 父对象(o 字段) / copy 新对象）；C 转移（move 函数参数与返回值 / 字段带 owned 赋值 / 线程捕获→提升根作用域；禁止 move：Arena / global / 无所有权对象）；D 销毁时机（作用域退出递归 / 根作用域退出 / Arena 统一回收 / defer 显式）。
- **2026-08-14 系统编程评估（内核编程场景缺口登记）**：以「完成操作系统内核编程」为验收场景评估——数据结构本体足够（class/Continuous/packed/align/枚举/切片/指针自由/位运算/原子/显式分配器/error union）；**6 项阻断性底层能力缺失**：K1 无标签 union（裸内存双关：页表/寄存器/上下文）、K2 volatile（MMIO，防 LLVM 优化掉）、K3 内联汇编 asm（特权指令，已标注 1.x）、K4 整数↔指针转换（`@ptrFromInt`/`@intFromPtr`，物理地址→指针）、K5 符号导出与段控制（`export fn` + 链接脚本）、K6 freestanding（无 OS 目标）；**5 项重要缺失**：K7 裸函数指针类型、K8 位域、K9 指针算术、K10 `@byteSwap`、K11 `Atomic(T)`；**标准库缺口**：bitmap/侵入式链表/环形缓冲/树/页内存。登记落点：`05` 系统编程缺口表、`04` 系统编程扩展、`02` 缺口小节（K1/K2/K4/K5 建议 1.0，K3/K6/K7–K11/std 为 1.x 或待设计决策）。
- **2026-08-14 类型系统定案（struct/class 合并 + Continuous + 元组 + Table——取代 ADR-0006 与 Q2 裁定的 struct/class 分立）**：① **统一关键字 `class`**（`struct` 删除）——默认 class 语义（堆上/分配器/接口/可 move/`to_json`）；② **内建布局特性 `Continuous`**（`class Point: Continuous`）——编译器验证字段全值类型，获值语义全集（无分配器/可内嵌/赋值即复制/`to_bytes` 直映射/`packed`/`align(N)`/字面量构造 `X{...}`）；③ **元组**——无名称、字段只读匿名值类型（天然连续内存）：`(1, "a")`、`t.0`、**支持解构**（`var (a, _) = t;`，`_` 占位符放弃值）；④ **`Table(T)`**——内建二维结构代替 `[M][N]T`：`table(rows, cols, init)`、`t[i, j]`、定长、引用类型、行主序可 `to_bytes`；⑤ `tree` 保留。落点：CONTEXT §4、01 §12.12/12.19/12.20、06 §2、04 序列化分层、ADR-0006。
- **2026-08-14 定案（标量类型体系：INumber 族——内建标量接口化）**：`INumber`（`add`/`sub`/`mul`/`div`/`neg`/`eq`/`lt`）→ 子接口 `IInt`（有符号 `i8`–`i128`/`isize`，+`mod`/`abs`）/ `IUint`（无符号 `u8`–`u128`/`usize`，+`mod`）/ `IFloat`（`f16`–`f128`，+`abs`/`pow`）——内建标量编译器内建实现（不可重载）；类型名保留小写（`i32` 实现 `IInt`），接口名大写；**运算符绑定 INumber 族**（`a + b` ≡ `a.add(b)`，`!=`/`<=`/`>`/`>=`/`%`/`%%` 编译器派生；无用户重载）；`where T: INumber` 可约束标量（新示例 `86-scalar-interfaces.hc`）。落点：CONTEXT §4 标量类型体系、01 §12.2/§12.16、06 §2 类型表与标量接口族。
- **2026-08-14 定案（比较接口化 + 连续内存内部化 + 补充定案）**：① **`ICompare`**（`eq`/`lt`，派生 `ne`/`le`/`gt`/`ge`）——`INumber : ICompare`；**相等 `==`/`!=` 语言内建通用**（一切类型），**序比较绑定 `ICompare`**（String 内建实现）。② **连续内存 = 语言内部机制（用户不可标注）**——存储形态自动判定（字段全值类型含定长数组/元组 → 连续；含引用/堆字段 → 堆上）；强制堆上分配用 `box()`；示例 `: Continuous` 标注全部移除。③ **多值返回**：元组 `(T1, T2)`、解构 `var (a, b) = f();`、`E!(T1, T2)`。④ **`table(alloc, rows, cols, init)` 显式分配器**。⑤ **标量装箱** `*INumber`/`*mut INumber`（接口 = 类型标注）。⑥ **接口实现标注定案**：冒号后缀。⑦ **`packed class` 字段集**：标量/枚举/连续内嵌/元组/定长数组。⑧ **元组比较/序列化**：`==` 逐元素、`to_bytes`、Map 键；**序列化 = 默认接口**（内建契约，不可重载）。落点：CONTEXT §4、01 §12.2/§12.12/§12.16、06 §2、示例 13/19/24/30/50/57/58/64/81/86、ADR-0006。
- **2026-08-14 定案（函数重载 / 可选参数 / 泛型约束验证 + 并发与 IO 补充）**：① **允许重载**——签名 = 函数名 + 参数类型列表 + 返回类型；返回类型在目标类型已知时参与选择；歧义编译错误要求显式；**泛型约束编译时验证、接口限制运行时拆除**（单态化零开销，Q1c）；**可选参数**（尾部、编译期常量默认值）。② **闭包可返回值**（捕获全值类型可返回；捕获引用/堆数据须 move 或 global）。③ **Future/Thread 方法集一致**：join/cancel（协作式取消）/is_done/detach；`await` ≡ `join()`。④ **数组/切片/集合比较**：数组与切片逐元素；Vec/Deque 逐元素；Map/Table 不提供 `==`（显式遍历）。⑤ **命名空间**：默认私有、`pub` 显式导出；`using ns.*` 冲突 = 编译错误，`using ns.name as 别名` 改名引入。⑥ **枚举负载任意类型**（含引用负载 → 自动堆上）。⑦ **io.fs 随机访问**：`seek`/`pos`/`read_at`/`write_at`。⑧ **UDP 进 1.0**：`io.net.udp`（bind/send_to/recv_from 元组返回）。落点：01 §12.5/§12.16、06 §5、CONTEXT §3、04（io.fs/io.net）、示例 87-overloads.hc、ADR-0009。
- **2026-08-14 定案（迭代契约 / 并发缓冲 / 元编程与 FFI 补充）**：① **迭代契约**——`IIterable` 三态：`IIterable(*T)`（只读 `for (x) |item|`）/ `IIterable(*mut T)`（可写 `for (x) |mut item|`）/ `IIterable(o T)`（拥有 `for (x) |move item|`）；内建类型编译器内建实现；用户类型实现即可参与 `for`；`arr.iter()` = 显式数据对象；惰性迭代 1.x。② **四模式/通道缓冲**——共享内存容器（write/read）无容量（write 不阻塞、read 阻塞到有值）；通道（send/recv）有界队列（`init(alloc, cap)`，send 满/recv 空阻塞）。③ **`comptime { ... }` 块**（编译期执行，与 script 块平行）；**错误机制统一**——作用域/函数/script/comptime 块均可返回 error，script/comptime 块失败 = 编译错误（解释器/编译器抛出，带块内 + 所属块位置）。④ **FFI 待定清理**——C 头导入 = 内建 `@cImport`、C 指针外置 + `box` 进入、错误码手动映射（均 Q-S4，清除「待定」标记）。⑤ **`build.zon`**（内容 = H 数据字面量 `const build = Build{...}`；依赖指纹校验 + 来源审计，C3）。⑥ **`Io.evented()`** = 单线程事件循环（select/epoll 式非阻塞 + async/await 协作；与 threaded 同一 Io 接口）。⑦ **String = `u8[]` 类型别名同构**（`&[u8]` 零成本互转，`as_slice` 无前缀视图）。落点：01 §7/§8/§12.8/§12.21/§12.26、06 §9/§10、CONTEXT §4/§6/§7、示例 88-iterators.hc。
- **2026-08-14 定案（程序环境 / 文本字面量 / 枚举转换 / 文件模型 / 错误码表示）**：① **程序环境**——入口 `io` 提供 `io.args() &[&[u8]]`（0 号 = 程序名）/ `io.env(name) ?&[u8]` / `io.stdin`/`io.stdout`/`io.stderr`（字节流）；**退出**：默认枚举 `enum ExitType { Exit, Error }` + `io.exit(t, code) !void`（Exit 静默正常 / Error 错误退出打印；main error → Error/1、正常 → Exit/0）。② **字符/字符串**——不引入 char（`'a'` = u8，非 ASCII 用 u32 码点显式）；**多行/原始字符串 `"""..."""`**（无转义）进 1.0。③ **枚举 ↔ 整数**——`@intFromEnum(e) usize`（变体序 0 起）/ `@enumFromInt(E, i)`（越界 Debug 检测）；仅纯常量枚举。④ **文件模型**——目录 = 包，包内文件共享命名空间（Q21 跨文件），跨包 `using pkg.xxx` + `build.zon`；`hc build` 编译包内全部文件、`hc run file.hc` 单文件脚本运行；无文件级 import。⑤ **global 初始化**——程序启动时执行（main 前，声明序，循环依赖编译错误），支持运行时初始化。⑥ **标准库单层**——1.0 无 core/std 分层；K6 freestanding 纳入时再抽 H core。⑦ **错误值运行时表示**——全局唯一整数错误码（编译器维护名↔码表）、error union = 码 + 成功标记（Zig 式零额外负载）、Debug 附源位置、anyerror 任意码 64 位。落点：01 §4/§5/§8/§11/§12.3/§12.13/§12.18、06 §1/§2/§5/§8、CONTEXT §5/§9、04 io。
- **2026-08-14 可行性 review + H1–H5 裁决**：系统语言专家 review 生成 `docs/review/2026-08-14-feasibility-review.md`（17 项实现不清楚清单，H1–H5 高严重度 + M1–M8 中严重度 + L1–L6 低严重度）。**已裁决（H1–H5）**：H1 特性标注（`[continuous]`/`[pad]`/`[align(T)]` 中括号，取代自动判定）；H2 move = 销毁权转移（变量不动、copy 显式）；H3 `==` 值比较绑定 ICompare（class 身份删除、指针/切片比地址+长度）；H4 数组引用 = 切片；H5 script 编译前（作用域类型可见、生成物不冲突）/ comptime 编译时。**待裁决（M1–M8、L1–L6）**：重载解析矩阵、期望类型传播、String 别名 vs newtype、IIterable(o T) 语义、胖指针销毁、4 组合测试矩阵、global 跨文件顺序、Table 语法、`.shallow` 语法、new 签名、ExitType 位置、@intFromEnum 宽度——登记于可行性报告第四节。
