# 语言设计共识

> 本文档记录与项目所有者达成的设计共识（2026-08-12），是实现的**唯一依据**。所有决策按「Zig → Rust → TypeScript」参考优先级作出（`docs/adr/0001-reference-policy.md`）。术语定义以 `CONTEXT.md` 为准。

## 1. 定位与哲学

- 以数据为中心：定义数据、修改数据、传输数据、保存数据是语言的四大支柱。**数据 = 内存的表现形式**（2026-08-14 定案）：连续内存块、树状关联内存块、相互引用的内存块都是数据；组织（数组/集合/字典/表格）、传输（指针复制/移动）、存储（序列化到内存/文件/数据库）见 CONTEXT §2
- **函数 = 唯一处理逻辑**（2026-08-13，Q13 定案）：一切数据处理通过函数表达；接口描述功能（处理能力的契约），复杂类型 = 数据字段 + 函数的组合；无其它处理机制（无运算符重载、无宏）
- **没有隐藏控制**：无异常、无宏、无隐式内存分配；一切控制流、资源与错误路径显式可见（唯一隐式行为：作用域退出自动销毁，词汇可见可预测）
- 同时支持系统编程（编译为原生二进制）与脚本编程（解释执行）
- 严肃长期项目，对标 Zig/Go；1.0 标准见 SPEC README

## 2. 双模式执行

- 同一份 `.hc` 源码两种执行方式，**语义一致**（不存在编译专用/脚本专用子语言）
- **语义一致边界**（2026-08-13 收紧，评审 B4）：语义一致 = 值语义、所有权语义、控制流一致；**错误检测策略是独立维度**——Debug 全检测、Release 裸路径、脚本模式 Debug 语义
- 架构：共享前端 → 共享 IR → 双后端（字节码 VM + LLVM 原生）
- 依据：`docs/adr/0004-dual-mode-architecture.md`

## 3. 类型系统

- 静态强类型；**推断优先，显式兜底**（2026-08-13 Q-S9 修订）：有信息来源的类型位置默认推断——变量绑定/字面量惰性宽度/泛型 T（anytype、where）/指针形态/函数返回类型；无法推断才显式——函数参数类型（含 `*`/`*mut`/`o` 形态）、class 字段类型、接口实现标注；`o` 不参与推断（Q1 按来源判定）
- 结构化类型（按形状判断兼容）为脚本模式可选特性（TS 第三）
- **引用类型**（2026-08-13，评审 B3 + Q3/Q3c；2026-08-14 Q1' 修订）：定长/变长数组、集合、**String（`u8[]` 别名）**为引用类型——传参走引用；复制需显式（`copy(&x)`）；**赋值 = 编译错误**（共享数据走显式指针 `&s1`，复制走显式 `copy(&s1)`；`copy` 默认深复制，浅复制需显式标注，内存问题用户负责）；标量保持值语义（赋值即复制）
- **权限标注模型**（2026-08-13，评审 D2；Rust 标杆修订）：类型标注 = 类型 + 读写权限（`*`/`*mut`）+ 所有权（o）；move 基于所有权判定（**拥有所有权才能 move**——非 Arena 分配），与读写权限同属统一权限体系
- 类型即数据的形状：「定义数据」支柱的可靠性与可验证性由静态类型保证

## 4. 内存模型（核心）

- **Allocator**：分配经显式 Allocator；未显式传入时回退全局分配器
- **所有权 = 销毁责任的唯一归属（2026-08-13 修订，Zig 式）**：同一时间只有一个对象（作用域/分配器）对「变量退出时销毁其内存」负责——**非访问权限控制**。非 Arena 分配默认注册当前作用域（退出自动销毁；`o` 冗余标注）；Arena 分配由 Arena 统一负责销毁（归 Arena）；Arena 来源禁止 move
- **作用域**：所有权与生命周期的基本单位；每个块是无名字的函数，函数是有名字的作用域
- **move（2026-08-13 修订）**：转移**销毁责任**；仅拥有所有权（非 Arena）可 move；调用点显式 `move`；不复制数据、不移动内存
- **可移动性（2026-08-13 修订）**：move 的唯一约束 = **拥有所有权**（非 Arena）；**旧「内存树无外部引用」谓词取消**（指针别名自由，用户负责，不阻塞 move）
- **全局变量**（2026-08-14 修订）：`global` 声明，根作用域上下文，静态生命周期（程序退出时销毁）；**有所有权（归根作用域）**、不可 move（移出即失去全局性）；`o` 标注不用于 global；**初始化时机（2026-08-14 定案；M7 修订）**：程序启动时执行（根作用域构造阶段，`main` 前）——支持运行时初始化（如 `global LOG_LEVEL = parse_env();`）；**跨文件按初始化表达式依赖图拓扑排序**（无依赖按文件声明序；循环依赖 = 编译错误）
- **传参规则**：标量/Continuous 类型默认复制；数组、集合、复杂类型为引用类型——传参走引用，复制需显式（评审 B3）
- **指针自由（Zig 式，2026-08-13 修订）**：变量可有多个读写指针（`*mut`）与多个只读指针（`*T`）——**指针问题（悬垂/别名）由用户负责**；唯一写者概念取消；`*mut` 可复制
- **只读引用**：多个可同时存在；指针问题用户负责；Debug 悬垂标记可选（编译时选项）
- **读写引用**：多个可同时存在（唯一写者取消）；`*mut` 可复制；**Debug 悬垂标记**（目标销毁时标记指向它的指针，访问已标记指针 → 提示带位置）= 可选诊断工具（非安全保证）
- **悬垂检测**：指针问题用户负责（Zig 式）；Debug 悬垂标记 = 可选诊断工具（非安全保证）
- **运行时错误**（2026-08-13 修订）：唯一写者冲突概念取消；Debug 悬垂标记开启时访问已标记悬垂指针 → 诊断提示（工具性质）；悬垂属用户责任；与 error union（可恢复）正交
- **无 GC**：双模式同一套模型
- 依据：`docs/adr/0003-memory-model.md`；未决项见 `05-open-questions-and-risks.md`

## 5. 错误处理

- error union + 显式错误集（Zig 第一）；`try` 式传播（Rust 第二）
- **无异常**（TS 第三不采纳：隐式控制流违背「显式优于隐式」）
- 悬垂检测错误属于本模型的运行时错误，同样携带出错位置
- **不可恢复终止机制（Q-S2 定案，2026-08-13）**：`@panic("消息", 位置)`——打印 + abort；不执行 defer 清理；无 unwind/recover；测试内 panic → 该测试 FAIL（不终止 hc test）
- **错误值运行时表示（2026-08-14 定案）**：错误 = **全局唯一整数错误码**（编译器维护「错误名 ↔ 码」表，跨包统一；Q13 错误名全局唯一）；error union 运行时表示 = 错误码 + 成功标记（Zig 式——成功路径零额外负载）；Debug 附带错误源位置（返回点）；`anyerror` = 任意码（64 位空间）

## 6. 并发

- 语言内**有 async/await 关键字**（2026-08-13 逆转；**偏离 Zig 第一**——Zig 0.15 移除关键字，H 选择 Rust/TS 式关键字）；`Future(T)` 为异步任务结果句柄，基于线程任务（A2 定案）
- **共享状态 = 四种线程访问模式类型**（2026-08-13 定案）：`OneToOne(T)`/`OneToMany(T)`/`ManyToOne(T)`/`ManyToMany(T)`——内建泛型共享内存容器（脚本生成实例化），写者数量由类型名保证（单写者无锁、多写者互斥）；**内建共享特例**（Q32）：方法取 `*Self` 只读引用、内部同步，不占唯一写者槽
- **线程所有权**（2026-08-13 定案）：任何作用域可开启线程，归当前作用域；退出时已完成→销毁、运行中→移交根作用域（**无隐式阻塞**）；显式 `t.join() !T` 消耗所有权，获取结果与错误（error union 跨线程传播）
- **根作用域**（2026-08-13，评审 A7）：程序最后退出的场所，负责最终资源回收；global 变量定义于此；后期线程池亦于此
- **线程捕获**（2026-08-13 定案 + Q18 细化）：值类型复制值；引用类型 move 所有权或为 global；**作用域例外**——作用域绑定的执行（await/join 后回到当前作用域）可捕获引用；可能逃逸的线程引用捕获禁用（防悬垂；≠闭包捕获 12.9）
- I/O 与并发抽象入标准库（Io 式接口）；线程为底层原语
- 静态并发安全标记（Send/Sync 式，Rust 第二）
- 事件循环式运行时仅作为脚本模式的库选项（TS 第三）
- 异步执行模型考虑 **Go 式协程 + 通道**（M:N 调度，2026-08-13 评审 B2 方向）——缓解「每个 async 任务一个 OS 线程」的线程爆炸；通道与四模式类型衔接，方向待细化

## 7. 元编程：脚本生成与 comptime 双轨（2026-08-13 评审修订）

- **脚本生成**：`script` 作用域标注脚本代码，**编译前**由脚本解释器执行并生成代码（H5 定案：编译前执行，无运行时环境——io/alloc/argv 不可用，一般只执行模板生成）；脚本用 H 编写（脚本模式运行），支持实时预览与校验
- **类型信息可见范围（H5 定案，2026-08-14）**：script 块在 class 内 → 该 class 的类型数据可用；在命名空间下 → 整个命名空间类型信息可用（`types` 元数据对象可见范围随块位置收窄：`types.fields(name)` / `types.type(name)` / `types.all()`）；**生成物（class/function/属性列表等）不得与当前环境冲突**（同名 = 编译错误）；脚本用 H 遍历类型定义拼接生成代码，无第二语言
- **脚本 = H 核心子集**（评审 B1）：在特定分配器、特定 IO 下运行，尽可能与 H 核心一致；若摩擦过大，后续可定义受限子集——脚本生成**必须实现**（核心特性）
- **comptime**：语言内保留（泛型/类型级计算，ADR-0006 修正）；**`comptime { ... }` 块（H5 定案）**——**编译时**执行（语义分析阶段），能获取的数据多得多（完整类型系统，可执行更多操作）；comptime 函数 = 参数含 `type`/`anytype` 即触发编译期执行的普通函数；`types` 元数据在 comptime 上下文可见全部类型
- **错误机制统一（2026-08-14 定案，Q5）**：作用域、函数、`script` 块、`comptime` 块均为可返回错误的执行单元（error union）——`script`/`comptime` 块执行失败 = **编译错误**，由解释器（脚本模式）或编译器（编译模式）抛出，错误信息带**块内位置** + 所属块位置；与运行时错误（函数/作用域）同一 error union 机制
- 分工：comptime 管类型级计算（泛型、类型即值、comptime_int）；脚本生成管样板与数据定义驱动代码生成——**「数据定义 → 样板」场景下脚本功能可选**（评审 A4，comptime 可承担生成）
- **降级闸门（Q-S10 定案，2026-08-13）**：脚本生成保持 1.0 必达；若 M5 后 VM/LLVM 一致性无法通过或脚本生成器成本超预期 → 1.0 降级为「脚本生成 = 编译期执行 H 子集函数（comptime 内联）」，`script{}` 语法保留、实现走编译期求值（B1 预案：特定分配器/IO 子集）
- 无宏（12.22）

## 8. 模块与包管理

- **命名空间组织**（2026-08-13 Q21 定案，C# 式）：`namespace Math { ... }` 块式分组（可跨文件、一文件多组）；`using Math;` 引入（限定访问与直接使用）；文件退化为物理单元
- **`pub` 管包边界**：同包跨命名空间靠 using；跨包可见需 pub + build.zon 依赖声明
- 包管理器内置进编译器（Zig 第一）；官方注册中心（Rust 第二）
- **依赖清单 = H 数据字面量**（2026-08-13 Q26 定案）：`const build = Build{ ... }`——清单即数据，脚本生成器可读取（A4 输入通道）；**build 文件 = `build.zon`**（2026-08-14 定案：Zig 式文件名，内容为 H 数据字面量——包名/版本/作者 + 依赖列表（名称/来源/版本/哈希指纹）+ 构建选项）；`hc pkg add ns/pkg@ver` 写依赖；**供应链安全（评审 C3）**：依赖包 `script` 块执行前指纹校验 + 来源审计
- **编译单元 / 文件模型（2026-08-14 定案）**：**目录 = 包（package）**——包内全部 `.hc` 文件共享命名空间（同包跨文件直接可见，Q21 跨文件成立）；跨包访问 = `using pkg.xxx` + `build.zon` 依赖声明；`hc build` 编译包内全部文件；`hc run file.hc` 单文件脚本运行（隐式单文件包）；无「文件级 import」（文件 = 物理单元，C# 式）

## 10. 语法

- C 风格：花括号、分号（三参考语言收敛一致，无争议）
- 命名（2026-08-17 补定）：**类型与命名空间 `PascalCase`**（首字母大写；缩写词全大写，如 `HTTPRequest`/`TCPSocket`）；**标识符（变量/函数/方法/字段/参数）`snake_case`**；**常量 `SCREAMING_SNAKE`**（如 `FLAG_EXEC`）。类型 PascalCase（Zig 第一）沿既有定案

## 11. 标准库

四大支柱映射（详细模块清单见 `04-stdlib-scope.md`）：

| 支柱 | 标准库模块 |
|---|---|
| 定义数据 | 类型系统 + 序列化/反序列化（comptime 驱动） |
| 修改数据 | 集合、容器、数据变换 |
| 传输数据 | 网络、进程间通信、FFI/C 互操作 |
| 保存数据 | 文件、存储、数据库接口 |

策略：Zig 式广度优先，四大支柱做扎实，其余按需。**标准库分层（2026-08-14 定案）**：1.0 **单层 std**（无 core/std 分层，维护成本低）；若 K6 freestanding（裸机）纳入 1.0，届时抽「H core」无 OS 依赖子集，否则 core 留 1.x。

### 12.1 基础语法（部分定义）
C 风格（花括号、分号）；标识符（变量/函数/方法/字段/参数）`snake_case`，类型与命名空间 `PascalCase`（缩写词全大写，如 `HTTPRequest`），常量 `SCREAMING_SNAKE`（2026-08-17 补定，见 §10）。

**测试函数（2026-08-13 Q8 定案；Q-R11 修订）**：`test fn 名称() !void { ... }` 标记为测试的函数（**可被普通代码调用/复用**），`hc test` 收集运行；测试失败 = error；**断言 API（Q-T1 定案）**：`expect` / `expect_eq` / `expect_neq` / `expect_error` / `expect_eq_slices`——归 std.debug、测试函数内隐式可用；**输出统计（Q-T2 定案）**：`[PASS]/[FAIL]/[SKIP] 文件::测试` 逐项 + `N passed, M failed, K skipped` 汇总；失败非零退出码；失败不中止；**隔离/串行/跳过（Q-T3 定案）**：测试函数独立作用域（退出自动销毁）；1.0 默认串行；`return error.SkipTest;` 标记跳过；**环境（Q-T4 定案）**：测试函数内隐式 `test_io`（独立 `Io.threaded()` 实例）+ `alloc`；其它运行时显式创建；**双模式（Q-T5 定案）**：`hc test` 默认脚本模式，`--mode=compile` 交叉验证；**示例测试形态（Q-T6 定案）**：S1 纯逻辑断言 / S2 main smoke / S3 局部逻辑 / S4 演示标注；输出不捕获（见 06 §2）。

**变量声明与指针**（项目所有者定义，2026-08-13；Rust 标杆修订同日）：
- `var mut x: o T = t;` — `var` 声明关键字；默认只读，`mut` 修饰可写（Rust 式，2026-08-13 Q7 定名，占位符解除）；`:T` 类型标注（可推断时省略）；`o` 前缀 = **所有权注册在当前作用域**（作用域退出时销毁；**仅适用于分配器分配的对象**——复杂类型/装箱指针，标量/Continuous 类型上写 `o` 编译错误，2026-08-13 Q15 裁定）
- `var x1: *T = &x;` — `*T` 只读指针类型；`&x` 取只读地址
- `var x2: *mut T = &mut x;` — `*mut T` 读写指针类型；`&mut x` 取可写地址（目标变量须可写）
- 无 `o` = 所有权注册在别处（如 arena 分配器统一分配/收回），本作用域不负责销毁；**无所有权变量（Arena 来源）禁止 move**——move 须对整个 Arena 进行（Q-S11）
- `global` 声明：根作用域上下文，静态生命周期（程序退出时销毁）；**有所有权（归根作用域）**、不可 move（移出即失去全局性）；`o` 标注不用于 global（2026-08-14 定案）
- 作用域退出语句：`defer`（始终执行）/ `errdefer`（仅错误路径）——通用清理机制（Zig 式，见 12.18）；**多 defer 按 LIFO 执行**（Q21 定案，2026-08-13：后声明先执行，与资源创建顺序成镜像）

**已定（2026-08-13；Q-S11 修订）**：`&`/`&mut` 匹配规则——`&x` 对只读/可写变量均合法（读权限可降级）；`&mut x` 仅对 `var mut` 变量合法；`&`/`&mut` 可作用于无 `o` 变量。**指针自由（Zig 式）**：同一变量可有多个 `*mut` 与多个 `*T` 指针同时存在，**指针问题（悬垂/别名）由用户负责**；`*mut` 可复制。

**省略规则（2026-08-13；Q1 裁定修订）**：`:T` 中的 T 与 `*`/`*mut` 描述均可省略，由系统推断；所有权**按分配来源编译时判定**（非 Arena 默认拥有），`o` 为可选冗余标注（不参与推断）。例：`var mut x: o = t;`（可写、类型推断；o 冗余）。

**已定（2026-08-13）**：`move` 参数在函数内隐含拥有（见 12.5）；所有权语法（`o`/`move`/`*`/`*mut`/`&`/`&mut`/`global`）全部定案。

### 12.2 运算符（已定义，2026-08-13；Q4 定案优先级表）
- 算术 `+ - * /`；复合赋值 `+= -= *= /=`
- 除模：`/` 截断除法；`%` 截断取余；`%%` 欧几里得取模（结果非负）
- 逻辑：关键字 `and`/`or`/`!`（不用 `&&`/`||` 符号，避免与位运算视觉混淆）
- 比较 `== != < <= > >=`：严格相等，无双轨（TS 式 `==`/`===` 不采纳）
- 位运算 `& | ^ ~ << >>`；范围 `..`（切片取段）
- **运算符绑定（2026-08-14 定案；H3 修订）**：算术 `+ - * /`（及一元 `-`）绑定 `INumber` 族——`a + b` ≡ `a.add(b)`，`%`/`%%` 由编译器派生；**相等 `==`/`!=` = 值比较，内部调用 ICompare 的方法**（标量/枚举/元组/String/集合按值；**class 身份比较删除**——需实现 ICompare 才有 `==`；指针比较 = 指向对象地址，数组/切片含位置 + 长度）；**序比较 `< <= > >=` 绑定 `ICompare`**（未实现则编译错误）；**无用户运算符重载**（运算符只绑定内建接口族）
- 解引用：标量取值显式 `p.*`；字段/索引访问**自动解引用**（`p.x`、`s[i]`，评审 A3）
- optional 解包：`x orelse 默认值`；`x.?` 显式断言解包（空则运行时错误带位置）
- 运算符重载：无（与「没有隐藏控制」一致）
- **整数溢出（Q-S6 定案，2026-08-13）**：Debug/脚本检测 → `@panic`（带位置）；Release 裸 wrap（两补码回绕）；`@addWithOverflow` / `@subWithOverflow` / `@mulWithOverflow` 显式原语（返回 value + overflow 标志，不受模式影响）；`@intCast` 超范围 Debug 检测/Release 裸
- **`&` 三义（Q24 定案，2026-08-13）**：单一 `&` token——类型位置 = 切片 `&[T]`；表达式一元 = 取地址 `&x`/`&mut x`；二元 = 位与；parser 上下文消解（见 06 §3）
- **优先级与结合性**（Zig 式 14 级，2026-08-13 Q4 定案）：后缀(1) → 一元(2) → `*`/`/`/`%`/`%%`(3) → `+`/`-`(4) → 移位(5) → 位与(6) → 位异或(7) → 位或(8) → 比较(9，非结合) → `and`(10) → `or`(11) → `orelse`/`catch`(12) → `..`(13) → 赋值(14，右结合)；`&` 一元/二元按位置区分；`try a catch b` = `try (a catch b)`。完整表见 06 §3

### 12.5 函数（部分定义）
函数是有名字的作用域（见 §4）；传参规则：标量/Continuous 类型默认复制，数组/集合/复杂类型为引用类型（传引用，复制需显式），其它对象只能引用/move。

**参数与返回值**（项目所有者定义，2026-08-13；Q22b 修订为类型标注制）：
- `fn fun(y: o *mut T) void {}` — 参数拥有用 `o` 标注（`o T` 拥有 / `*T` 只读引用 / `*mut T` 可写引用）；接口约束用签名末尾 **where 子句**：`fn add(a: *T) void where T: INumber`（调用点 `add(&a)` / `add(&mut a)` / `add(move a)`）
- **move 规则（2026-08-13 修订）**：仅拥有所有权（非 Arena）的变量可 move——**无谓词限制**（可含引用字段、可有外部指针，指针问题用户负责）；`o T` 参数在函数内负责销毁（退出自动销毁）；**`o` 与 `*`/`*mut` 正交**：`o *mut T` 允许（拥有可写指针）
- 非拥有参数 `y: *mut T` / `y: *T` 为借用（调用方保留所有权）
- **返回值规则**（细节待后续讨论）：函数内新建的值必须 move 返回（无所有权的除外）；返回引用必须是指向函数参数（只读/读写参数）的引用，不得返回局部变量的引用（悬垂防护）
- 返回值语法（已同意）：`fn() oT`（拥有）/ `fn() *T` / `fn() *mut T`（引用）
- **权限标注模型**（2026-08-13，评审 D2；Rust 标杆修订）：类型标注 = 类型 + 读写权限（`*`/`*mut`）+ 所有权（o）；move 基于所有权判定（**拥有所有权才能 move**——非 Arena 分配），与读写权限同属统一权限体系；comptime 函数返回类型（`fn List(T: type) type`）不适用运行时 move 规则

**所有权语法已全部定案（2026-08-13，Rust 标杆修订）**：`o`/`move`/`*`/`*mut`/`&`/`&mut`/`global` 及省略规则、move 隐含拥有。

**重载与可选参数（2026-08-14 定案）**：
- **允许重载**：函数签名 = **函数名 + 参数类型列表 + 返回类型**（共同决定）；调用点按参数精确匹配，返回类型在目标类型已知时参与选择（`var x: f64 = get();` 选返回 f64 的重载）；字面量（惰性宽度）匹配多个重载或上下文歧义 → **编译错误，要求显式标注**
- **泛型重载**：泛型函数（where 约束）在调用点**编译时验证**约束——验证通过即可调用（Q1c 定案：接口限制**运行时拆除**——单态化静态分发，无虚表、无运行时检查，零开销）；泛型与具体重载并存时统一参与解析（Q1a 歧义规则）
- **可选参数**：`fn f(a: i32, b: i32 = 0)`——默认值须**编译期常量**（字面量/const）；只能出现在参数列表**尾部**；解析优先精确参数数量匹配
- 接口方法（如 INumber 的 `add`）为**成员契约**，不参与全局重载解析；`new` 样板由脚本生成（参数按字段）

**内建函数（Q12 定案，2026-08-13）**：`box(value, alloc)`（装箱 → `o *mut T`）与 `copy(&value)`（深拷贝）是编译器内建的数据操作原语，不可用户定义/重载；非关键字（见 06 §5）。

### 12.6 条件语句（已定义，2026-08-13）
- `if` 是**表达式**：`var x = if (c) a else b;` — 作表达式时 **else 强制**（保证确定值，呼应显式初始化）；作语句时 else 可选
- `if (opt) |v|` 捕获 optional（配合 12.3 的 `?T`）
- **`if (e!) |v| else |err|` error union 双向捕获（Q9 定案，2026-08-13）**：必须成对——错误必须显式处理（「没有隐藏控制」）；作表达式时两分支值类型一致
- switch 穷举匹配见 12.13

### 12.7 循环（已定义，2026-08-13）
- `while (cond) {}`；续步表达式：`while (i < n) : (i += 1) {}`（替代 `for` 的更新子句）
- **while 捕获（Q10 定案，2026-08-13）**：`while (opt) |v| {}`（optional 捕获，空则退出）；`while (e!) |v| {} else |err| {}`（error union 捕获，错误走 else 后退出）；可与续步表达式组合 `while (opt) |v| : (continue_expr) {}`
- `for (items) |item| {}` — 数组/切片迭代，捕获默认只读；可写捕获 `for (items) |mut item|`（2026-08-13，评审 B5 + Rust 标杆统一）
- 无 `do-while`、无 `loop` 关键字（用 `while (true)`）
- `break`/`continue` + 带标签 `break :label` / `continue :label`（嵌套退出）

### 12.8 迭代器（已定义，2026-08-13；2026-08-14 契约细化）
- `for` 支持数组/切片直通；任何实现「迭代特性」（12.16）的类型可参与 `for` 迭代（`for` 语法不变，底层走特性）
- **迭代契约（2026-08-14 定案）**：接口 **`IIterable`** 按**元素访问形态**三态（泛型实例化语法与 `Vec(i32)` 一致用圆括号）：
  - `IIterable(*T)` — 只读迭代（默认 `for (x) |item|`）
  - `IIterable(*mut T)` — 可写迭代（`for (x) |mut item|`，评审 B5）
  - `IIterable(o T)` — 拥有迭代（`for (x) |move item|`，**M4 定案：迭代器持有容器所有权——x 被 move 进迭代器、next 逐元素转移所有权、迭代后容器不可再用**；内建实现：Vec/String/Deque 逐个 pop + 转移、数组逐元素 move）
  元素类型 T 与形态由接口方法（`next(self: *mut Self) ?T` 按对应形态）推断；内建类型（数组/切片/Vec/Map/Table/String）编译器内建实现三态
- 标准库提供迭代器对象：`arr.iter()` — **迭代器是显式数据对象**，可传递、可组合；一次性迭代器（next 消耗状态）1.0 即可；惰性/组合子迭代留 1.x（与「无隐藏控制」张力）
- 变换**立即求值**（TS 式）：`arr.iter().filter(...).map(...)` 每步产出新数据对象
- 惰性适配器不进入 1.0（求值时机隐藏，与「没有隐藏控制」张力最大）；作为 1.x 性能通道

### 12.9 闭包（已定义，2026-08-13）
Zig 无闭包，按参考规则取 Rust 第二；捕获模式与 H 语法体系对齐：

- 捕获模式**显式标注**（粒度 = 整个闭包）：默认只读捕获（**自由变量精确分析，2026-08-17——只捕获 body 实际引用的外部变量，含嵌套传递；未引用变量不捕获**）；`mut |x| ...` 提升为可写捕获（Rust 标杆）；`move |x| ...` 转移捕获（深拷贝独立副本）——捕获模式在声明处可见（无隐藏）；只读捕获内重绑定被捕获变量（含复合赋值）→ `error.ReadonlyCapture`
- 调用语法：`f(x)` 直接调用（对数据对象做「调用」操作）
- 闭包是**数据对象**：捕获为字段的结构体 + 调用约定；遵循所有权模型（可 `o`、可 move、捕获随闭包销毁）
- **捕获登记（Q26 定案，2026-08-13；Q-S11 修订）**：捕获变量与闭包建立 **Debug 可选悬垂标记**（编译时选项开启：目标销毁 → 闭包标记，调用提示带位置——诊断工具，非安全保证）；闭包存容器合法（67/72 模式）
- **销毁顺序（Q26 定案）**：作用域退出 = 声明逆序（LIFO），容器先于被捕获目标销毁，常规无悬垂
- 单变量粒度捕获留 1.x
- 闭包类型标注与「特性」（12.16）联动

### 12.10 所有权（已定义）
见 §4 内存模型（作用域所有权、move、销毁责任）。语法形式：`o` 类型前缀（拥有）、`move` 参数（转移所有权）、`*T`/`*mut T`（引用），见 12.1/12.5。

**可移动性（2026-08-13 修订；2026-08-14 补充）**：可 move ⟺ 拥有所有权（非 Arena/global，见 §4）——**旧「内存树无外部引用」谓词取消**（指针别名自由，用户负责）；move 转移销毁责任（**不复制数据、不移动内存、变量本身不变**）；**move 后原绑定仍可访问**（内存仍有效），继续访问造成的悬垂/冲突由用户负责（2026-08-14 定案）。

**指针可空性（Q16 定案，2026-08-13）**：`*T`/`*mut T` 不可空（空态用 `?*T`/`?*mut T`）；悬垂属用户责任（Debug 悬垂标记为可选诊断工具）；无 NULL 字面量。

**临时引用生命周期（Q25 定案，2026-08-13）**：临时 `*mut`/`*T` 存活到所在完整表达式/语句结束；绑定引用存活到作用域结束（原「写者资格/链末注销/reborrow」语义随唯一写者取消而移除——传参即指针传递）。

### 12.11 切片（已定义，2026-08-13；Rust 标杆修订同日）
切片 = `*T`/`*mut T` 的带位置与长度形态，**Rust 式类型** `&[T]`（只读）/ `&mut [T]`（可写），对连续内存的**视图**，**不拥有数据**（无 `o`）：

- `var s: &[T] = &arr[1..3];` — 只读切片；`var s2: &mut [T] = &mut arr[1..3];` — 可写切片
- 操作与 `*T`/`*mut T` 一致：**多切片自由、指针问题用户负责、Debug 悬垂标记可选**（2026-08-13 Q-S11 修订）
- `move` 只针对切片所在的定长数组（`o [N]T`），不针对切片本身
- **数组的引用默认就是切片（H4 定案，2026-08-14）**：`&arr` 直接产生切片（起始 + 长度）——`&arr` 类型即 `&[T]`（切片 = 带索引位置和长度的指针）；`&arr[start..end]` 指定范围（`..` 范围含首不含尾）
- 数组 `[N]T` = **引用类型**（评审 B3）：可有 `o`、可被切片；复制需显式
- 传参：与指针规则一致——参数 `&[T]`/`&mut [T]`，无「视图例外」；切片含指针，属「其它对象」而非数据栈对象
- 字符串字面量 → 静态只读切片 `&[u8]`（无 `o`、不可 move；细节归 12.19）

### 12.12 类型定义（2026-08-14 定案：struct/class 合并；H1 修订：特性标注）
「定义数据」支柱的核心。**统一关键字 `class`**（`struct` 删除）；**存储形态由特性标注决定**（H1 定案，取代自动判定；无继承、组合优于继承）：

- **特性标注语法（H1 定案）**：类型声明上方中括号 `[name]` / `[name(参数)]`——`[continuous]`（连续内存值类型）、`[pad]`（紧凑打包，原 `packed`）、`[align(T)]`（对齐到类型 T 的对齐值，如 `[align(u64)]` = 8 字节）
- **`[continuous]` 标注**：连续内存值类型——值语义全集（无分配器/栈上/可内嵌、赋值即复制、`to_bytes`/`from_bytes` 直映射、`[pad]`/`[align(T)]` 布局控制、字面量构造 `X{...}`）；编译器验证字段全为值类型（标量/枚举/定长数组/元组/连续类型），否则编译错误
- **未标注 → 堆上**：需分配器、接口描述功能、字段可带 `o`、可 move、构造 = `alloc.init(T)`（分配器按类型自动大小创建实例）/ `new()` 样板 / 普通函数返回、`to_json`/`from_json`
- 字段可含：标量、连续类型、元组、**定长数组（内嵌连续）**、切片、复杂类型（String/集合/class，Q2 裁定放宽——成员集统一）
- **成员可见性（Q3 定案）**：**方法默认公开**（`pub` 标注）；**属性默认私有**（`private` 标注，显式可选项）；`pub mut A: o T`——pub（可见性）+ mut（字段可写）+ `o T`（字段类型形态）分离；**属性无所有权标注**（即使字段类型 `o T`，所有权由类型实例管理，随实例销毁）
- 字段默认只读，`mut` 修饰可写字段；写字段需持有类型实例的可写引用（`*mut`）
- **构造**：`alloc.init(T)`（分配器按类型自动获取大小并创建实例，返回拥有实例）；`box()` 装箱值
- 方法 = 类型声明的函数成员（Zig 式，无 `impl` 关键字）：`[continuous] class Point { x: f32, y: f32, fn dist(a: *Point, b: *Point) f32 }`；字面量构造 `Point{x = 1.0, y = 2.0}`（连续类型）
- **元组（2026-08-14 定案）**：无名称、初始化后字段只读的匿名值类型（天然连续内存）：`(1, "a", 2.5)`；访问 `t.0`/`t.1`；**支持解构** `var (a, b, _) = t;`；**多值返回** `fn divmod(a, b) (i32, i32)`（`var (q, r) = f();`）；`==` 逐元素（值比较）；可 `to_bytes`、可内嵌、可作 Map 键
- 与 12.20 组合：类型定义是「组合优于继承」的基础；差异 = `[continuous]`（值语义）vs 未标注（堆上引用语义）

### 12.13 枚举类（已定义，2026-08-13）
「定义数据」支柱的类型构造，**合一式**（Rust 式变体 + Zig 式捕获语法）：

- `enum Value { int: i32, float: f64, none }` — 变体可选负载；纯常量枚举 = 变体均无负载的特例
- switch 穷举：漏分支编译期报错；负载捕获沿用 `|x|` 惯例
- 数据栈对象自动判定：负载全为值类型 → 可复制；含引用 → 只能引用/move（与类型定义一致）
- 变体负载含复杂类型/数组时，枚举实例归其它对象（2026-08-13，评审 D3 延伸）
- **枚举 ↔ 整数（2026-08-14 定案）**：`@intFromEnum(e) usize`（变体序索引，0 起）/ `@enumFromInt(i) E`（反向，越界 Debug 检测 / Release 未定义值）；仅**纯常量枚举**（变体无负载）可转换；带负载枚举不可（须 switch 匹配）；`@intCast` 不处理枚举

### 12.16 泛型和特性（已定义，2026-08-13 重构）
- **泛型 = comptime 式**：`fn List(T: type) type`、`anytype`、类型即值、惰性实例化（Zig 式，2026-08-13 保留）
- **脚本生成**（§7）负责样板与数据定义驱动的代码生成（序列化/校验/存储）
- **分工已确认**（X1，2026-08-13）：comptime 管类型级计算；脚本生成管样板代码生成
- **接口（特性）** = 类型的**特性标**（2026-08-13，评审 A1）：声明类型必须实现的方法契约——`interface A { fn a(t: *mut T) }`；类型显式声明实现（implements 标注，具体形式待定）；可描述复杂类型、标量类型、内建类型、用户定义类型（class/Continuous/元组）。**内建特性 Continuous（2026-08-14 定案）**：编译器识别的布局标记（非行为契约，见 12.12）
- **标量接口族（2026-08-14 定案；修订：比较接口化）**：内建标量构成数字接口层级——**`ICompare`**（`eq`/`lt`，派生 `ne`/`le`/`gt`/`ge`）→ **`INumber : ICompare`**（`add`/`sub`/`mul`/`div`/`neg`）→ `IInt`（有符号 `i8`–`i128`/`isize`，+`mod`/`abs`）/ `IUint`（无符号 `u8`–`u128`/`usize`，+`mod`）/ `IFloat`（`f16`–`f128`，+`abs`/`pow`）；内建标量编译器内建实现（不可重载）；**相等 `==`/`!=` 语言内建通用**、**序比较 `<` 等绑定 `ICompare`**（String 编译器内建实现 ICompare）；运算符 `+ - * /` 绑定该族（12.2）；`where T: INumber` 可约束标量；标量可 `box` 装箱为 `*INumber`/`*mut INumber`（接口 = 类型标注，Q17 统一机制）
- **泛型约束验证（Q1c 定案，2026-08-14）**：泛型函数（where 约束）在调用点**编译时验证**——验证通过即可调用；**接口限制运行时拆除**（单态化静态分发、无虚表、无运行时检查——零开销）；泛型与具体重载统一参与解析（见 12.5）
- **接口指针（Q17 定案，2026-08-13；M5 修订）**：`*Shape` = 胖指针（**三字宽 = data + 虚表 + alloc 引用**——装箱携带分配器、销毁 `o *I` 用携带的 alloc 释放 data）；`box` 装箱后赋给接口指针**编译期自动收窄**（接口实现检查）；data 部分参与 Debug 悬垂标记（同 `*T`），虚表不参与
- **接口三用途（Q-R9 定案，2026-08-13）**：① 标记 class 功能（implements 标注：`class Foo: Shape`）；② 标记参数类型（`where T: Shape` 约束）；③ 类型参数编译可验证（单态化检查实现）
- **接口参数（Q22/Q22b 定案，2026-08-13）**：带约束虚拟类型 T——约束放签名末尾 **where 子句**（`fn add(a: *T) void where T: INumber`）；形态映射 `&T`→`*T`（只读）/ `&mut T`→`*mut T`（可写）/ `move T`→`o T`（拥有）；调用点 `add(&a)` / `add(&mut a)` / `add(move a)`；静态单态化为主路径，`*Shape` 胖指针（Q17）用于异构集合
- **接口工厂（R-4 定案，2026-08-13）**：`Io.threaded()`/`Io.evented()` 返回**具体实现类型**（`ThreadedIo`/`EventedIo`，实现 Io）；入口 `main(io: Io)` 由编译器注入并自动收窄为接口句柄；具体类型值 → 接口句柄参数自动装箱
- 接口用于约束与组合（12.20）；闭包「调用契约」、迭代「迭代契约」均为接口实例
- **接口不提供运算符重载**（12.2 已定）
- 「数据定义 → 样板」场景下脚本功能**可选**（评审 A4：comptime 可承担生成；脚本为 H 核心子集，见 §7）

### 12.18 文件与 IO（已定义，2026-08-13；Q22c 修订；2026-08-17 修订形态）
- **IO 环境 = 标准库模块（2026-08-17 定案，ADR-0010——修订 Q22c/12.18）**：`import H.std.{io}` 引入，函数直接调用（`io.print(...)`/`io.fs.*`/`io.net.*`）——无参数传递、无入口注入；「没有隐藏控制」仍成立（import + 显式调用可见）
- `Io` 接口保留（2026-08-17）：并发 E2 的 `Io.threaded()/evented()` 显式切换机制仍是设计的一部分；入口注入取消（原 Q22c 虚拟类型制 `io: *T where T: Io` 不再作为入口形态）
- 文件句柄关闭：**defer 式**——`defer f.close()` 保证作用域退出时关闭（清理动作在创建处显式可见，不用隐式析构）；`errdefer` 仅在错误返回路径执行
- `defer`/`errdefer` 是通用作用域退出语句（Zig 式），不限于 IO
- 错误一律 error union（无异常）；同步默认，事件循环式运行时为脚本模式库选项
- 双模式下同一套 IO 标准库行为一致
- 字节为中心：`&[u8]` 视图 + 文本编码函数（UTF-8 优先）
- **程序环境（2026-08-14 定案；2026-08-17 修订）**：`io` 模块提供——`io.env(name) ?&[u8]`（环境变量）、`io.stdin`/`io.stdout`/`io.stderr`（字节流：`read_all`/`write_all`）；**命令行参数经入口 `main(args)` 注入（0 号 = 程序名），`io.args()` 取消（ADR-0010）**
- **退出（2026-08-14 定案）**：默认枚举 **`enum ExitType { Exit, Error }`** + `io.exit(t: ExitType, code: u8) !void`——`Exit` 正常静默退出、`Error` 错误退出（打印错误标记/位置）；`main` 返回 error → 等效 `io.exit(ExitType.Error, 1)`；正常返回 → `io.exit(ExitType.Exit, 0)`；测试失败 → 非零（Q-T2）

### 12.19 集合与字符串（已定义，2026-08-13；Q3 裁定修订）
- 集合/字符串 = **复杂类型**（class 家族）：堆上、组合、接口描述功能（12.20/12.16）；**引用类型**（评审 B3）：传参走引用，复制需显式 `copy(&x)`；**赋值 = 编译错误**（2026-08-14 修订，取代 Q3c 别名共享：共享走显式指针、复制走显式 `copy(&x)`；`copy` 默认深复制，浅复制需显式标注，内存问题用户负责）；**String = 内建新类型（2026-08-13 Q3 裁定；2026-08-14 M3 修订）**：底层布局 = `Vec(u8)`（编译器内建实现），功能与 `Vec(u8)` 一致，数组/切片规则全部适用（切片 = 数组的视图）；**内容视图 `s.as_slice() -> &[u8]`（R-2 定案：无前缀；`to_bytes()` 为带前缀序列化格式 Q38）**；原 Q16「String 值复制」例外取消（「无隐式分配」原则恢复无例外）
- 泛型集合 **comptime 式实例化**（2026-08-13 修正，X1 连带）：`Vec(T)` 由编译期机制实例化——**双模式一致**（编译模式编译期实例化、脚本模式执行前实例化，机制同一）
- **语言无内建字符串**：字面量 = 静态只读切片（`&[u8]`，见 12.11）；可变字符串 = 标准库 `String`（`u8[]` 的别名，2026-08-13 Q3 裁定；借 `class` 定义，接口描述 UTF-8 等能力）
- 集合接口：迭代契约（12.8）+ 序列化契约（定义数据）等
- 主要集合：`Vec`、`Map`、`Set`、`Deque`（04-stdlib-scope 细化）；**`Table(T)`（2026-08-14 定案）**：内建二维结构代替二维数组（`[M][N]T` 移除）——构造 **`Table(T).init(alloc, rows, cols, init)`**（M8：统一方法形态）、访问 **`t[i, j]`**（M8：多参索引，仅 Table 合法）、定长、引用类型（传参走引用、复制需显式 `copy`）、行主序连续内存可 `to_bytes`

### 12.20 面向对象和组合（已定义，2026-08-13；2026-08-14 修订）
- **类型** = 组合 + 接口，**无继承**：统一关键字 `class`（struct 已合并，12.12）；`tree`（递归/层级结构）保留——家族可扩展
- `tree` = 递归组合：节点含子节点集合，父子所有权层级化（父 `o` 拥有子）——JSON/配置/文档树形态
- 成员：字段（标量/Continuous/元组/其它复杂类型，可带 `o`）+ 方法（Zig 式函数成员，同 12.12）+ **显式接口实现**（12.16）
- 构造 = `new()` 样板 / 普通函数返回实例（无特殊构造语法，Zig/Rust 式）；Continuous 保留字面量构造 `X{...}`（12.12）；脚本生成为常用构造提供样板
- **无隐式析构**：资源清理走 `defer`（F1 已定）
- **可移动性（2026-08-13 Q-S11 修订，取代 Q1 谓词）**：move 唯一约束 = **拥有所有权**（非 Arena 分配；Arena 归 Arena，禁止 move——move 须对整个 Arena 进行）；旧「内存树无外部引用」谓词取消——**含引用值字段的 class 实例同样可 move**（指针问题用户负责）；class 实例 move = 整个内存树（含 String/Vec 等自有子对象）的销毁责任一起转移
- 组合优于继承（Zig 第一）

### 12.21 并发编程（已定义，2026-08-13）
- 共享状态：四种线程访问模式类型 `OneToOne(T)`/`OneToMany(T)`/`ManyToOne(T)`/`ManyToMany(T)`——内建泛型共享内存容器（脚本生成实例化），读前写后的命名顺序
- **四模式类型方法集（Q14 定案；Q-R12 补充）**：`init(alloc)` / `write(v)` / `read() T`（阻塞）/ `try_read() ?T`（非阻塞）/ `close()`（结束标志，消费型语义）/ **`send(v)`、`recv() T`（通道方法——线程间数据传输，与 write/read 同源，Q-R12 定案）**；方法取 `*Self`（Q32 内建共享特例）；close 后 write 报错、try_read 返回 null
- **缓冲与阻塞（2026-08-14 定案）**：共享内存容器（write/read）**无容量概念**——write 不阻塞（直接写共享槽 + 内部同步，写者数由类型名保证）、read 阻塞到有值；通道（send/recv）为**有界队列**——容量构造时指定（`init(alloc, cap)`），send 满时阻塞、recv 空时阻塞；close 后 write/send 报错、try_read/try_recv 返回 null
- **原子操作（Q-S3 定案，2026-08-13）**：`@atomicLoad(T, p, order)` / `@atomicStore(T, p, v, order)` / `@atomicRmw(T, p, op, v, order)`——无锁原语；内存序 `relaxed`/`acquire`/`release`/`acq_rel`/`seq_cst`（默认 seq_cst）；四模式类型内部实现基于这些原语
- 线程所有权：spawn 归当前作用域；退出时已完成→销毁、运行中→移交根作用域（无隐式阻塞）；显式 `t.join() !T`（消耗所有权，返回结果与 error union 错误）
- 线程捕获：值类型复制；引用类型 move 或 global（无只读引用捕获；≠闭包捕获 12.9）
- **线程捕获静态检查（Q19 定案）**：绑定/逃逸数据流判定（作用域内 join/await = 绑定可捕获引用；detach 或未 join 退出 = 逃逸禁引用捕获）+ **冻结窗口**（spawn→await 间被捕获目标主线程不可写，await/join 后恢复；并发写共享数据走四模式类型）
- 同步原语：由四模式类型族承担（Mutex 式语义并入 `ManyToMany` 等）
- 线程 = 复杂类型数据对象（12.24）；Send/Sync 式静态标记
- 根作用域 = 程序最后退出场所（评审 A7）：负责最终资源回收；global 定义于此；后期线程池亦于此

### 12.23 异步编程（已定义，2026-08-13 逆转）
- **async/await 是语言关键字**（逆转此前 Zig 式无关键字决策；偏离 Zig 第一，取 Rust/TS 式）
- `async fn f(...) R` 返回 **`Future(R)`**（R = 完整返回类型，含 `!`，Q20 定案 2026-08-13）；`await f` 等待完成并返回 R（函数级标记，Rust/TS 惯例）
- **执行语义 = 线程默认**：`async` 函数 = 线程任务（`Io.Threaded`），`await` 等待线程结果（与 `t.join()` 同源）；事件循环（Evented）为可选运行时实现，接口不变
- `Future(T)` = 异步任务结果句柄（复杂类型），基于线程任务；`await` 返回完整类型（含 error union，`try await` 解包）
- 关联 12.21（await 与 join 语义同源）、12.24（线程是数据对象）
- 执行模型考虑 **Go 式协程 + 通道**（M:N 调度，评审 B2 方向）——缓解「每个 async 任务一个 OS 线程」的爆炸风险；方向待细化

### 12.24 多线程模型即数据对象（已定义，2026-08-13）
- **线程 = 数据对象**（H 特有）：`Thread` 是复杂类型（class），可定义、move 传递、join 消耗
- 所有权规则：spawn 归当前作用域；退出时已完成→销毁、运行中→移交根作用域
- `t.join() !T` 消耗所有权获取结果（错误跨线程以 error union 传播）
- **接口契约**：`interface Thread(T)` — `join() !T`、`cancel() !void`、`is_done() bool`
- **detach()**：消耗所有权、显式放弃结果（线程继续运行，由根作用域回收）——与 join、作用域退出移交三种路径覆盖线程生命周期
- 线程捕获规则见 12.21；与四模式类型的组合用法（如 `ManyToMany(T)` 承载线程间共享）

### 12.26 跨语言调用（已定义，2026-08-13 Q-S4 定案）
见 §11 传输数据（FFI/C ABI + `hc cc`）。参考：Zig `extern`/链接模型；Rust `extern "C"` + FFI；TS 无原生 FFI。

- `extern fn c_func(args...) 返回类型;`——C ABI 外部函数声明（链接期解析；`hc cc` 编译 C 源码链接）
- `@cImport("header.h")`——编译期解析 C 头文件生成 H 声明（内建 C 解析器；基本类型/struct/enum/函数指针）
- **C 指针 = `*T` 但不参与双向登记**（外部内存、用户负责——悬垂/写者检测不适用）；进入引用体系需显式 `box` 包装
- **C 错误码 → error union：手动映射**（无隐式转换——`if (ret != 0) return error.X;`，与「没有隐藏控制」一致）
- C struct ↔ H Continuous 类型：POD 直映射 + `@offsetOf`/`@alignOf` 布局验证；函数指针 → `FnN` 调用接口（显式转换）

**2026-08-14 确认（清理待定标记）**：① C 头导入 = 内建 `@cImport`（Q-S4 已定：编译期解析 C 头生成 H 声明，内建 C 解析器；范围：基本类型/struct/enum/函数指针）；② C 指针 = **外置**——`*T` 不参与 Debug 悬垂标记，进入引用体系需显式 `box` 包装（Q-S4 已定）；③ C 错误码 → error union = **手动映射**（Q-S4 已定，无隐式转换）。
